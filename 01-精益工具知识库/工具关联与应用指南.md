## 工具组合应用场景

### 场景一：新产线建设/改造

**推荐工具组合：**
1. **5S** → 建立现场管理基础
2. **标准作业** → 制定操作流程
3. **VSM** → 设计理想价值流
4. **TPM** → 确保设备可靠性
5. **安灯** → 建立异常响应机制
6. **看板** → 实施拉动生产
7. **可视化** → 实现状态透明

**实施顺序：** 5S → 标准作业 → TPM → VSM → 安灯 → 看板 → 可视化

### 场景二：质量提升专项

**推荐工具组合：**
1. **标准作业** → 确保操作一致性
2. **防错** → 预防人为失误
3. **安灯** → 及时发现异常
4. **5Why** → 分析根本原因
5. **A3** → 结构化问题解决
6. **SPC** → 统计过程控制

**实施顺序：** 标准作业 → 防错 → 安灯 → 5Why → A3 → SPC

### 场景三：效率提升专项

**推荐工具组合：**
1. **VSM** → 识别浪费环节
2. **SMED** → 缩短换模时间
3. **TPM** → 提升设备效率
4. **标准作业** → 优化作业流程
5. **改善** → 持续小步改进
6. **OEE分析** → 量化改进效果

**实施顺序：** VSM → 标准作业 → SMED → TPM → 改善 → OEE分析

### 场景四：库存降低专项

**推荐工具组合：**
1. **看板** → 建立拉动系统
2. **平准化** → 均衡生产节奏
3. **JIT** → 实现准时交付
4. **SMED** → 支持小批量生产
5. **TPM** → 确保设备稳定
6. **安灯** → 快速响应异常

**实施顺序：** SMED → TPM → 看板 → 平准化 → JIT → 安灯

## 工具间协同效应

### 强协同工具对

| 工具组合 | 协同效应 | 应用示例 |
|---------|---------|---------|
| **5S + 可视化** | 现场状态一目了然 | 物料定位标识 + 状态看板 |
| **标准作业 + 防错** | 标准化操作防失误 | 作业指导书 + 防错装置 |
| **看板 + 安灯** | 拉动生产异常响应 | 看板信号 + 异常停线 |
| **VSM + 改善** | 价值流持续优化 | 价值流分析 + Kaizen活动 |
| **TPM + SMED** | 设备效率最大化 | 预防性维护 + 快速换模 |

### 工具实施前提条件

| 工具 | 必要前提条件 | 说明 |
|------|-------------|------|
| 看板 | 5S, 标准作业 | 需要有清晰的现场管理和作业标准 |
| VSM | 基本数据收集 | 需要了解各工序的节拍时间、换模时间等 |
| SMED | 标准作业 | 需要有标准的换模流程作为改进基础 |
| 防错 | 问题分析 | 需要明确常见错误类型和原因 |
| 平准化 | 看板系统 | 需要建立拉动系统作为基础 |

## 紧固件行业工具应用优先级

### 冷镦工序
**优先级排序：**
1. 5S（模具管理）
2. 标准作业（换模流程）
3. SMED（换模时间缩短）
4. TPM（模具寿命管理）
5. 防错（钢丝直径防混）

### 搓丝工序
**优先级排序：**
1. 防错（螺纹检测）
2. 标准作业（搓丝板安装）
3. TPM（搓丝板寿命管理）
4. 安灯（质量异常报警）
5. SMED（快速换型）

### 热处理工序
**优先级排序：**
1. 标准作业（工艺参数）
2. 可视化（炉温监控）
3. 安灯（温度异常报警）
4. TPM（炉体维护）
5. 防错（料框防混）

### 表面处理工序
**优先级排序：**
1. 安灯（槽液参数监控）
2. 标准作业（槽液维护）
3. 可视化（参数趋势）
4. 防错（氢脆防控）
5. TPM（设备保养）

### 包装工序
**优先级排序：**
1. 防错（混料防止）
2. 标准作业（包装流程）
3. 5S（包装材料管理）
4. 看板（补货信号）
5. 安灯（称重异常）

## 工具实施成熟度评估

| 成熟度等级 | 特征 | 推荐工具 |
|------------|------|----------|
| **L1 初始级** | 现场混乱，问题频发 | 5S, 标准作业, 基础培训 |
| **L2 基础级** | 基本秩序建立，设备稳定 | TPM, 安灯, 防错, SMED |
| **L3 发展级** | 流程标准化，异常减少 | 看板, 可视化, 改善, PDCA |
| **L4 优化级** | 拉动生产，持续改进 | VSM, JIT, 平准化, A3 |
| **L5 卓越级** | 精益文化，尽善尽美 | 全员改善, 精益供应链, 创新 |
