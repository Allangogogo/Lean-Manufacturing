# 搓丝工序精益应用

> 将精益工具应用于金属紧固件搓丝（Thread Rolling）工序的实践指南。

## 工序概述

搓丝是将冷镦后的半成品通过搓丝板或滚丝轮加工出螺纹的工序，是决定紧固件螺纹精度的关键工序。

| 参数 | 典型值 |
|------|--------|
| 设备 | Sacma 搓丝机、Landis 滚丝机 |
| 节拍时间 | 40-100 件/分钟 |
| 关键质量指标 | 螺纹通止规检测、螺纹中径、螺距、牙型角 |
| 主要浪费来源 | 搓丝板磨损、换型停机、螺纹不良、设备振动 |

## 重点改善方向

### 1. 搓丝板寿命管理

**现状问题**：
- 搓丝板寿命靠经验判断，突发磨损导致批量不良
- 搓丝板更换记录不完整
- 不同产品搓丝板混用

**改善措施**：
- **寿命追踪系统**：每套搓丝板建立档案，累计加工数量，设定预警值（如 80% 寿命）
- **振动监控**：安装振动传感器，实时监控搓丝板状态（>2g 阈值报警）
- **定置管理**：搓丝板按产品系列分区存放，标识清晰，先进先出
- **预防性更换**：达到预警值主动更换，不等到磨损超标

**预期效果**：
- 搓丝板突发磨损归零
- 搓丝板寿命提升 15-20%
- 螺纹不良率降低 60%

### 2. 换型时间缩短（SMED）

**当前状态**：换型时间约 45 分钟

**SMED 改善步骤**：

| 步骤 | 活动 | 时间 |
|------|------|------|
| 外部准备 | 预装搓丝板、准备工具和参数 | 0min（运行时完成） |
| 停机拆卸 | 拆卸旧搓丝板 | 4min |
| 安装调整 | 安装新搓丝板、调整间隙 | 6min |
| 首件检验 | 通止规检测 + 首件尺寸 | 2min |
| **合计** | | **12min** |

**关键改善点**：
- 搓丝板预装在调整架上（外部化）
- 快速夹紧机构替代螺栓紧固
- 标准化间隙参数（数字化存储）
- 通止规自动检测集成

### 3. 螺纹质量防错

**常见缺陷与防错措施**：

| 缺陷类型 | 原因 | 防错措施 |
|---------|------|---------|
| 螌纹通规不过 | 搓丝板磨损、压力不足 | 振动监控 + 自动压力补偿 |
| 螺纹止规过 | 搓丝板间隙过大 | 间隙自动检测 + 预警 |
| 螺纹偏斜 | 搓丝板对中不良 | 导向销 + 自动对中装置 |
| 螺纹烂牙 | 钢丝硬度异常、润滑不良 | 来料检测 + 润滑液监控 |
| 螺距超差 | 搓丝板牙型磨损 | 搓丝板寿命管理 + 首件全检 |
