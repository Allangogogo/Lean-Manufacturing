# 冷镦工序精益应用

> 将精益工具应用于金属紧固件冷镦（Cold Heading）工序的实践指南。

## 工序概述

冷镦是紧固件制造的首道成型工序，通过冷镦机将钢丝线材在常温下镦粗成型，制造螺栓、螺钉、螺母等紧固件的头部和杆部。

| 参数 | 典型值 |
|------|--------|
| 设备 | Sakamura 冷镦机、National 冷镦机 |
| 加工力 | 85kN（M8）~ 400kN（M16） |
| 节拍时间 | 60-120 件/分钟 |
| 关键质量指标 | 头部尺寸、杆部直径、同轴度、表面裂纹 |
| 主要浪费来源 | 换模停机、模具磨损、钢丝来料不良、设备故障 |

## 重点改善方向

### 1. 模具管理精益化

**现状问题**：
- 模具存放混乱，换模时找模耗时
- 模具寿命靠经验判断，突发断裂导致批量不良
- 模具维修记录不完整

**改善措施**：
- **5S 定置管理**：影子板存放模具，按产品系列分区，标识清晰
- **模具寿命追踪**：建立模具档案，记录每次使用数量，设定更换预警值
- **TPM 自主保全**：操作员每日检查模具磨损状况，清洁冲头和凹模
- **可视化管理**：模具状态看板（在用/备用/维修/报废）

**预期效果**：
- 换模时间缩短 50%
- 模具突发断裂归零
- 模具寿命提升 15-20%

### 2. 换模时间缩短（SMED）

**当前状态**：换模时间约 60 分钟

**SMED 改善步骤**：

| 步骤 | 活动 | 时间 |
|------|------|------|
| 外部准备 | 预热下一套模具、准备工具 | 0min（机器运行时完成） |
| 停机拆模 | 拆卸旧模具 | 5min |
| 安装调机 | 安装新模具、调整参数 | 8min |
| 首件检验 | 首件尺寸确认 | 2min |
| **合计** | | **15min** |

**关键改善点**：
- 模具预热外部化（在预热架上提前加热）
- 快速换模夹具（液压夹具替代螺栓紧固）
- 标准化调机参数（电子化存储，一键调用）
- 平行作业（两人同时操作）

### 3. 质量防错体系

**常见缺陷与防错措施**：

| 缺陷类型 | 原因 | 防错措施 |
|---------|------|---------|
| 头部裂纹 | 钢丝硬度超标、模具磨损 | 来料硬度检测 + 模具寿命预警 |
| 头部偏心 | 模具对中不良 | 模具安装导向销 + 首件三坐标检测 |
| 杆部弯曲 | 送料机构磨损 | 导轨间隙定期校准 + 弯曲自动检测 |
| 表面压伤 | 模具表面缺陷 | 模具使用前检查 + 表面粗糙度标准 |
| 尺寸超差 | 模具磨损、参数漂移 | SPC 在线监控 + 自动补偿 |
