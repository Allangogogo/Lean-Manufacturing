# PDCA循环（PDCA Cycle）

## 工具名称

- **中文**：PDCA循环 / 戴明循环 / 管理循环
- **英文**：PDCA Cycle / Deming Cycle / Shewhart Cycle / Plan-Do-Check-Act
- **日文**：PDCAサイクル / デミングサイクル

## 定义与目的

PDCA循环是由美国质量管理专家沃特·阿曼德·休哈特（Walter A. Shewhart）首先提出，后由爱德华兹·戴明（W. Edwards Deming）在日本推广并普及的管理方法。因此也被称为"戴明循环"或"休哈特循环"。

PDCA是**Plan（计划）→ Do（执行）→ Check（检查）→ Act（行动/处理）**四个阶段的迭代循环。它是持续改善的基本方法论，适用于从个人工作改进到组织战略管理的所有层面。

**核心目的**：

1. **系统化改善**：将改善活动组织为结构化的循环过程
2. **持续改进**：每完成一个循环，解决问题并设定更高的目标
3. **防止再发**：通过标准化将成功的经验固化，防止问题复发
4. **数据驱动**：每个阶段都以事实和数据为基础
5. **全员参与**：从高层到一线员工都可以使用PDCA方法

**PDCA的本质**：

PDCA不是一次性的线性过程，而是**螺旋上升的循环**。每完成一个循环，组织的能力和绩效就提升一个层级，然后在新的层级上开始下一个循环。

```
       ┌─────────┐
       │  Plan   │──→ 设定目标和方法
       └────┬────┘
            ↓
       ┌─────────┐
       │   Do    │──→ 按计划执行
       └────┬────┘
            ↓
       ┌─────────┐
       │  Check  │──→ 检查结果与目标的差距
       └────┬────┘
            ↓
       ┌─────────┐
       │   Act   │──→ 标准化成功经验 / 修正方案
       └────┬────┘
            ↓
       进入下一个PDCA循环（更高层级）
```

## 关键原则

### 原则一：计划先行

"磨刀不误砍柴工"。PDCA强调在行动之前充分准备——理解问题、分析原因、制定方案、预见风险。没有充分计划的执行往往事倍功半。

### 原则二：小规模试验

Do阶段不主张大规模推行，而是先在小范围内试验。通过小规模试验验证方案的可行性，降低全面推行的风险。

### 原则三：基于事实和数据

Check阶段必须用数据和事实来评判结果，而非主观感觉。"感觉效果不错"不是Check，"不良率从2000ppm降至300ppm"才是Check。

### 原则四：标准化是闭环的关键

Act阶段的标准化是PDCA循环闭环的关键。如果成功的经验没有标准化，下次遇到同样的问题还会重蹈覆辙。

### 原则五：永不停止

PDCA是一个持续的循环，没有终点。每完成一个循环，就设定新的目标，开始下一个循环。

### 原则六：大小循环嵌套

组织层面有大PDCA循环（如年度质量改善），部门层面有中PDCA循环（如季度工艺优化），个人层面有小PDCA循环（如每日工作改进）。大循环包含小循环，相互支撑。

## 每个阶段的详细活动

### Plan（计划）阶段

Plan是PDCA循环的起点，也是最关键的阶段。计划的质量直接决定了后续执行和改善的效果。

**详细活动**：

1. **识别问题/机会**
   - 从数据中发现问题（如不良率上升、效率下降）
   - 从Gemba Walk中发现改善机会
   - 从客户需求中发现改进方向
   - 从标杆对比中发现差距

2. **分析现状**
   - 收集相关数据
   - 绘制现状图表（趋势图、帕累托图等）
   - 到现场确认实际情况（现地现物）
   - 确定问题的范围和影响

3. **设定目标**
   - 明确改善的目标值（SMART原则）
   - 设定目标达成的时间期限
   - 定义成功的衡量标准

4. **分析原因**
   - 使用5Why分析追溯根本原因
   - 使用鱼骨图系统分析可能原因
   - 用数据验证根本原因

5. **制定对策**
   - 针对根本原因制定对策
   - 评估对策的可行性和风险
   - 制定实施计划（5W1H：What/Who/When/Where/Why/How）
   - 确定所需的资源

**Plan阶段的输出**：完整的计划文档，包括问题描述、目标、根因、对策、实施计划。

### Do（执行）阶段

Do阶段按照计划实施对策。

**详细活动**：

1. **准备实施**
   - 确认资源到位（人员、物料、设备）
   - 培训相关人员
   - 准备所需的文件和工具

2. **小规模试验**
   - 在小范围内试行对策
   - 记录试验过程中的数据和观察
   - 收集操作者的反馈

3. **全面实施**
   - 试验成功后全面推行
   - 按照计划的时间节点推进
   - 记录实施过程中的偏差和调整

**Do阶段的关键要求**：
- 严格按照计划执行（Plan的忠实执行）
- 如需调整，应记录调整原因和影响
- 收集过程数据，为Check阶段提供依据

### Check（检查）阶段

Check阶段验证实施效果是否达到预期目标。

**详细活动**：

1. **收集结果数据**
   - 按照Plan阶段定义的衡量标准收集数据
   - 对比实施前后的数据
   - 与目标值进行比较

2. **分析效果**
   - 目标是否达成？
   - 对策是否有效？
   - 是否产生了副作用？
   - 是否有意外的正面效果？

3. **总结经验**
   - 哪些对策有效？为什么有效？
   - 哪些对策无效？为什么无效？
   - 过程中遇到了什么问题？
   - 有哪些可以改进的地方？

**Check阶段的常见结果**：

| 结果类型 | 说明 | 下一步 |
|---------|------|--------|
| 完全达标 | 目标100%达成 | 进入Act阶段标准化 |
| 部分达标 | 目标达成70-99% | 分析差距原因，微调后继续 |
| 未达标 | 目标达成<70% | 回到Plan阶段重新分析 |
| 负面效果 | 产生了副作用 | 分析副作用原因，调整方案 |

### Act（行动/处理）阶段

Act阶段将成功的经验标准化，对未解决的问题启动新的PDCA循环。

**详细活动**：

1. **标准化成功经验**
   - 更新标准作业指导书（SOP）
   - 更新设备维护标准
   - 更新质量检验标准
   - 培训相关人员
   - 横展到其他类似工序/产品

2. **处理遗留问题**
   - 分析未达成目标的原因
   - 调整对策或重新制定方案
   - 将遗留问题纳入下一个PDCA循环

3. **总结和分享**
   - 编写改善报告
   - 在团队会议上分享经验
   - 记录到组织知识库

## PDCA与持续改善的关系

PDCA是持续改善（Kaizen）的方法论载体。持续改善的理念通过PDCA循环来实现：

```
持续改善（Kaizen）的理念
    ↓
通过PDCA循环来实现
    ↓
每个PDCA循环解决一个问题
    ↓
循环不断，改善不断
    ↓
组织能力螺旋上升
```

**PDCA在不同层级的应用**：

| 层级 | PDCA循环周期 | 典型应用 |
|------|------------|---------|
| 战略层 | 年度 | 年度质量目标、产能规划 |
| 战术层 | 季度/月度 | 工艺优化、效率提升 |
| 执行层 | 周/日 | 日常问题解决、班组改善 |
| 操作层 | 小时/即时 | 操作方法改进、异常处理 |

## 产品日常改善的PDCA应用

### 案例一：机加工工序效率提升的PDCA

**Plan（计划）**：
- 问题：机加工工序OEE仅为62%，目标提升至80%
- 分析：停机时间占比25%（其中换型占15%，故障占10%）
- 根因：换型时间长（平均45分钟），设备预防性维护不足
- 对策：实施SMED缩短换型时间，建立TPM制度
- 目标：3个月内OEE从62%提升至80%

**Do（执行）**：
- 第1-2周：视频记录换型过程，分析内外作业
- 第3-4周：实施SMED改善（内外分离、快速锁紧）
- 第5-8周：建立TPM日常点检和定期维护制度
- 第9-12周：巩固和优化

**Check（检查）**：
- 换型时间：45分钟 → 12分钟（达成目标<15分钟）
- 设备故障率：月均3次 → 月均0.5次
- OEE：62% → 78%（接近但未达80%目标）
- 分析：性能率仍有提升空间，节拍时间偏慢

**Act（行动）**：
- 标准化：SMED标准换型程序纳入SOP，TPM制度正式运行
- 遗留问题：性能率提升纳入下一个PDCA循环
- 横展：将SMED方法推广到精加工工序

### 案例二：包装区物料损耗降低的PDCA

**Plan**：
- 问题：包装区每月损耗率2.5%（标准<0.5%）
- 分析：主要损耗来自混料和数量偏差
- 对策：建立颜色编码系统+自动计数称重复核

**Do**：
- 第1周：实施颜色编码
- 第2周：安装自动计数和称重系统
- 第3-4周：培训操作者并试运行

**Check**：
- 损耗率：2.5% → 0.3%（达成目标）

**Act**：
- 标准化包装区操作SOP
- 横展到仓库发料区

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 改善周期 | 从启动PDCA到关闭的平均天数 | ≤60天 | PDCA的效率 |
| PDCA完成率 | 按时完成的PDCA循环数/计划数 × 100% | ≥90% | 执行力 |
| 目标达成率 | 达到目标的PDCA项目比例 | ≥80% | PDCA的有效性 |
| 标准化率 | 已标准化的成功经验/总成功经验 × 100% | ≥90% | 知识固化 |
| 问题复发率 | 已解决的问题再次发生的比例 | ≤10% | 标准化的有效性 |
| 改善提案数 | 每月提交的改善提案数 | 持续增长 | 全员参与度 |
| 改善提案实施率 | 已实施的提案/总提案数 × 100% | ≥60% | 改善文化 |
| PDCA层级覆盖 | 实施PDCA的部门/团队比例 | ≥80% | PDCA的普及度 |

## 常见误区

### 误区一：PDCA就是做事的流程

**错误理解**：PDCA就是"先想好再做，做完检查一下"的做事方法。

**正确认知**：PDCA是持续改善的系统方法论，强调的是循环和迭代。每次循环都在前一次的基础上提升，而不是重复做同样的事。

### 误区二：Do阶段最重要

**错误理解**：计划不如变化，重要的是快速行动。

**正确认知**：Plan阶段的质量决定了整个循环的成败。"花80%的时间计划，20%的时间执行"是PDCA的经验法则。没有充分计划的执行往往导致返工和浪费。

### 误区三：Check就是看结果

**错误理解**：执行完了看看结果好不好就行了。

**正确认知**：Check不仅是看结果是否达标，更重要的是分析为什么达标或为什么不达标。理解因果关系才能为Act阶段提供有效的改进方向。

### 误区四：Act就是写总结

**错误理解**：Act阶段就是写一份总结报告。

**正确认知**：Act的核心是标准化和横展。成功的经验必须固化为标准，否则问题会复发。总结报告只是Act的一部分，更重要的是更新标准、培训人员、推广经验。

### 误区五：PDCA只适用于大项目

**错误理解**：只有大的改善项目才需要走完整的PDCA流程。

**正确认知**：PDCA适用于所有层级的改善活动。每天的工作改进、每个小问题的解决都可以用PDCA方法。事实上，大量小PDCA循环的积累才是持续改善的真正力量。
