# 现场走动（Gemba Walk）

## 工具名称

- **中文**：现场走动 / 现场巡视 / 现场管理
- **英文**：Gemba Walk / Go and See / Management by Walking Around
- **日文**：現場（げんば）/ 現場歩行（げんばほこう）

## 定义与目的

Gemba（现场）是日语"实地、真实场所"的意思。在制造业中，Gemba特指实际进行生产工作的场所——车间、产线、工位。Gemba Walk 是管理者定期到现场进行观察、学习和指导的管理活动。

Gemba Walk 的核心理念是"大野圆圈"（Ohno Circle）——丰田创始人之一大野耐一会站在生产现场，画一个圆圈，站在里面观察生产过程，直到发现浪费和改善机会。

**核心目的**：

1. **学习和理解**：亲眼看到实际工作如何进行，而非仅依赖报告和数据
2. **发现问题**：通过观察识别浪费、异常和改善机会
3. **支持和指导**：帮助一线员工解决问题，提供资源支持
4. **培养人才**：通过现场互动培养员工的问题意识和改善能力
5. **建立信任**：管理者亲临现场传递"重视现场"的信号

**Gemba Walk vs 传统巡视的本质区别**：

| 维度 | 传统巡视 | Gemba Walk |
|------|---------|------------|
| 目的 | 检查和监督 | 学习和指导 |
| 态度 | "你们做得对不对？" | "我能帮你什么？" |
| 行为 | 指手画脚、批评指责 | 观察、提问、倾听 |
| 频率 | 偶尔、无规律 | 定期、持续 |
| 结果 | 员工紧张、隐瞒问题 | 员工主动暴露问题、参与改善 |
| 关注点 | 结果（数字好不好） | 过程（事情怎么做） |

## 关键原则

### 原则一：去现场，看现实

**现地现物（Genchi Genbutsu）** 是Gemba Walk的核心。不要坐在办公室看报表做决策，要亲自到现场看实物、了解实际情况。

管理者应该能够回答：这个工序的节拍时间是多少？这个工位的在制品有多少？这台设备的OEE是多少？如果不能回答，说明去现场不够。

### 原则二：学习和指导，非检查和批评

Gemba Walk 的目的不是抓现行、找问题、批评人。如果员工因为管理者的到来而紧张，说明Gemba Walk做错了。正确的做法是让员工感到支持和信任，主动分享他们遇到的问题和想法。

### 原则三：按标准观察

Gemba Walk 不是漫无目的的闲逛。应使用结构化的观察方法（如4M观察法），按照标准化的检查要点进行观察。

### 原则四：关注过程，而非仅关注结果

结果数据（如产量、不良率）是过去的反映。Gemba Walk 关注的是产生这些结果的过程——操作方法、设备状态、物料流转、安全状况等。改善过程才能改善结果。

### 原则五：即时行动

发现的问题应即时处理或记录，并在约定时间内跟进。如果反复走动发现问题但从不解决，员工会失去参与的信心。

### 原则六：持续和规律

Gemba Walk 应该是日常管理的一部分，而非偶尔为之。建议每天至少一次，每次30-60分钟，形成规律。

## 4M观察法

4M是Gemba Walk 最经典的观察框架，涵盖生产过程的四个核心要素：

### 人（Man）

| 观察要点 | 具体内容 |
|---------|---------|
| 操作标准化 | 操作者是否按标准作业执行？有无偏离？ |
| 技能水平 | 操作者是否具备所需技能？是否需要培训？ |
| 安全行为 | 操作者是否佩戴劳保用品？操作是否安全？ |
| 精神状态 | 操作者是否疲劳？注意力是否集中？ |
| 人员配置 | 每个工位的人员是否合理？是否有等待或过载？ |

### 机（Machine）

| 观察要点 | 具体内容 |
|---------|---------|
| 设备状态 | 设备运行是否正常？有无异常振动、噪音、温度？ |
| 日常点检 | 操作者是否执行了日常点检？记录是否完整？ |
| 安全防护 | 设备安全防护装置是否完好？有无被拆除或绕过？ |
| 换型状态 | 换型工具和物料是否准备就绪？ |
| 异常记录 | 设备异常记录是否完整？是否及时处理？ |

### 料（Material）

| 观察要点 | 具体内容 |
|---------|---------|
| 物料标识 | 物料标识是否清晰？规格、批号、状态是否明确？ |
| 物料存放 | 物料存放是否规范？有无混料风险？ |
| 在制品数量 | 各工位在制品数量是否合理？有无堆积？ |
| 不良品处理 | 不良品是否及时隔离？标识是否清楚？ |
| 物料流转 | 物料流转是否顺畅？有无等待或搬运浪费？ |

### 法（Method）

| 观察要点 | 具体内容 |
|---------|---------|
| 作业标准 | 作业指导书是否在现场？是否是最新版本？ |
| 工艺参数 | 工艺参数是否在规定范围内？ |
| 质量控制 | 关键质量特性的控制方法是否有效？ |
| 异常处理 | 异常处理流程是否清晰？操作者是否理解？ |
| 持续改善 | 现场是否有改善迹象？改善提案的执行情况？ |

## 八大浪费识别（DOWNTIME）

Gemba Walk 的核心任务之一是识别八大浪费。DOWNTIME是八大浪费的英文首字母缩写：

| 浪费类型 | 英文 | 紧固件行业典型表现 |
|---------|------|------------------|
| **D** - Defects（缺陷） | 不良品 | 冷镦头部开裂、螺纹烂牙、镀层脱落 |
| **O** - Overproduction（过量生产） | 多生产 | 超过客户订单的生产量，导致库存积压 |
| **W** - Waiting（等待） | 空闲等待 | 等待模具、等待检验、等待物料 |
| **N** - Non-utilized talent（未利用的才能） | 人才浪费 | 操作者的改善建议未被采纳 |
| **T** - Transportation（搬运） | 不必要的搬运 | 物料在车间内多次搬运、长距离搬运 |
| **I** - Inventory（库存） | 过多库存 | 在制品堆积、成品库存过高 |
| **M** - Motion（动作） | 不必要的动作 | 弯腰取工具、走远路取物料 |
| **E** - Extra-processing（过度加工） | 过度加工 | 过高的表面粗糙度要求、不必要的全检 |

## 实现步骤

### 第一步：制定Gemba Walk计划

1. 确定走动频率（建议每天至少一次）
2. 确定走动路线（覆盖所有关键工序）
3. 确定每次走动的时间（建议30-60分钟）
4. 确定参与人员（管理者 + 班组长 + 相关职能人员）
5. 准备观察工具（检查表、相机、笔记本）

### 第二步：设计走动路线

**紧固件工厂Gemba Walk路线示例**：

```
起点：车间入口
→ 1. 钢丝放线区（检查钢丝规格、库存、标识）
→ 2. 冷镦区（检查设备状态、操作标准化、在制品）
→ 3. 搓丝区（检查螺纹质量、换型状态、防错装置）
→ 4. 热处理区（检查炉温记录、首件检验、安全防护）
→ 5. 表面处理区（检查镀层质量、环保排放、物料流转）
→ 6. 检验区（检查检验标准、不良品处理、质量数据）
→ 7. 包装区（检查包装数量、标签、成品库存）
→ 8. 模具存放区（检查模具状态、维护记录）
终点：回到车间入口
```

### 第三步：执行走动观察

1. 按照走动路线逐一观察
2. 使用4M观察法和检查表进行系统观察
3. 与操作者交流，倾听他们的想法和问题
4. 记录发现的问题和改善机会
5. 即时处理简单问题，复杂问题记录后跟进

**交流技巧**：
- 多问开放式问题："这个工序你遇到什么困难？"
- 多听少说：80%时间倾听，20%时间提问
- 表达感谢："谢谢你告诉我这个问题"
- 避免指责："这个事情为什么会这样？"而非"你怎么搞的？"

### 第四步：记录和跟进

1. 每次Gemba Walk后填写走动记录
2. 分类整理发现的问题（紧急/重要/一般）
3. 制定行动计划和责任人
4. 在下次Gemba Walk时回顾上次问题的闭环情况
5. 定期汇总Gemba Walk数据，识别趋势

**Gemba Walk记录表**：

| 日期 | 区域 | 发现问题 | 类别 | 责任人 | 计划完成日期 | 状态 |
|------|------|---------|------|--------|------------|------|
| 04/30 | 冷镦 | M10冲头磨损未更换 | 设备 | 张三 | 04/30 | 已完成 |
| 04/30 | 搓丝 | 在制品堆积超过标准 | 库存 | 李四 | 05/01 | 进行中 |
| 04/30 | 热处理 | 炉温记录缺失1小时 | 方法 | 王五 | 04/30 | 已完成 |

### 第五步：持续改善

1. 每周回顾Gemba Walk数据
2. 识别高频问题区域和类型
3. 制定系统性改善方案
4. 评估Gemba Walk的有效性
5. 调整走动路线和观察重点

## 紧固件工厂走动路线和检查要点

### 路线一：冷镦区检查要点

| 检查项目 | 正常标准 | 异常表现 | 处理方式 |
|---------|---------|---------|---------|
| 钢丝规格 | 与生产计划一致 | 规格不符 | 立即停止，更换钢丝 |
| 冲头状态 | 磨损在允许范围内 | 冲头裂纹或严重磨损 | 更换冲头 |
| 产品头部尺寸 | 在公差范围内 | 超差 | 调整设备或停机 |
| 安全防护 | 护罩完好 | 护罩缺失或打开 | 恢复安全防护 |
| 在制品数量 | ≤标准量（如200件） | 超标 | 调整生产节奏 |
| 润滑状态 | 润滑正常 | 润滑不足 | 补充润滑 |

### 路线二：搓丝区检查要点

| 检查项目 | 正常标准 | 异常表现 | 处理方式 |
|---------|---------|---------|---------|
| 搓丝滚轮 | 状态良好 | 磨损或崩齿 | 更换滚轮 |
| 螺纹质量 | 通止规检测合格 | 通止规异常 | 调整或更换滚轮 |
| 通止规状态 | 在校准有效期内 | 过期或损坏 | 送检或更换 |
| 防错装置 | 正常运行 | 失灵 | 修复防错装置 |
| 产品长度 | 在公差范围内 | 超差 | 调整送料机构 |

### 路线三：热处理区检查要点

| 检查项目 | 正常标准 | 异常表现 | 处理方式 |
|---------|---------|---------|---------|
| 炉温 | 在工艺要求范围内 | 偏差超限 | 调整炉温 |
| 网带速度 | 在工艺要求范围内 | 偏差超限 | 调整网带速度 |
| 炉温记录 | 连续完整 | 记录中断 | 检查记录仪 |
| 首件硬度 | 在标准范围内 | 不合格 | 调整工艺参数 |
| 淬火液温度 | 在工艺要求范围内 | 偏差超限 | 调整冷却系统 |
| 消防设施 | 完好可用 | 缺失或失效 | 立即恢复 |

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 走动频率 | 每周Gemba Walk次数 | ≥5次（每天1次） | 管理者的现场参与度 |
| 每次走动时间 | 平均每次走动的持续时间 | 30-60分钟 | 走动的深度 |
| 发现问题数 | 每次走动发现的问题数量 | 不追求数量，追求质量 | 问题发现能力 |
| 改善行动数 | 由Gemba Walk触发的改善行动数 | 持续增长 | Gemba Walk的影响力 |
| 问题关闭率 | 已关闭问题/总发现问题 × 100% | ≥90% | 问题解决的闭环性 |
| 问题平均关闭时间 | 从发现到关闭的平均天数 | ≤7天 | 问题解决的效率 |
| 重复问题率 | 重复出现的问题/总问题数 × 100% | ≤10% | 根本对策的有效性 |
| 员工参与度 | 主动提出改善建议的员工比例 | ≥50% | Gemba Walk对员工参与的促进 |

## 常见误区

### 误区一：Gemba Walk是检查和监督

**错误理解**：管理者去现场是为了检查员工有没有偷懒、操作对不对。

**正确认知**：Gemba Walk的目的是学习和指导。如果员工因为你的到来而紧张，说明你把它做成了"检查"。正确的Gemba Walk应该让员工感到被支持，主动分享问题和想法。

### 误区二：发现问题当场批评

**错误理解**：在现场发现问题应该当场指出来、批评责任人。

**正确认知**：当场批评会让员工产生抵触情绪，以后会隐瞒问题。正确的做法是：先了解情况（为什么这样？有什么困难？），然后一起讨论解决方案，最后提供支持。

### 误区三：Gemba Walk只是高层的事

**错误理解**：只有总经理、厂长才需要做Gemba Walk。

**正确认知**：Gemba Walk适用于所有层级的管理者。班组长每天在自己的区域内走动是最基层的Gemba Walk，车间主任、质量经理、生产经理都应该有各自的Gemba Walk路线。

### 误区四：Gemba Walk不需要准备

**错误理解**：随便到现场转转就是Gemba Walk。

**正确认知**：有效的Gemba Walk需要准备——了解当前的生产计划、质量数据、设备状态，准备好观察检查表和记录工具。没有准备的走动容易流于形式。

### 误区五：走动后不跟进

**错误理解**：走动时记了一堆问题，回去后就忘了。

**正确认知**：Gemba Walk的价值在于发现问题后的行动。如果发现问题不跟进、不解决，员工会认为走动只是走过场，失去参与的信心。
