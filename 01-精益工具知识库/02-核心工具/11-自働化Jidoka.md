# 自働化（Jidoka）

## 工具名称

- **中文**：自働化 / 自働化 / 人字旁的自动化
- **英文**：Jidoka / Autonomation / Automation with a Human Touch
- **日文**：自働化（じどうか）

## 定义与目的

自働化是丰田生产系统的两大支柱之一（另一个是准时化JIT）。"自働化"的"働"字特意加上了人字旁，强调的是**带有人类智慧的自动化**——设备不仅能自动运行，还能自动检测异常、自动停止、自动通知人员介入。

这与普通的"自动化"（Automation）有本质区别。普通自动化是设备按照预设程序运行，即使出现异常也继续运转，直到操作者发现并干预。自働化则赋予设备"判断力"——当异常发生时，设备自动停止，防止不良品产生或设备损坏。

**核心目的**：

1. **防止不良品流入下工序**：异常发生时立即停止，不让不良品继续产生
2. **保护设备和模具**：异常停机避免设备在异常状态下继续运行导致损坏
3. **实现人机分离**：设备自动监控异常，操作者可以从"看管设备"变为"多工序操作"
4. **即时暴露问题**：每次停机都是改善的机会，让隐藏的问题浮出水面
5. **提升首次合格率**：通过源头质量控制，减少过程变异

**自働化与自动化的本质区别**：

| 维度 | 自动化（Automation） | 自働化（Jidoka） |
|------|---------------------|-----------------|
| 核心特征 | 设备自动运行 | 设备自动运行 + 自动检测异常 |
| 异常处理 | 设备继续运行，等待人工干预 | 设备自动停止，等待人工处理 |
| 质量控制 | 依赖终检 | 源头控制，过程内保证质量 |
| 人员角色 | 看管设备运行 | 监控多台设备，处理异常 |
| 异常暴露 | 异常被掩盖 | 异常被即时暴露 |
| 设备设计 | 追求不停机 | 追求异常时自动停机 |

## 关键原则

### 原则一：异常时立即停机

设备在检测到异常（尺寸超差、温度异常、压力异常、振动异常等）时，应自动停止运行，而不是继续生产不良品。

### 原则二：将判断力赋予设备

通过传感器、检测装置和控制逻辑，使设备具备"判断"产品是否合格、过程是否正常的能力。

### 厇则三：安灯（Andon）系统

异常停机后，通过安灯系统通知相关人员。安灯不仅是报警工具，更是信息传递和问题升级的机制。

### 原则四：人机分离

当设备具备自働化能力后，一名操作者可以同时看管多台设备，从"一人一机"变为"一人多机"。

### 原则五：停机是改善的机会

每次异常停机都不应该被视为"损失"，而是暴露问题、推动改善的机会。通过分析停机原因，消除根本问题，防止再发。

### 原则六：支持而非惩罚

安灯拉绳或停机按钮不应被视为"给车间找麻烦"。操作者主动停机是负责任的表现，应予以鼓励和支持。

## 自働化的实现架构

### 第一层：源头质量控制

在生产过程中设置检测点，在异常产生的第一时间发现并停止：

- **过程内检测**：在线传感器实时检测关键参数
- **自检**：操作者在完成操作后自行检验
- **防错装置**：物理装置阻止不合格品继续流转

### 第二层：异常停机机制

当检测到异常时，设备自动停止：

- **自动停机**：设备检测到异常参数时自动停止
- **异常区域检测**：设备运行在异常区域（如超温、超压）时自动停机
- **计数停机**：达到预设数量或时间时自动停机进行检查

### 第三层：安灯系统

异常停机后，通过安灯系统通知人员：

- **灯号显示**：不同颜色的灯表示不同类型的异常
- **声音报警**：蜂鸣器或语音提示
- **信息显示**：电子看板显示异常位置和类型
- **升级机制**：一定时间内未响应则自动升级

### 第四层：问题响应和解决

人员到达现场，分析原因并解决问题：

- **快速响应**：操作者和班组长在规定时间内到达
- **临时对策**：恢复生产，防止停机时间过长
- **根本对策**：分析根本原因，制定永久对策
- **标准化**：将对策标准化，防止问题再发

## 实现步骤

### 第一步：识别关键检测点

1. 分析每个工序的质量关键特性
2. 识别过程中最容易产生异常的环节
3. 确定需要设置自働化检测的关键点
4. 优先处理高频缺陷和高严重度缺陷

**产品关键检测点示例**：

| 工序 | 关键检测点 | 检测参数 | 异常判定标准 |
|------|-----------|---------|------------|
| 机加工 | 头部直径 | 直径尺寸 | 超出公差 ±0.05mm |
| 机加工 | 外形高度 | 高度尺寸 | 超出公差 ±0.03mm |
| 精加工 | 外径 | 关键尺寸 | 超出公差范围 |
| 精加工 | 通止规 | 量规检测 | 止规通过 = 不合格 |
| 热处理 | 炉温 | 温度 | 偏离设定值 ±10°C |
| 热处理 | 硬度 | 洛氏硬度 | 不在HRC范围内 |
| 电镀 | 镀层厚度 | 厚度 | 低于最低要求 |
| 电镀 | 盐雾时间 | 耐蚀性 | 不达标准要求 |

### 第二步：设计自働化装置

根据检测点的要求，设计相应的自働化装置：

**机械式自働化**：
- 限位挡块：物理检测尺寸
- 量规：在线检测尺寸
- 弹簧式检测：检测力或压力

**电气式自働化**：
- 光电传感器：检测有无、位置
- 激光测径仪：非接触式尺寸检测
- 热电偶：温度检测
- 压力传感器：力或压力检测

**视觉式自働化**：
- 工业相机：表面缺陷检测
- 机器视觉：尺寸自动测量
- OCR：标识和编号识别

### 第三步：设计安灯系统

1. **灯号设计**：
   - 绿色：正常运行
   - 黄色：需要注意（小异常，可自行处理）
   - 红色：停机异常（需要帮助）
   - 蓝色：物料请求
   - 白色：质量确认

2. **响应流程**：
   ```
   操作者拉灯 → 班组长3分钟内到达 → 5分钟内判断
   → 可恢复：临时对策恢复生产 → 记录 → 分析
   → 不可恢复：设备/工艺人员介入 → 15分钟内到场
   → 30分钟未解决：升级至主管
   → 60分钟未解决：升级至经理
   ```

3. **安灯看板**：
   - 显示当前各工位状态
   - 记录每次安灯的时间、原因、响应时间、解决时间
   - 统计安灯频次和类型分布

### 第四步：人机分离实施

1. **评估设备自働化水平**：确定哪些设备已经具备自働化能力
2. **规划操作者看管范围**：根据设备自働化水平，确定一人看管几台设备
3. **设计巡回路线**：优化操作者的巡回路线，确保能及时响应
4. **培训操作者**：培训操作者掌握多设备操作和异常处理能力

### 第五步：建立问题解决机制

1. **每日安灯回顾**：每天回顾安灯记录，分析高频异常
2. **问题升级机制**：明确不同级别异常的响应时间和升级路径
3. **根本原因分析**：对重复发生的异常进行5Why分析
4. **对策实施和验证**：实施对策并验证效果
5. **标准化和横展**：将成功的对策标准化并推广到其他设备/产线

### 第六步：持续改善

1. 定期评估自働化覆盖率
2. 分析安灯数据，识别改善趋势
3. 逐步提升设备自働化水平
4. 从"自动停机"向"预防性自働化"进化

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 安灯拉动次数 | 每日/每班安灯被拉动的总次数 | 趋势下降（但初期可能上升） | 反映异常发生的频率 |
| 安灯响应时间 | 从拉灯到人员到达现场的时间 | ≤3分钟 | 响应速度 |
| 安灯解决时间 | 从拉灯到问题解决、恢复生产的时间 | ≤15分钟 | 问题解决效率 |
| 异常停机时间 | 因异常停机的总时间/总运行时间 × 100% | 持续降低 | 自働化的效果指标 |
| 首次合格率（FPY） | 首次检验合格数/总检验数 × 100% | ≥99% | 源头质量控制效果 |
| 不良品流出率 | 流出到下工序或客户的不良品数/总生产数 × 100% | <0.1% | 自働化拦截效果 |
| 一人看管设备数 | 每名操作者平均看管的设备数量 | 逐步增加 | 人机分离的进展 |
| 自働化覆盖率 | 已实施自働化的检测点/总检测点 × 100% | ≥80% | 自働化实施的完整性 |
| 问题解决率 | 已解决的安灯问题/总安灯问题 × 100% | ≥90% | 问题解决的闭环率 |
| 异常再发率 | 同一问题重复发生的次数/总问题数 × 100% | <5% | 根本对策的有效性 |

## 制造业具体应用案例

### 案例一：精加工设备尺寸检测自働化停机

**背景**：精加工是产品精密成型的关键工序。传统方式下，操作者定期抽检尺寸质量，但两次抽检之间产生的不良品会流入下工序。

**问题**：
- 精加工刀具磨损导致外径逐渐偏大
- 人工抽检频率为每30分钟一次
- 在30分钟的间隔内，可能产生200-500件不良品
- 不良品流入热处理后才发现，造成批量损失

**自働化改善方案**：

1. **在线量规检测**：
   - 精加工设备出料口安装自动量规检测机
   - 每件产品自动通过通规和止规检测
   - 通规通过 + 止规不通过 = 合格品，流入下工序
   - 止规通过 = 不合格品，自动分拣到不良品箱

2. **异常自动停机**：
   - 连续3件止规通过（不合格） → 设备自动停止
   - 安灯亮红灯，蜂鸣器报警
   - 显示屏提示"精加工不良，连续3件不合格"

3. **刀具磨损预警**：
   - 统计连续合格品数量
   - 当合格率从99.9%下降到99.5%时，黄灯预警（提示刀具可能磨损）
   - 当合格率低于99%时，红灯停机（提示更换刀具）

**改善效果**：

| 指标 | 改善前 | 改善后 |
|------|--------|--------|
| 不良品流出率 | 2.5% | 0% |
| 每次不良品批量损失 | 200-500件 | 3件（最大） |
| 质检人员 | 2人/班 | 1人/班（巡检） |
| 客诉率 | 15次/年 | 0次/年 |

### 案例二：机加工设备外形尺寸自働化

**背景**：机加工设备生产法兰凸缘工件，外形尺寸是关键质量特性。

**自働化方案**：

1. **激光在线测径**：机加工出料口安装激光测径仪，实时测量头部直径
2. **SPC实时监控**：自动绘制X-bar R控制图，当点超出控制限时自动停机
3. **趋势预警**：当连续7点呈上升或下降趋势时，黄灯预警
4. **首件强制检测**：每次换型后的前10件必须100%检测

**效果**：机加工工序的Cpk从1.0提升至1.67，外形尺寸不良率从0.8%降至0.05%。

### 案例三：热处理炉温自働化监控

**背景**：网带式热处理炉是产品淬火和回火的关键设备。炉温控制直接影响产品力学性能。

**自働化方案**：

1. **多点温度监控**：炉膛内设置5个温度监测点，实时监控温度分布
2. **超温/低温保护**：温度超出设定范围 ±15°C 时自动报警，超出 ±25°C 时自动切断加热电源
3. **网带速度监控**：监控网带速度，异常时自动停机（防止产品在炉内停留时间过长或过短）
4. **首件硬度检测**：每班开班和每次参数调整后的首件必须做洛氏硬度检测
5. **温度曲线记录**：每批产品的温度曲线自动记录并存档

**效果**：热处理批量报废事件从每年2-3次降至零，产品硬度合格率从98.5%提升至99.8%。

## 常见误区

### 误区一：自働化就是自动化

**错误理解**：自働化就是买自动化设备。

**正确认知**：自働化的核心是"异常时自动停止"，而非"自动运行"。很多工厂买了昂贵的自动化设备，但没有异常检测和停机功能，这不是自働化。

### 误区二：停机是损失

**错误理解**：自働化导致频繁停机，降低了生产效率。

**正确认知**：短期看，停机确实会损失一些产量。但长期看，自働化减少了不良品、返工、客诉、设备损坏等更大的损失。而且每次停机都是改善的机会。

### 误区三：操作者拉安灯是给车间找麻烦

**错误理解**：安灯拉绳是给管理者施压的工具，拉了会被批评。

**正确认知**：自働化文化强调"停机是好事"——它暴露了问题，防止了更大的损失。管理者应鼓励操作者主动拉灯，而非惩罚。

### 误区四：自働化可以替代质量检验

**错误理解**：有了自働化就不需要质量部门了。

**正确认知**：自働化是过程质量控制的重要手段，但终检、型式检验、来料检验等仍然需要。自働化减少了对终检的依赖，但不能完全替代。

### 误区五：自働化一步到位

**错误理解**：所有工序都要立刻实施自働化。

**正确认知**：自働化应分步实施，优先在关键质量特性和高频缺陷的工序实施，逐步扩大覆盖范围。
