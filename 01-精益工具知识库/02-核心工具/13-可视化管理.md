# 可视化管理（Visual Management）

## 工具名称

- **中文**：可视化管理 / 目视管理 / 可视化控制
- **英文**：Visual Management / Visual Control / Visual Workplace
- **日文**：可視化管理（かしかんり）/ 目で見る管理（めでみるかんり）

## 定义与目的

可视化管理是通过视觉信号（颜色、标识、看板、灯光、图表等）使工作现场的状态、异常、标准和信息一目了然的管理方法。其核心理念是：**让任何人走到现场，都能在30秒内了解当前的状况是正常还是异常。**

可视化管理不是"锦上添花"的装饰，而是精益生产的基础能力。它是5S的延伸，是安灯系统的组成部分，是看板系统的表现形式，是持续改善的信息基础。

**核心目的**：

1. **即时发现异常**：正常与异常的视觉差异让问题无处隐藏
2. **快速传递信息**：无需口头传达或查阅系统，信息直接呈现在现场
3. **减少寻找时间**：工具、物料、文件的定置定位减少寻找浪费
4. **统一理解标准**：可视化标准减少理解偏差和沟通成本
5. **促进自主管理**：操作者能自主判断状态，减少对管理者的依赖
6. **暴露问题**：可视化使隐藏的问题浮出水面，推动持续改善

**可视化管理的成熟度层级**：

| 层级 | 特征 | 示例 |
|------|------|------|
| 第一层：5S基础 | 物品定置定位，标识清晰 | 工具影子板、区域地标线 |
| 第二层：异常可视化 | 正常/异常状态一目了然 | 安灯、设备状态灯 |
| 第三层：绩效可视化 | 关键指标实时呈现 | 生产看板、OEE看板 |
| 第四层：管理可视化 | 管理决策和行动可视化 | A3报告展示、改善跟踪看板 |
| 第五层：文化可视化 | 精益理念和文化可视化 | 改善提案展示、团队荣誉墙 |

## 常用可视化工具

### 工具一：看板（Kanban Board）

看板是可视化管理最经典的应用。通过卡片或电子屏显示任务/物料的状态和数量。

**类型**：
- **生产看板**：显示生产计划和实际完成情况
- **物料看板**：显示物料库存水位和补货信号
- **质量看板**：显示质量指标和异常信息
- **项目看板**：显示改善项目进度

**设计要点**：
- 从左到右或从上到下的流动方向
- 每个阶段有明确的在制品上限
- 异常用红色或特殊标记突出
- 定期更新（至少每班一次）

### 工具二：安灯（Andon）

安灯是通过灯光信号传递异常信息的系统。

**颜色编码标准**：
- **绿色**：设备正常运行
- **黄色**：需要注意（即将缺料、小异常等）
- **红色**：停机异常（设备故障、质量问题等）
- **蓝色**：物料请求（需要补充物料）
- **白色**：质量确认请求

**安灯响应流程**：
```
拉灯/亮灯 → 3分钟内班组长到达 → 5分钟内判断
→ 恢复：临时对策 → 记录 → 后续改善
→ 未恢复：升级 → 设备/工艺人员15分钟内到场
→ 30分钟未解决：升级至主管
```

### 工具三：影子板（Shadow Board）

影子板是将工具的轮廓画在板上，使用后工具必须放回对应位置。缺失的工具一目了然。

**应用场景**：
- 扳手、量具等常用工具的存放
- 模具存放区
- 备件存放

### 工具四：地标线（Floor Marking）

通过不同颜色的地面标线划分区域和通道。

**颜色标准**：
- **黄色**：通道线、区域边界
- **红色**：不良品区、废品区
- **绿色**：合格品区、工作区
- **白色**：工作台、设备定位
- **黄黑相间**：警示区域（设备运动范围、危险区）
- **绿白相间**：行人通道

### 工具五：KPI看板

将关键绩效指标以图表形式展示在车间现场。

**常见KPI看板内容**：
- 小时产量追踪（实际vs目标）
- OEE（设备综合效率）
- 质量指标（不良率、FPY）
- 安全指标（安全事故、近失事件）
- 改善提案数量和实施进度
- 人员出勤情况

### 工具六：标准作业展示

将标准作业指导书（SOP）以可视化方式展示在工位旁。

**设计要点**：
- 图片优先于文字
- 关键参数用大字体和颜色标注
- 正确做法 vs 错误做法的对比
- 放置在操作者的视线高度

## 实现步骤

### 第一步：现场评估

1. 走访生产现场，记录当前的可视化状态
2. 识别信息需求：哪些信息需要传递给谁
3. 识别异常类型：哪些异常需要即时发现
4. 评估现有可视化工具的有效性
5. 确定改善优先级

**现场评估检查清单**：

| 评估项目 | 当前状态 | 目标状态 | 优先级 |
|---------|---------|---------|--------|
| 产线状态（运行/停机） | 不清楚 | 安灯显示 | 高 |
| 小时产量 | 下班后才知道 | 实时显示 | 高 |
| 质量异常 | 发现后才处理 | 即时报警 | 高 |
| 物料状态 | 堆积后才知道 | 看板拉动 | 中 |
| 设备状态 | 故障后才修 | 预防性维护可视化 | 中 |
| 工具存放 | 随意放置 | 影子板定置 | 低 |

### 第二步：设计可视化方案

1. 确定每个可视化工具的位置、尺寸、内容
2. 设计颜色编码标准（全厂统一）
3. 确定更新频率和责任人
4. 选择合适的载体（看板/电子屏/标识牌）

**产品车间可视化布局示例**：


### 第三步：制作和安装

1. 制作看板、标识牌、地标线等可视化工具
2. 按设计位置安装
3. 颜色编码和标识标准化
4. 电子看板系统调试（如有）

### 第四步：培训和推行

1. 培训所有人员理解可视化的含义和使用方法
2. 培训班组长如何更新看板信息
3. 培训操作者如何使用安灯系统
4. 试运行1-2周，收集反馈
5. 根据反馈调整优化

### 第五步：维护和持续改善

1. 确保看板信息的及时更新
2. 定期检查可视化工具的完好性
3. 每月回顾可视化管理的有效性
4. 根据业务变化更新可视化内容
5. 逐步引入电子化和智能化可视化

## 产品车间可视化应用

### 应用一：小时产量追踪

**目的**：实时监控每小时的产量是否达到目标，及时发现产量偏差。

**实施方式**：
- 在每条产线旁设置小时产量追踪板
- 目标值按节拍时间计算（如节拍3秒/件，则每小时目标1200件）
- 每小时由操作者或班组长记录实际产量
- 超出目标范围（±10%）用红色标注

**示例**：

| 时段 | 目标 | 实际 | 达成率 | 状态 |
|------|------|------|--------|------|
| 08:00-09:00 | 1200 | 1180 | 98% | 正常 |
| 09:00-10:00 | 1200 | 1050 | 88% | 异常 |
| 10:00-11:00 | 1200 | 1220 | 102% | 正常 |
| 11:00-12:00 | 1200 | 1190 | 99% | 正常 |

### 应用二：OEE看板

**目的**：展示设备综合效率（OEE）的三个维度：可用性、性能、质量。

**OEE看板内容**：
- 可用率 = (运行时间 - 停机时间) / 运行时间
- 性能率 = (理论周期时间 × 总产量) / 运行时间
- 质量率 = 合格品数 / 总产量
- OEE = 可用率 × 性能率 × 质量率

**目标**：OEE ≥ 85%（世界级水平）

### 应用三：质量警报系统

**目的**：当质量指标超出控制限时，即时报警。

**实施方式**：
- 检验数据实时录入系统
- 系统自动计算不良率、CPK等指标
- 超出控制限时，车间电子屏弹出红色警报
- 同时发送消息给质量主管

### 应用四：设备状态可视化

**目的**：一目了然地了解每台设备的运行状态。

**实施方式**：
- 设备上方安装三色灯（绿/黄/红）
- 电子看板显示设备实时状态
- 设备编号、产品型号、操作者姓名一目了然
- 停机原因用代码显示（如E01=模具更换，E02=设备故障，E03=缺料）

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 异常发现时间 | 从异常发生到被发现的平均时间 | ≤5分钟 | 可视化的核心效果 |
| 信息传递效率 | 从异常发现到相关人员收到信息的时间 | ≤1分钟 | 信息传递速度 |
| 看板更新及时率 | 按时更新的看板数/总看板数 × 100% | ≥98% | 可视化的持续有效性 |
| 安灯响应时间 | 从拉灯到人员到达现场的时间 | ≤3分钟 | 安灯系统的有效性 |
| 工具寻找时间 | 操作者寻找工具的平均时间 | ≤30秒 | 影子板的效果 |
| 5S评分 | 5S审核得分 | ≥90分 | 可视化管理的基础 |
| 目视化覆盖率 | 已实施可视化的区域/总区域 × 100% | ≥80% | 可视化实施的完整性 |
| 异常处理闭环率 | 已处理的异常/总异常 × 100% | ≥95% | 异常管理的闭环 |

## 常见误区

### 误区一：可视化就是贴标签

**错误理解**：可视化管理就是在墙上贴几张图表和标识。

**正确认知**：可视化不仅是贴标签，更是一套信息管理系统。关键是信息的准确性、及时性和可操作性。如果看板上的数据不准确或不及时更新，可视化反而会误导决策。

### 误区二：可视化越多越好

**错误理解**：把所有信息都贴到墙上就是好的可视化。

**正确认知**：信息过载等同于没有信息。可视化管理的原则是"必要信息、一目了然"。过多的图表和标识反而会让人忽视关键信息。

### 误区三：可视化只是给领导看的

**错误理解**：看板和图表是给来参观的领导看的装饰品。

**正确认知**：可视化的首要服务对象是现场操作者和班组长。他们需要通过可视化信息进行日常决策和异常响应。如果操作者不使用，可视化就没有价值。

### 误区四：电子化一定比手工好

**错误理解**：用电子屏替代手工看板就是升级。

**正确认知**：电子化有其优势（自动更新、远程查看），但手工看板也有独特价值（操作者亲手更新信息有助于加深理解和参与感）。选择哪种方式应根据实际需求和条件决定。

### 误区五：可视化管理一劳永逸

**错误理解**：做好了可视化就不需要维护了。

**正确认知**：可视化需要持续维护。看板信息要定期更新，损坏的标识要及时修复，过时的内容要及时清理。否则可视化会逐渐退化，失去作用。
