# 平准化（Heijunka）

## 工具名称

- **中文**：平准化生产 / 均衡化生产
- **英文**：Heijunka / Production Leveling / Production Smoothing
- **日文**：平準化（へいじゅんか）

## 定义与目的

平准化是精益生产的核心支柱之一，指在一定时期内，按照客户需求的节拍时间，对产品的产量和品种进行均衡排产的生产方式。其本质是将不均匀的客户需求转化为平稳的生产计划，避免传统"批量生产"模式下忽高忽低的生产波动。

**核心目的**：

1. **消除生产波动**：避免某些时段超负荷生产、某些时段设备闲置的情况
2. **降低库存水平**：均衡生产使中间在制品库存保持稳定且最低
3. **平滑资源负荷**：人员、设备、物料的需求趋于平稳，减少加班和赶工
4. **缩短交付周期**：稳定的生产节拍使交付时间可预测、可承诺
5. **暴露潜在问题**：均衡的生产节奏让隐藏的浪费和瓶颈无处遁形

**与批量生产的对比**：

| 维度 | 批量生产 | 平准化生产 |
|------|---------|-----------|
| 排产方式 | 按产品种类集中生产 | 按客户需求交替生产 |
| 批量大小 | 大批量（数百至数千） | 小批量（数十件） |
| 换型频率 | 低（每次换型产量大） | 高（频繁换型，每次产量小） |
| 库存水平 | 高（大量在制品和成品库存） | 低（接近客户需求量） |
| 生产波动 | 大（忙闲不均） | 小（平稳节拍） |
| 对异常的暴露 | 掩盖问题 | 暴露问题 |

## 关键原则

### 原则一：节拍时间驱动

节拍时间（Takt Time）是平准化的基准。它不是设备能力，而是客户需求的节奏。

```
节拍时间 = 可用工作时间 / 客户需求量
```

例如：每天可用工作时间 460 分钟（8小时 - 2小时休息），客户需求 9200 件M8螺栓，则：
- 节拍时间 = 460分钟 × 60秒 / 9200件 = 3秒/件

### 原则二：品种均衡

在同一条生产线上，按照产品品种的构成比例交替生产，而非按品种集中批量生产。例如，若客户需要 M8:M10:M12 = 5:3:2 的比例，则生产序列为：M8-M8-M10-M8-M12-M8-M10-M8-M12-M10...

### 原则三：小批量高频次

将大批量拆分为小批量，以更高频率进行生产和换型。这要求换型时间必须大幅缩短（与SMED配合）。

### 原则四：拉动式补货

成品以客户消耗速度被拉动，上游工序以下游消耗速度补充，形成连续的拉动链。

### 原则五：逐步推进

平准化不是一步到位，而是从一条产线、一个产品族开始，逐步扩大范围。

### 原则六：与SMED、看板、自働化协同

平准化需要SMED缩短换型时间、看板实现拉动补货、自働化保证异常即时发现，三者缺一不可。

## 实现步骤

### 第一步：收集需求数据

1. 收集过去 3-6 个月的实际订单数据
2. 按产品品种统计每日/每周需求量
3. 分析需求波动规律（趋势、季节性、随机波动）
4. 确定计划周期内的总需求量和日均需求量

### 第二步：计算节拍时间

1. 确定可用工作时间（扣除计划停机、休息、维护时间）
2. 计算日均需求量
3. 计算节拍时间
4. 验证设备产能是否满足节拍要求

```
可用时间 = 总工作时间 - 计划停机 - 休息时间 - 设备维护时间
日均需求 = 计划周期总需求 / 计划工作天数
节拍时间 = 可用时间 / 日均需求
```

### 第三步：确定产品族和生产比例

1. 按工艺路线将产品分组为产品族
2. 计算各品种在总需求中的比例
3. 确定一个节拍周期内的品种序列
4. 计算每品种在一个节拍周期内的生产数量

**紧固件产品族示例**：

| 产品族 | 包含品种 | 典型工艺 |
|--------|---------|---------|
| 六角螺栓族 | M8/M10/M12/M16 | 冷镦→搓丝→热处理→镀锌 |
| 内六角族 | M6/M8/M10 | 冷镦→攻丝→热处理→发黑 |
| 螺母族 | M8/M10/M12 | 冷镦→攻丝→热处理→镀锌 |
| 垫圈族 | M8/M10/M12 | 冲压→热处理→镀锌 |

### 第四步：构建平准化箱

平准化箱（Heijunka Box）是实现平准化排产的可视化工具：

1. 设计平准化箱的格子结构（行=产品品种，列=时间段）
2. 按生产比例在各格子中放置生产看板（Kanban卡）
3. 确定看板的投放节奏（通常按节拍时间等间隔投放）
4. 建立看板的补充规则

**平准化箱布局示例**（每列代表一个节拍时间3秒）：

```
时间 →  3s    6s    9s    12s   15s   18s   21s   24s   27s   30s
M8    [M8]  [M8]  [M8]  [M8]  [M8]  [M8]  [M8]  [M8]  [M8]  [M8]
M10   [M10]       [M10]       [M10]       [M10]       [M10]      
M12              [M12]              [M12]              [M12]      
```

### 第五步：编制日生产计划

1. 将月度/周度需求分解为日计划
2. 按平准化比例排列每日的品种序列
3. 考虑换型时间和换型顺序优化
4. 与物料供应计划同步（JIT供货）

### 第六步：缩短换型时间（配合SMED）

1. 分析当前换型时间的构成
2. 将内部作业转为外部作业
3. 优化内部作业的效率
4. 将换型时间缩短至节拍时间以内（理想目标：<10分钟）

### 第七步：实施与持续改善

1. 从一条产线试点开始
2. 培训操作人员理解平准化理念和操作方法
3. 建立异常响应机制（安灯系统）
4. 每日回顾平准化执行情况
5. 逐步扩大到更多产线和产品族

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 节拍时间遵守率 | 实际节拍达标数/计划节拍数 × 100% | ≥95% | 衡量生产节奏的稳定性 |
| 生产节拍偏差 | (实际节拍 - 计划节拍)/计划节拍 × 100% | ≤±5% | 节拍波动范围 |
| 日产量偏差率 | (实际产量 - 计划产量)/计划产量 × 100% | ≤±3% | 产量完成的准确性 |
| 在制品库存水平 | 平均在制品数量（件或金额） | 降低30-50% | 平准化的核心收益之一 |
| 成品库存天数 | 成品库存量/日均出货量 | ≤3天 | 成品库存的周转效率 |
| 换型时间 | 从最后一件A产品到第一件B产品的时间 | <10分钟 | 平准化的前提条件 |
| 换型次数 | 每日/每班的换型总次数 | 按计划执行 | 频繁换型是平准化的特征 |
| 加班时间 | 每日加班小时数 | 降低50%以上 | 平准化消除赶工现象 |
| 客户交付准时率 | 准时交付订单数/总订单数 × 100% | ≥98% | 平准化提升交付稳定性 |
| 品种切换效率 | 换型后首件合格率 | ≥99% | 换型质量的衡量 |

## 紧固件行业具体应用案例

### 案例一：M8/M10/M12混合排产优化

**背景**：某紧固件工厂冷镦车间原来按品种集中排产，M8螺栓一次生产5000件，再切换M10生产3000件，最后M12生产2000件。每种产品换型时间约45分钟，导致：

- M8成品库存堆积约2000件（3天用量）
- M12经常缺货，需要紧急赶工
- 冷镦机利用率波动在60%-100%之间

**平准化改善方案**：

1. **需求分析**：M8:M10:M12 = 5:3:2，每日总需求 9200 件
2. **节拍时间**：460分钟 / 9200件 = 3秒/件
3. **换型时间缩短**：通过SMED将换型时间从45分钟缩短至8分钟
4. **平准化序列**：每个循环生产 M8-M8-M8-M8-M8-M10-M10-M10-M12-M12（共10件）
5. **批量设定**：每品种每次生产200件，10个循环后换型

**改善效果**：

| 指标 | 改善前 | 改善后 | 变化 |
|------|--------|--------|------|
| 日产量 | 波动8000-10000件 | 稳定9200件 | 消除波动 |
| 在制品库存 | 5000件 | 1800件 | -64% |
| 成品库存天数 | 5天 | 1.5天 | -70% |
| 加班时间 | 日均2.5小时 | 日均0.5小时 | -80% |
| 客户准时交付率 | 88% | 98% | +10% |

### 案例二：表面处理车间的平准化

**背景**：镀锌车间需要处理来自多条冷镦线的不同规格紧固件，电镀槽容量有限，不同规格的镀层厚度和时间要求不同。

**平准化方案**：

1. 按镀层要求将紧固件分组（如：普通镀锌组、达克罗组、热镀锌组）
2. 同一镀层组内按规格大小交替排产
3. 建立镀锌专用平准化箱，每格代表一个挂具的装载量
4. 冷镦车间的生产节奏与镀锌车间的处理节奏同步

**效果**：镀锌槽利用率从72%提升至89%，在制品等待时间从4小时缩短至1小时。

## 常见误区

### 误区一：平准化等于平均分配

**错误理解**：将总产量除以天数就是平准化。

**正确认知**：平准化不仅是产量的均衡，更重要的是品种的均衡。一天只生产一种产品不是平准化，即使产量是"均衡"的。

### 误区二：平准化要求所有品种同时均衡

**错误理解**：必须在所有产线、所有品种上同时实施平准化。

**正确认知**：平准化是逐步推进的。先从一个产品族、一条产线开始，建立能力后再逐步扩大。

### 误区三：平准化会降低效率

**错误理解**：频繁换型会降低设备利用率，增加成本。

**正确认知**：虽然换型时间会增加，但库存持有成本、加班成本、紧急调度成本的降低通常远大于换型时间的增加。综合成本是下降的。

### 误区四：平准化只适用于重复生产

**错误理解**：只有大批量重复生产的场景才适合平准化。

**正确认知**：紧固件行业天然是重复生产的场景，非常适合平准化。即使品种多、批量小，通过合理的品种组合和节拍设计，也能实现有效平准化。

### 误区五：需求波动大时无法平准化

**错误理解**：客户需求波动太大，无法实施平准化。

**正确认知**：需求波动恰恰是需要平准化的原因。通过成品库存作为缓冲，平准化生产以稳定的节奏补充成品库存，成品库存吸收需求波动。

### 误区六：平准化只是计划部门的事

**错误理解**：平准化排产是计划部门的工作，车间只需执行。

**正确认知**：平准化是全员参与的系统工程。车间需要实现快速换型、设备可靠性和质量稳定性，这些是平准化成功的基础。
