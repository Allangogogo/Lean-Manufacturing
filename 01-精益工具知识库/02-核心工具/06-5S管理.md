# 5S管理

## 工具名称

| 语言 | 名称 |
|------|------|
| 中文 | 5S管理/5S现场管理 |
| 英文 | 5S Workplace Organization |
| 日文 | 5S（整理 Seiri / 整頓 Seiton / 清掃 Seiso / 清潔 Seiketsu / 躾 Shitsuke） |

## 定义与目的

5S是一种起源于日本的现场管理方法，通过对工作现场进行系统性的整理、整顿、清扫、清洁和素养五项活动，创造一个有序、高效、安全、舒适的工作环境。5S是精益生产的基石，为其他所有精益工具的有效运行提供基础条件。

在紧固件制造中，5S确保模具、检具、原材料、半成品、成品等物品都有明确的存放位置和标识，操作员能够快速找到需要的物品，减少寻找浪费，降低混料风险，提升整体效率。

### 核心目的

- **消除浪费**：减少寻找物品、走动、等待等非增值活动
- **提升效率**：物品定置定位，取用快速准确
- **保障质量**：防止混料、误用，减少人为失误
- **确保安全**：消除安全隐患，减少工伤事故
- **改善士气**：创造整洁有序的工作环境，提升员工满意度
- **建立基础**：为标准作业、TPM、看板等精益工具提供实施基础

## 五个S详解

### 第一个S：整理（Seiri）

**定义**：区分工作场所中"需要"和"不需要"的物品，清除非必需品。

**目的**：释放空间，减少干扰，防止误用。

**实施步骤**：

1. **全面盘点**：对工作区域内所有物品进行逐一清点
2. **红牌作战**：对可疑物品（不确定是否需要）贴上红色标签
3. **判定基准**：制定物品需要/不需要的判定标准

| 判定问题 | 处理方式 |
|----------|----------|
| 这件物品是否在日常工作中使用？ | 否 → 移除 |
| 最近一次使用是什么时候？ | 超过3个月 → 评估是否移除 |
| 使用频率如何？ | 极低 → 移至远距离仓库 |
| 是否有重复的物品？ | 是 → 保留最优的，移除多余的 |

4. **处理非必需品**：
   - 移除不需要的物品（报废、转移、退还）
   - 红牌物品移到红牌区集中处理
   - 记录移除物品清单
5. **定期复核**：每月进行一次整理检查，防止不需要的物品重新堆积

**紧固件行业应用**：
- 清除车间内报废的模具和冲头
- 移除过期的工艺文件和作业指导书
- 处理多余的原材料和不合格品
- 清理不再使用的工具和量具

### 第二个S：整顿（Seiton）

**定义**：将需要的物品按规定的位置和方法摆放整齐，做好标识，实现"30秒内找到任何物品"。

**目的**：减少寻找时间，实现可视化管理。

**实施步骤**：

1. **分析物品使用频率**：

| 使用频率 | 存放位置 |
|----------|----------|
| 每小时使用 | 工位旁边/触手可及 |
| 每天使用 | 工位附近/通道两侧 |
| 每周使用 | 车间公共区域 |
| 每月使用 | 仓库指定区域 |
| 半年以上 | 远距离仓库/淘汰 |

2. **确定存放位置**：根据使用频率和工作流程确定最优存放位置
3. **选择存放方法**：使用合适的存放器具（货架、料盒、挂架等）
4. **标识管理**：为每个存放位置制作清晰标识

**定置管理三要素**：
- **定位置**：每件物品有唯一的存放位置
- **定方法**：每件物品有规定的存放方法（直列、叠放、悬挂等）
- **定标识**：每个位置有清晰的标识（名称、编号、图片）

5. **可视化设计**：
   - 使用颜色编码区分不同类别
   - 使用影子板标识工具存放位置
   - 使用轮廓线标示物品摆放区域
   - 使用标识牌标注物品名称和数量

**紧固件行业应用**：
- 模具定置：按产品型号分类存放，标识牌注明型号、规格、库存量
- 检具定置：通止规、卡规等量具按型号分类放在专用量具架上
- 原料区域：不同材质、规格的钢丝分区存放，标识清晰
- 半成品区域：各工序的半成品分区存放，颜色编码区分

### 第三个S：清扫（Seiso）

**定义**：彻底清扫工作场所，清除脏污和垃圾，同时通过清扫发现设备和环境的异常。

**目的**：保持环境整洁，通过清扫发现潜在问题。

**实施步骤**：

1. **制定清扫基准**：

| 项目 | 内容 | 频率 | 负责人 |
|------|------|------|--------|
| 地面 | 清扫铁屑、油污 | 每班 | 操作员 |
| 设备表面 | 擦拭设备外壳和操作面板 | 每班 | 操作员 |
| 设备内部 | 清理铁屑和油泥 | 每周 | 操作员+维修 |
| 工具量具 | 清洁并归位 | 使用后 | 操作员 |
| 门窗墙壁 | 擦拭清洁 | 每周 | 轮值 |
| 排水沟 | 清理铁屑和杂物 | 每月 | 轮值 |

2. **清扫即点检**：清扫过程中同时检查设备状态
   - 有无松动的螺栓
   - 有无泄漏（油、水、气）
   - 有无异常磨损
   - 有无安全隐患

3. **污染源对策**：针对脏污的产生源头制定对策
   - 加装防护罩减少铁屑飞溅
   - 修复泄漏点
   - 改进排屑系统

4. **清扫工具准备**：为每个区域配备专用清扫工具并定置存放

### 第四个S：清洁（Seiketsu）

**定义**：将前三个S（整理、整顿、清扫）的成果制度化、标准化，保持和巩固。

**目的**：将短期活动转化为长期制度。

**实施步骤**：

1. **制定5S标准**：为每个区域制定5S可视化标准（照片/图表）
2. **建立责任区域**：划分5S责任区域，明确责任人

**5S责任区域划分示例**：

| 区域 | 责任人 | 检查频率 | 检查标准 |
|------|--------|----------|----------|
| 冷镦工位A | 操作员甲 | 每班 | 5S标准照片 |
| 冷镦工位B | 操作员乙 | 每班 | 5S标准照片 |
| 搓丝工位 | 操作员丙 | 每班 | 5S标准照片 |
| 热处理区 | 操作员丁 | 每班 | 5S标准照片 |
| 公共通道 | 轮值 | 每天 | 通道畅通标准 |

3. **建立检查制度**：
   - 操作员每日自查
   - 班组长每日巡查
   - 车间主任每周检查
   - 工厂层面每月审计
4. **5S审核评分**：制定5S审核评分标准，定期打分评比
5. **改善跟踪**：对审核中发现的问题进行跟踪整改

### 第五个S：素养（Shitsuke）

**定义**：培养员工遵守规章制度和工作标准的习惯和自觉性。

**目的**：将5S从"要我做"转变为"我要做"。

**实施步骤**：

1. **培训教育**：定期进行5S培训和意识教育
2. **领导示范**：管理层以身作则践行5S
3. **规章制度**：建立5S相关的行为规范
4. **表彰激励**：对5S表现优秀的个人和团队进行表彰
5. **持续活动**：通过5S改善发表会、竞赛等活动保持热情

## 红牌作战

### 什么是红牌作战

红牌作战是5S活动中整理阶段的核心工具。对工作现场中可疑的、不确定是否需要的物品贴上红色标签（红牌），要求相关部门在规定时间内做出处理决定。

### 红牌作战流程

```
步骤1：制定红牌标准
  - 明确什么情况下需要贴红牌
  - 准备红牌标签（统一格式）

步骤2：现场贴红牌
  - 全员参与，分区域进行
  - 对每件可疑物品贴红牌
  - 记录物品信息（名称、数量、位置、贴牌原因）

步骤3：红牌物品集中
  - 将红牌物品移到红牌区
  - 无法移动的在原位标识

步骤4：评审处理
  - 由5S委员会评审每件红牌物品
  - 做出处理决定：保留/转移/报废/退还

步骤5：处理执行
  - 按决定执行处理
  - 记录处理结果
  - 撤除红牌

步骤6：总结回顾
  - 统计红牌数量和处理结果
  - 分析需要改进的方面
  - 策划下一轮红牌作战
```

### 红牌标签格式

| 字段 | 内容 |
|------|------|
| 编号 | 唯一编号 |
| 物品名称 | 物品的名称和描述 |
| 数量 | 数量 |
| 存放位置 | 当前所在位置 |
| 贴牌原因 | 不确定需要/使用频率低/过期/其他 |
| 贴牌日期 | 贴牌的日期 |
| 期望处理日期 | 评审处理的截止日期 |
| 处理结果 | 保留/转移/报废/退还（评审后填写） |

## 定置管理

### 定置管理原则

- **有物必有位**：每件物品都有固定的存放位置
- **有位必有标识**：每个存放位置都有清晰的标识
- **有标识必对位**：标识与实际存放物品一致
- **常用近放，少用远放**：根据使用频率确定存放距离
- **先进先出**：有保质期或时效要求的物品按先进先出原则存放

### 定置率计算

```
定置率 = (已定置物品数量 / 应定置物品总数量) × 100%

目标：定置率 > 95%
```

## 紧固件车间5S实施

### 模具定置

**冷镦模具区**：
- 按产品型号分区域存放（M6/M8/M10/M12等）
- 每套模具使用专用模具架，标注型号和规格
- 使用状态标识：绿色=可用，黄色=待修，红色=报废
- 模具寿命记录卡随模具存放
- 定量管理：每型号设定最高/最低库存量

**搓丝板区**：
- 按螺纹规格分区存放
- 使用专用搓丝板架，防止碰伤牙型
- 标注规格、适用产品、库存量

### 检具管理

**量具定置**：
- 通止规按规格分类存放在专用量具柜
- 每套量具配备影子板，缺失一目了然
- 标注校准有效期，到期自动送检
- 精密量具（千分尺、投影仪）专柜存放

**检具标识**：
- 校准合格标签（绿色）
- 校准到期预警标签（黄色）
- 校准不合格停用标签（红色）

### 原料区域划分

**钢丝原料区**：
- 按材质分区（低碳钢、中碳钢、合金钢等）
- 每个区域设置标识牌（材质、规格、供应商、入库日期）
- 限量存放：设定最大库存量和安全库存量
- 先进先出管理：按入库日期排列

**辅料区**：
- 冷却液、润滑油、清洗剂等辅料分区存放
- 危化品专柜存放，配备安全标识
- 标注有效期和使用注意事项

## 关键指标/KPI

| 指标 | 定义 | 计算方法 | 目标值参考 |
|------|------|----------|-----------|
| **5S审计评分** | 按5S审核标准的综合评分 | 各项评分加权平均 | > 90分（满分100） |
| **工具查找时间** | 操作员寻找工具/物品的平均时间 | 抽样测量取平均值 | < 30秒 |
| **定置率** | 已定置物品占应定置物品的比例 | 已定置数 / 应定置数 × 100% | > 95% |
| **红牌关闭率** | 红牌物品在期限内处理完成的比例 | 按期关闭数 / 红牌总数 × 100% | > 90% |
| **5S审核通过率** | 首次审核即达标的区域比例 | 达标区域数 / 总区域数 × 100% | > 85% |
| **混料事故次数** | 因定置管理不到位导致的混料次数 | 月度统计 | 0次 |
| **寻找时间减少率** | 实施前后寻找时间的降低比例 | (改善前-改善后)/改善前 × 100% | > 70% |
| **清扫时间** | 每班清扫所需的平均时间 | 抽样测量 | 持续缩短 |

## 紧固件行业具体应用案例

### 案例：冷镦车间5S改善

**背景**：某紧固件工厂冷镦车间面积约2000平方米，有15台冷镦机。车间内物品摆放混乱，模具找不着、量具缺件、通道堵塞等问题频发。操作员每天花约30分钟寻找工具和模具。

**改善过程**：

**第1个月——整理**
- 对车间所有物品进行全面盘点
- 红牌作战：贴出红牌物品860件
- 处理结果：报废280件，转移350件，保留230件
- 释放有效面积约300平方米

**第2个月——整顿**
- 划分明确的功能区域：生产区、模具区、原料区、半成品区、成品区、通道
- 为每台设备的工具配置影子板
- 模具区重新规划，按型号分区定置
- 所有区域安装标识牌

**第3个月——清扫**
- 制定每个区域的清扫标准和责任表
- 配备专用清扫工具
- 开展"清扫即点检"活动
- 修复设备泄漏点12处

**第4个月——清洁**
- 制定5S审核评分标准
- 划分责任区域并公示
- 建立每日巡查和每周检查制度
- 引入5S评分看板

**第5-6个月——素养**
- 举办5S培训和发表会
- 开展5S竞赛评比
- 建立5S改善提案通道

**改善效果**：

| 指标 | 改善前 | 改善后 | 变化 |
|------|--------|--------|------|
| 工具查找时间 | 30分钟/天 | 3分钟/天 | -90% |
| 5S评分 | 52分 | 91分 | +75% |
| 混料事故 | 月均3次 | 0次 | -100% |
| 车间有效面积 | 1700m² | 2000m² | +18% |
| 工伤事故 | 月均2次 | 月均0.3次 | -85% |
| 员工满意度 | 62分 | 85分 | +37% |

## 常见误区

### 误区一：5S就是大扫除

5S不等于定期大扫除。大扫除是临时性、一次性的活动，而5S是日常化、制度化、持续性的管理体系。每个S都有其明确的目的和方法，远不止于打扫卫生。

### 误区二：5S只针对生产现场

5S适用于所有工作场所，包括办公室、仓库、实验室、食堂等。生产现场只是5S应用的一个场景。事务部门的5S同样能带来效率提升。

### 误区三：5S是额外工作

5S应融入日常工作流程，而非额外负担。通过制定合理的清扫基准和时间安排，5S活动可以成为操作员日常工作的有机组成部分。

### 误区四：花钱越多效果越好

5S的核心是方法和习惯，而非投入。简单的标识牌、影子板、区域划线就能带来显著效果。过度追求精美的标识和设施反而可能本末倒置。

### 误区五：5S做完一次就完成了

5S是一个持续改善的过程，不是一次性项目。即使达到了较高水平，如果不持续维护和改善，5S状态会逐渐退化。需要建立长效维持机制。

### 误区六：只有基层员工参与5S

5S需要全员参与，从最高管理层到一线操作员。管理层的重视和示范对5S的成功推行至关重要。如果管理层不参与，5S很难持续。
