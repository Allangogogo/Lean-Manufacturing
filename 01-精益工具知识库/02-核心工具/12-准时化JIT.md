# 准时化（JIT）

## 工具名称

- **中文**：准时化 / 及时生产
- **英文**：JIT / Just-In-Time
- **日文**：ジャストインタイム

## 定义与目的

准时化（JIT）是丰田生产系统的另一大支柱（与自働化并列），由大野耐一在丰田汽车公司发展完善。JIT的核心定义是：**在需要的时候，按需要的量，生产（或交付）需要的产品。**

JIT不是一种单一的技术，而是一套完整的生产哲学和管理体系。它追求的是消除一切浪费（Muda），特别是过量生产、等待、库存、搬运等与时间相关的浪费。

**核心目的**：

1. **消除过量生产**：只生产客户需要的数量，不多不少
2. **降低库存水平**：库存是万恶之源，JIT追求最小化库存
3. **缩短交付周期**：从接到订单到交付的总时间最短
4. **暴露问题**：低库存使生产过程中的问题无法隐藏，必须解决
5. **提升现金流**：减少库存积压，释放流动资金

**JIT的本质**：

JIT追求的是**流动（Flow）**——物料和信息在整个价值流中不间断地流动，没有等待、没有堆积、没有回流。

```
传统模式：推动式（Push） → 按预测生产 → 大批量 → 高库存
JIT模式：拉动式（Pull） → 按需求生产 → 小批量 → 低库存
```

## 关键原则

### 原则一：节拍时间（Takt Time）

节拍时间是JIT的脉搏。它等于客户的需求节奏：

```
节拍时间 = 可用工作时间 / 客户需求量
```

所有生产活动必须围绕节拍时间来组织。过快生产是浪费（过量生产），过慢生产是无法满足需求。

### 原则二：连续流（Continuous Flow）

理想的JIT状态是单件流（One-Piece Flow）——每件产品从前工序到后工序不间断流动，没有等待和堆积。在制造业，由于机加工等工序的特点，可能无法实现真正的单件流，但应追求最小批量的连续流。

### 原则三：拉动（Pull）

下游工序向上游工序发出"需要物料"的信号，上游工序根据这个信号生产。这就是看板（Kanban）拉动系统。

- 不是"我生产了推给你"
- 而是"你需要了告诉我，我再生产"

### 原则四：均衡化（Heijunka）

JIT要求生产是均衡的。如果需求波动大，通过成品库存作为缓冲，上游生产保持均衡。

### 原则五：标准化（Standardization）

标准化作业是JIT的基础。只有操作标准化了，节拍时间才能稳定，连续流才能顺畅。

### 原则六：持续改善（Kaizen）

JIT不是一蹴而就的目标，而是持续改善的方向。每次改善都在接近"完美的JIT"——零库存、零等待、零缺陷。

## JIT三要素详解

### 要素一：节拍时间

节拍时间将客户需求转化为生产节奏。它确保生产速度与客户需求同步。

**节拍时间的计算示例**：

假设制造工厂：
- 每天工作 8 小时 = 480 分钟
- 计划休息 60 分钟，计划停机 30 分钟
- 可用工作时间 = 480 - 60 - 30 = 390 分钟
- 客户每天需要 7800 件 某型号 工件

```
节拍时间 = 390分钟 × 60秒 / 7800件 = 3秒/件
```

这意味着每 3 秒钟，必须有一件 某型号 工件从生产线产出。

### 要素二：连续流

连续流的目标是消除工序间的所有等待和堆积，使产品从原材料到成品不间断地流动。

**产品生产的连续流设计**：

```
棒料放线 → 机加工 → 精加工 → 热处理 → 表面处理 → 检验 → 包装
```

理想状态下，每个工序之间没有在制品堆积，产品一个接一个地流过所有工序。

**实现连续流的条件**：
1. 各工序的节拍时间匹配（平衡率≥85%）
2. 换型时间足够短（SMED）
3. 设备可靠性高（TPM）
4. 质量稳定（自働化、防错）
5. 布局紧凑（减少搬运距离）

### 要素三：拉动

拉动系统是JIT的执行机制。最经典的拉动工具是看板（Kanban）。

**看板拉动的运作方式**：

```
客户消耗成品 → 成品仓库补充看板送回包装工序
→ 包装工序根据看板生产 → 包装工序消耗半成品 → 半成品补充看板送回表面处理工序
→ 表面处理工序根据看板生产 → ... 依次向上游传递
```

## 实现步骤

### 第一步：价值流分析

1. 绘制当前价值流图（Current State VSM）
2. 识别所有增值活动和非增值活动
3. 计算增值比（增值时间/总前置时间）
4. 识别瓶颈工序和主要浪费

**产品价值流示例**：

| 工序 | 周期时间 | 前置时间 | 在制品 | 等待时间 |
|------|---------|---------|--------|---------|
| 棒料放线 | 1秒/件 | 2天（库存） | 10000件 | 2天 |
| 机加工 | 3秒/件 | 4小时 | 5000件 | 4小时 |
| 精加工 | 2秒/件 | 2小时 | 3000件 | 2小时 |
| 热处理 | 连续式 | 8小时 | 一批 | 8小时 |
| 表面处理 | 连续式 | 4小时 | 一批 | 4小时 |
| 检验包装 | 5秒/件 | 1小时 | 500件 | 1小时 |

**增值时间合计**：约 0.5 小时
**总前置时间**：约 3.5 天
**增值比**：0.5/(3.5×24) = 0.6%（典型的离散制造水平）

### 第二步：设计未来价值流

1. 设定目标前置时间（如缩短50%）
2. 设计连续流布局
3. 建立拉动系统
4. 确定节拍时间
5. 设计均衡化排产方式

### 第三步：建立拉动系统

1. **确定看板类型**：
   - 生产看板：指示上游工序生产指定数量的产品
   - 取料看板：指示从仓库或上工序取料
   - 信号看板：当库存降到再订货点时触发补充

2. **计算看板数量**：

```
看板数量 = (日均需求 × 前置时间 × (1 + 安全系数)) / 看板容量
```

3. **设定看板规则**：
   - 无看板不生产
   - 有看板才取料
   - 后工序只向前工序取已生产的产品
   - 不良品不流入下工序

### 第四步：实施JIT供应

1. **供应商JIT供货**：与关键供应商（如棒料供应商）建立JIT供货机制
   - 棒料按日或按班次配送
   - 小批量多频次送货
   - 供应商管理库存（VMI）

2. **厂内JIT配送**：
   - 物料按看板信号配送到工位
   - 线边库存控制在2-4小时用量
   - 使用物料超市（Supermarket）作为缓冲

3. **成品JIT发货**：
   - 按客户订单节拍发货
   - 与物流商建立定时配送机制
   - 成品库存控制在1-3天

### 第五步：缩短前置时间

1. 减小批量大小（配合SMED缩短换型时间）
2. 优化设备布局（从功能布局改为单元布局）
3. 减少搬运距离和次数
4. 消除等待时间（工序平衡）
5. 缩短热处理和表面处理的等待时间

### 第六步：持续改善

1. 定期更新价值流图
2. 每月回顾库存水平和前置时间
3. 识别新的改善机会
4. 逐步向"零库存"目标推进

## 棒料JIT供应管理

棒料是产品的主要原材料，通常占产品成本的60-70%。棒料的JIT供应是制造工厂JIT实施的关键环节。

### 棒料JIT供应模式

**模式一：定时配送**
- 供应商按固定时间表配送（如每天上午10点和下午3点）
- 每次配送量根据当天生产计划确定
- 适用于需求稳定的品种

**模式二：看板拉动**
- 工厂设置棒料物料超市
- 当某种规格的棒料库存降到再订货点时，发出看板给供应商
- 供应商根据看板在约定时间内送达
- 适用于需求波动较大的品种

**模式三：供应商管理库存（VMI）**
- 供应商在工厂附近设立仓库或中转站
- 供应商根据工厂的消耗数据自动补货
- 工厂按实际使用量与供应商结算
- 适用于用量大、品种多的情况

### 棒料JIT供应的关键要求

1. **缩短交付周期**：供应商到工厂的运输时间应控制在4小时以内
2. **小批量多频次**：每次配送量减少，配送频率增加
3. **质量保证**：供应商过程质量保证，减少来料检验
4. **信息共享**：工厂的生产计划和库存数据与供应商实时共享
5. **应急预案**：交通异常、供应商产能异常等情况的应急方案

## 关键指标/KPI

| 指标名称 | 计算方法 | 目标值 | 说明 |
|---------|---------|--------|------|
| 库存周转率 | 年销售成本/平均库存金额 | ≥12次/年 | 库存管理效率 |
| 库存天数 | 平均库存金额/日均销售成本 | ≤30天 | 库存持有的时间 |
| 前置时间（Lead Time） | 从原材料投入到成品产出的时间 | 持续缩短 | 生产流动效率 |
| 增值比 | 增值时间/总前置时间 × 100% | 持续提升 | 消除非增值活动 |
| 在制品库存 | 任何时刻生产线上的在制品数量 | 持续降低 | 流动性的体现 |
| 搬运距离 | 产品从原材料到成品的总搬运距离 | 持续缩短 | 布局优化 |
| 交付准时率 | 准时交付订单数/总订单数 × 100% | ≥98% | JIT的外部效果 |
| 看板周转率 | 看板循环次数/天 | 按设计执行 | 拉动系统的健康度 |
| 棒料库存天数 | 棒料库存量/日均消耗量 | 3-7天 | 原材料JIT水平 |
| 批量大小 | 平均每批生产数量 | 持续降低 | 小批量化的进展 |

## 制造业具体应用案例

### 案例一：从推动式到拉动式的转型

**背景**：某制造工厂原来采用推动式生产——计划部门根据月度预测制定生产计划，各工序按计划生产，不论下工序是否需要。

**问题**：
- 成品库存高（平均45天库存量）
- 在制品堆积严重（机加工和精加工之间堆了3天的量）
- 热处理排队等待时间长（平均8小时）
- 客户紧急插单时频繁调整计划，导致混乱

**JIT改善方案**：

1. **成品超市建立**：
   - 根据客户交货频率设定成品库存水位
   - 成品库存作为"缓冲"吸收需求波动
   - 超市库存水位 = 日均出货量 × 2天

2. **看板拉动系统**：
   - 包装工序从成品超市取货后，产生生产看板给检验工序
   - 检验工序完成后，产生看板给表面处理工序
   - 依次向前拉动，直至机加工工序

3. **均衡化排产**：
   - 月度需求分解为日需求
   - 每天按M8:某型号:某型号 = 5:3:2的比例均衡生产
   - 配合SMED实现频繁换型

**改善效果**：

| 指标 | 改善前 | 改善后 |
|------|--------|--------|
| 成品库存天数 | 45天 | 8天 |
| 在制品库存 | 3天 | 0.5天 |
| 前置时间 | 5天 | 1.5天 |
| 热处理等待时间 | 8小时 | 1小时 |
| 客户准时交付率 | 85% | 97% |

### 案例二：棒料JIT供应实施

**背景**：棒料库存占用大量资金和仓库空间。原来每月采购一批棒料（约200吨），库存周转率仅为2次/年。

**JIT供应方案**：

1. **供应商选择**：选择距离工厂50公里以内的棒料供应商
2. **配送频率**：从每月1次改为每周3次（周一/周三/周五）
3. **每批配送量**：约12-15吨（约2天用量）
4. **信息共享**：工厂ERP系统与供应商共享未来一周的生产计划
5. **质量前移**：供应商出厂检验替代工厂来料检验（经过审核认证后）

**改善效果**：
- 棒料库存从200吨降至40吨
- 棒料库存天数从30天降至6天
- 仓库面积释放50%
- 棒料库存资金占用减少80%

## 常见误区

### 误区一：JIT就是零库存

**错误理解**：JIT的目标就是把库存降到零。

**正确认知**：库存是手段，不是目的。JIT追求的是消除浪费、缩短前置时间、提升流动效率。库存是实现这些目标的手段之一，但盲目降库存而不改善过程能力会导致缺货和停产。正确的做法是先改善过程能力，再逐步降低库存。

### 误区二：JIT只适用于汽车等大批量行业

**错误理解**：产品品种多、批量小，不适合JIT。

**正确认知**：产品的工艺路线相对简单（机加工→精加工→热处理→表面处理→检验包装），非常适合JIT。关键在于建立看板拉动系统和均衡化排产。

### 误区三：JIT会增加缺货风险

**错误理解**：降低库存会导致无法满足客户需求。

**正确认知**：JIT通过拉动系统确保生产与需求同步，通过成品库存缓冲吸收需求波动。只要设计合理，JIT不会增加缺货风险，反而因为前置时间缩短而能更快响应客户需求变化。

### 误区四：JIT只是生产部门的事

**错误理解**：JIT是车间的事情，与采购、销售无关。

**正确认知**：JIT是全价值链的变革。采购需要JIT供货，销售需要准确的需求预测和均衡的订单，生产需要均衡化排产，物流需要准时配送。任何一个环节的脱节都会影响JIT的运行。

### 误区五：JIT可以一步到位

**错误理解**：一次性导入所有JIT工具和方法。

**正确认知**：JIT是循序渐进的过程。建议从价值流分析开始，选择一条关键产线试点，逐步推广。急于求成往往导致系统性失败。
