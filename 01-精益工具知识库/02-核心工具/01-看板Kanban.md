# 看板（Kanban）

## 工具名称

| 语言 | 名称 |
|------|------|
| 中文 | 看板管理系统 |
| 英文 | Kanban System |
| 日文 | かんばん（Kanban） |

---

## 定义与目的

看板是一种基于实际需求的拉动式（Pull）视觉调度系统，起源于丰田生产方式（TPS）。其核心思想是**后工序根据实际消耗向前工序发出补货信号**，从而避免过量生产，控制在制品（WIP）水平，实现流动式生产。

在紧固件制造中，看板用于协调冷镦、搓丝、热处理、表面处理、分选、包装等工序间的物料流动，确保每个工序仅在需要时才生产所需数量的产品。

### 核心目的

- **消除过量生产浪费**：仅在下游工序消耗后才触发上游生产
- **可视化工作流**：让所有人一目了然地看到生产状态、瓶颈和异常
- **控制在制品数量**：通过设定WIP上限，防止中间库存积压
- **缩短前置时间**：减少等待和排队时间，加速物料流动
- **建立持续改进基础**：通过度量流动指标，识别改进机会

---

## 关键原则

### 原则一：可视化（Visualize）

将所有工作项及其状态以可视化方式呈现。在紧固件生产线中，可使用看板卡片、信号灯、电子看板等方式，让每个工序的生产状态、排队数量、异常信息对所有人透明。

### 原则二：限制在制品（Limit WIP）

为每个工序或缓冲区设定最大在制品数量上限。一旦达到上限，上游工序必须停止生产，直到下游消耗了部分在制品。这是拉动式生产的核心机制。

### 原则三：管理流动（Manage Flow）

关注的重点不是每个工序的利用率，而是整个系统的流动效率。目标是让产品在系统中持续流动，减少等待、排队和返工。

### 原则四：明确策略（Make Policies Explicit）

对看板的使用规则做出明确书面规定，包括：补货触发条件、优先级规则、异常处理流程、WIP上限调整权限等。所有相关人员必须清楚理解并遵守这些规则。

### 原则五：实施反馈循环（Implement Feedback Loops）

建立定期的回顾和调整机制，如每日站会、每周看板审查、每月流动指标分析等。通过反馈循环不断优化看板参数和流程。

### 原则六：持续改进（Improve Collaboratively）

基于看板系统的度量数据，团队协作进行渐进式改善。看板系统本身也是一个持续演进的过程，需要根据实际情况不断调整优化。

## 实施步骤

### 第一步：绘制当前价值流图

首先对紧固件生产的完整流程进行价值流分析，识别所有工序、缓冲区、信息流和物料流。明确每个工序的节拍时间、换型时间、合格率、设备可用率等关键参数。

### 第二步：设计看板系统

根据流程特点设计看板类型和数量：

**生产看板（Production Kanban）**
- 授权上游工序生产指定数量的产品
- 包含信息：产品型号、数量、目标工序、物料批次

**取料看板（Withdrawal Kanban）**
- 授权从缓冲区或上游工序取走指定数量的产品
- 包含信息：产品型号、数量、来源位置、目标位置

**信号看板（Signal Kanban）**
- 当库存降至触发点时发出补货信号
- 适用于批量生产工序（如热处理）

### 第三步：计算看板数量

看板数量的计算公式：

```
N = (D × L × (1 + α)) / C

N = 看板数量
D = 平均日需求量
L = 补货前置时间（天）
α = 安全系数（通常0.1~0.3）
C = 每个看板代表的包装数量
```

### 第四步：设定WIP上限

根据看板数量和包装规格，计算每个工序的WIP上限。WIP上限应考虑设备能力、换型时间、质量波动等因素。

### 第五步：制作看板卡片/信号

设计标准化的看板卡片，包含以下必要信息：

| 字段 | 说明 |
|------|------|
| 产品编号 | 物料编码和名称 |
| 批次数量 | 每张看板代表的数量 |
| 源工序 | 物料来源的工序/位置 |
| 目标工序 | 物料要去的工序/位置 |
| 优先级 | 生产优先级标记 |
| 触发日期 | 看板被释放的日期 |
| 有效期限 | 看板的有效时间 |

### 第六步：试运行与调整

选择一条产品线进行试运行，收集数据，调整看板参数。重点观察：
- 是否频繁出现缺料停线
- WIP是否超出预期
- 物料流动是否顺畅
- 异常处理是否及时

### 第七步：全面推广与持续优化

在试运行成功的基础上逐步推广到所有产品线，建立定期审查机制，持续优化看板参数。

## 看板在紧固件工序间的应用

### 工序间看板布局

```
[钢丝原料库] →→ [冷镦工序] →→ [搓丝工序] →→ [热处理工序] →→ [表面处理工序] →→ [分选/质检] →→ [包装工序] →→ [成品库]
                    ↓              ↓              ↓                ↓                ↓              ↓
              [冷镦缓冲区]   [搓丝缓冲区]   [热处理缓冲区]  [表面处理缓冲区]  [分选缓冲区]   [包装缓冲区]
```

### 各工序看板规则

**冷镦 → 搓丝**
- 搓丝工序消耗冷镦半成品后，释放看板到冷镦工序
- 冷镦工序收到看板后开始生产对应型号和数量
- 缓冲区最大WIP：2小时产量

**搓丝 → 热处理**
- 热处理为批量工序，使用信号看板
- 当缓冲区库存降至触发点时，发出批量生产信号
- 每批数量根据网带炉装载量确定

**热处理 → 表面处理**
- 表面处理消耗热处理品后释放看板
- 考虑表面处理的批量特性（挂镀/滚镀的最小批量）

**表面处理 → 分选/包装**
- 分选工序按客户订单拉动
- 包装工序根据发货计划拉动

### 看板异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 看板丢失 | 立即调查原因，补发看板并记录 |
| 物料与看板不符 | 暂停流转，核实后重新标识 |
| WIP超限 | 上游工序停止生产，分析原因 |
| 设备故障 | 安灯报警 + 看板冻结 |
| 质量异常 | 隔离可疑品，启动质量调查 |

## 关键指标/KPI

| 指标 | 定义 | 目标值参考 |
|------|------|-----------|
| **前置时间（Lead Time）** | 产品从进入系统到完成的总时间 | 持续缩短 |
| **周期时间（Cycle Time）** | 单个工序完成一件产品的时间 | 接近节拍时间 |
| **吞吐量（Throughput）** | 单位时间内系统输出的产品数量 | 满足客户交付需求 |
| **在制品数量（WIP）** | 系统中所有未完成产品的总数 | 低于看板设定上限 |
| **流动效率** | 增值时间 / 总前置时间 | 目标 > 25% |
| **看板周转率** | 看板完成循环的频率 | 越高越好 |
| **缺料停线率** | 因缺料导致的停线时间占比 | < 2% |
| **看板准确率** | 看板信息与实际物料一致的比率 | > 99% |

## 紧固件行业具体应用案例

### 案例：M8六角螺栓生产线看板实施

**背景**：某紧固件工厂M8六角螺栓月产量100万件，从冷镦到包装共6道工序。实施前各工序独立排产，导致中间库存高达3天产量，且经常出现某些型号积压而另一些型号缺料的情况。

**实施方案**：

1. 按客户订单将产品分为A类（高频通用件）、B类（中频标准件）、C类（低频定制件）
2. A类产品采用连续拉动看板，工序间WIP上限设为4小时产量
3. B类产品采用批量信号看板，批量大小为1天产量
4. C类产品采用一次性生产看板，按订单单独排产
5. 在每个工序间设置标准化缓冲区，使用颜色编码区分不同产品类型

**实施效果**：

| 指标 | 改善前 | 改善后 | 变化 |
|------|--------|--------|------|
| 中间库存 | 3天 | 0.8天 | -73% |
| 前置时间 | 5天 | 1.8天 | -64% |
| 准时交付率 | 85% | 96% | +11% |
| 缺料停线时间 | 4小时/周 | 0.5小时/周 | -87% |

## 常见误区

### 误区一：看板就是一张卡片

看板不仅是一个物理工具，更是一套完整的拉动式生产和持续改进的管理体系。仅制作卡片而没有配套的规则、流程和文化建设，无法发挥看板的真正价值。

### 误区二：看板数量一旦设定就不变

看板数量需要根据需求变化、产能调整、质量改善等因素持续优化。初期设定通常偏保守（偏多），随着系统稳定应逐步减少看板数量，暴露问题并推动改善。

### 误区三：每个工序都要用看板

并非所有工序都适合使用看板。对于交货期很长的定制化产品或大批量连续流工序，看板可能不适用或需要变体形式。应根据产品特性和生产模式选择合适的拉动机制。

### 误区四：看板系统可以独立运行

看板系统需要均衡化生产、设备稳定性（TPM）、质量一致性（标准作业）等基础支撑。在基础不牢固时贸然推行看板，可能导致频繁停线和混乱。

### 误区五：追求100%的看板遵守率

看板系统需要一定的灵活性来应对异常情况。过度僵化地执行看板规则可能导致系统无法适应实际变化。关键是建立明确的异常处理流程，在规则和灵活性之间取得平衡。

### 误区六：电子看板可以完全替代物理看板

电子看板在数据追踪和分析方面有优势，但在现场可视化和即时感知方面不如物理看板。最佳实践是物理看板与电子系统相结合，发挥各自优势。
