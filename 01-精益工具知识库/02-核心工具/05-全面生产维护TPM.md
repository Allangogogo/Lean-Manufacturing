# 全面生产维护（TPM）

## 工具名称

| 语言 | 名称 |
|------|------|
| 中文 | 全面生产维护/全员生产保全 |
| 英文 | Total Productive Maintenance (TPM) |
| 日文 | 全社的予防保全（ぜんしゃてきよぼうほぜん / Zensha-teki Yobō Hozen） |

---

## 定义与目的

TPM（全面生产维护）是一种全员参与的设备维护管理体系，旨在通过全员参与的自主维护和计划维护活动，实现设备综合效率（OEE）的最大化。TPM不仅关注设备本身的维护，更强调通过设备管理推动整个生产系统的改善。

在紧固件制造中，冷镦机、搓丝机、网带炉、电镀线等关键设备的稳定运行直接决定产品质量和交货能力。TPM是确保这些设备高效运行的核心管理工具。

### 核心目的

- **追求零故障**：通过预防性和预测性维护，最大限度减少设备故障
- **追求零不良**：通过设备精度保持，消除因设备原因导致的质量不良
- **追求零事故**：通过安全设备管理，消除安全隐患
- **全员参与**：让每一位员工都成为设备的维护者和改善者
- **最大化OEE**：通过消除六大损失，提升设备综合效率

## 八大支柱详解

### 支柱一：自主维护（Jishu Hozen）

自主维护是指操作员对自己负责的设备进行日常维护保养活动，包括清扫、润滑、紧固、点检等。目标是培养操作员的"设备主人"意识。

**三步法**：
1. **初期清扫**：彻底清扫设备，发现潜在问题（跑冒滴漏、松动、磨损）
2. **困难部位对策**：解决清扫困难、点检困难、润滑困难、调整困难的部位
3. **自主点检**：建立操作员日常点检标准和方法

### 支柱二：计划维护（Planned Maintenance）

计划维护是通过定期检查、预防性维修和预测性维修，避免设备突发故障的系统性维护活动。

**维护层级**：
| 层级 | 内容 | 频率 |
|------|------|------|
| 日常点检 | 操作员进行的外观检查和简单保养 | 每班 |
| 定期保养 | 按计划进行的润滑、更换、调整 | 每周/月/季 |
| 预防性维修 | 基于设备状态的预防性维修 | 按状态或时间 |
| 预测性维修 | 基于数据分析的预测性维护 | 实时监测 |
| 大修 | 设备全面解体检修 | 每年/每两年 |

### 支柱三：个别改善（Kobetsu Kaizen）

针对设备的主要损失（停机损失、速度损失、质量损失）进行专项改善活动。通过OEE数据分析，识别损失最大的设备和损失类型，组建跨部门改善小组进行攻关。

### 支柱四：教育训练（Education & Training）

系统性地提升员工的设备维护技能和知识：
- 操作员的设备基础知识培训
- 自主维护技能培训
- 维修人员的专业技能提升
- 新员工的设备操作和维护培训

### 支柱五：初期管理（Early Equipment Management）

将设备使用和维护阶段的经验反馈到新设备的规划和采购阶段，从源头提升设备的可维护性和可靠性。

**关键活动**：
- 新设备采购时的可维护性评估
- 安装调试阶段的知识积累
- 设备初期流动管理（新设备投产后的特别监护）

### 支柱六：品质维护（Quality Maintenance）

从设备角度分析和消除品质不良，确保设备精度满足产品质量要求。

**实施步骤**：
1. 分析设备状态与产品质量的关联
2. 确定设备精度标准
3. 建立设备精度点检和校准体系
4. 对设备精度劣化进行预防性管理

### 支柱七：事务改善（Office TPM）

将TPM理念延伸到管理部门，改善办公流程效率，消除事务性浪费，提升对生产现场的支援效率。

### 支柱八：安全环境（Safety, Health & Environment）

以"零灾害、零公害"为目标，通过设备安全管理、环境管理，确保安全清洁的工作环境。

## OEE计算方法

### OEE（Overall Equipment Effectiveness）设备综合效率

OEE是衡量设备利用效率的核心指标，由三个因素相乘得出：

```
OEE = 可用率（Availability） × 性能率（Performance） × 合格率（Quality）
```

### 可用率（时间开动率）

```
可用率 = (计划运行时间 - 停机损失) / 计划运行时间 × 100%

停机损失包括：
- 设备故障停机
- 换型调机停机
- 等待物料/人员/指令
- 计划外的调整和维修

示例：
计划运行时间：440分钟/班（8小时 - 2次休息共20分钟）
故障停机：15分钟
换型时间：10分钟
等待时间：5分钟
可用率 = (440 - 30) / 440 × 100% = 93.2%
```

### 性能率（速度开动率）

```
性能率 = (理想节拍时间 × 总产出数量) / 实际运行时间 × 100%

性能损失包括：
- 设备空转和短暂停机
- 速度降低（低于设计速度运行）
- 小停机（卡料、调整等）

示例：
理想节拍时间：1.0秒/件
实际产出：35,000件
实际运行时间：410分钟（= 24,600秒）
性能率 = (1.0 × 35,000) / 24,600 × 100% = 142.3%

注意：当性能率 > 100% 时，说明实际速度超过了设定的理想节拍，
应重新评估理想节拍时间的合理性。
```

### 合格率（质量开动率）

```
合格率 = 合格品数量 / 总产出数量 × 100%

质量损失包括：
- 不合格品（报废）
- 返工品（修复后合格）
- 开机废品（换型后的调试废品）

示例：
总产出：35,000件
不合格品：350件
开机废品：100件
合格率 = (35,000 - 350 - 100) / 35,000 × 100% = 98.7%
```

### OEE综合计算

```
OEE = 93.2% × 87.5% × 98.7% = 80.3%

行业基准：
- 世界级OEE：> 85%
- 行业平均：60-70%
- 典型改善空间：当前OEE × (1 + 改善比例)
```

### 六大损失

| 损失类型 | 对应OEE因素 | 典型表现 |
|----------|-------------|----------|
| 设备故障 | 可用率 | 突发故障导致停机 |
| 换型调整 | 可用率 | 换模具、换品种的停机时间 |
| 空转短停 | 性能率 | 卡料、传感器误报等短暂停机 |
| 速度降低 | 性能率 | 设备降速运行 |
| 过程缺陷 | 合格率 | 加工过程中产生的不良品 |
| 开机废品 | 合格率 | 换型后调试阶段的废品 |

### 冷镦机TPM

**自主维护要点**：

| 点检项目 | 频率 | 方法 | 判定标准 |
|----------|------|------|----------|
| 润滑油油位 | 每班 | 目视 | 在上下限之间 |
| 润滑油油温 | 每班 | 温度计 | < 60°C |
| 冲模温度 | 每2小时 | 红外测温 | < 150°C |

**计划维护要点**：
- 每月：检查曲轴轴承间隙、更换润滑油
- 每季度：检查传动皮带、校准送料机构
- 每半年：全面检查电气系统、液压系统

## 关键指标/KPI

| 指标 | 定义 | 计算方法 | 目标值参考 |
|------|------|----------|-----------|
| **OEE** | 设备综合效率 | 可用率 × 性能率 × 合格率 | > 85%（世界级） |
| **MTBF** | 平均故障间隔时间 | 总运行时间 / 故障次数 | 持续提升 |
| **MTTR** | 平均修复时间 | 总维修时间 / 故障次数 | 持续缩短 |
| **计划维护完成率** | 按计划完成的维护活动比例 | 完成项数 / 计划项数 × 100% | > 95% |
| **自主维护点检率** | 操作员自主点检执行率 | 实际点检次数 / 计划点检次数 × 100% | > 98% |
| **故障次数** | 月度/季度设备故障次数 | 统计期内的故障总次数 | 持续减少 |
| **设备停机率** | 设备停机时间占可用时间的比例 | 停机时间 / 可用时间 × 100% | < 5% |
| **维护成本率** | 维护费用占设备资产的比例 | 年维护费用 / 设备资产 × 100% | 行业基准 |
| **备件库存周转率** | 备件使用与库存的比例 | 年消耗金额 / 平均库存金额 | > 2次/年 |

## 紧固件行业具体应用案例

### 案例：冷镦车间OEE提升

**背景**：某紧固件工厂冷镦车间12台冷镦机，平均OEE仅为55%，远低于行业平均水平。设备故障频繁，换型时间长，质量波动大。

**改善措施**：

1. **自主维护**：培训所有操作员进行日常点检和保养，建立设备"家有"制度（每台设备有明确的负责人）
2. **计划维护**：建立设备维护日历，按周/月/季/年执行维护计划
3. **换型改善**：应用SMED方法，将平均换型时间从45分钟缩短到15分钟
4. **故障分析**：对Top 10故障类型进行根本原因分析，制定预防措施
5. **精度管理**：建立模具寿命跟踪系统，按寿命预警更换

**OEE提升效果**：

| OEE因素 | 改善前 | 改善后 | 主要改善措施 |
|---------|--------|--------|-------------|
| 可用率 | 78% | 92% | 减少故障、缩短换型 |
| 性能率 | 82% | 90% | 减少短暂停机、恢复速度 |
| 合格率 | 86% | 98% | 模具精度管理、参数优化 |
| **OEE** | **55%** | **81%** | **+26个百分点** |

**经济效益**：
- 产能提升35%（不增加设备）
- 年节约维修费用约30万元
- 不良品率降低60%
- 设备投资回收期缩短

## 常见误区

### 误区一：TPM只是维修部门的事

TPM的"T"代表Total（全员），操作员、班组长、工程师、管理层都应参与。操作员的自主维护是TPM的基础，维修部门主要负责专业性较强的计划维护和故障修复。

### 误区二：OEE越高越好，追求100%

OEE的理论上限是100%，但盲目追求100%可能导致过度维护、过度库存或过度生产。OEE应与客户需求和生产计划协调。关键是消除六大损失中最大的损失。

### 误区三：TPM只关注设备

TPM虽然以设备为中心，但最终目标是通过设备管理推动整体生产系统的改善，包括质量、效率、成本、安全、交期等全方位的提升。

### 误区四：TPM投入大见效慢

TPM的初期投入主要是培训和时间成本，但通过减少故障、降低不良、提升效率带来的回报通常远超投入。自主维护活动几乎不需要额外的硬件投资。

### 误区五：买了好设备就不需要TPM

设备再先进也需要维护。且越是先进的设备，维护的专业性和及时性要求越高。TPM是确保设备在整个生命周期内保持最佳状态的管理体系。

### 误区六：TPM活动就是贴标签和做表格

TPM有丰富的工具和表格，但这些只是手段而非目的。TPM的核心是通过全员参与的文化建设，实现设备零故障和生产系统持续改善。
