## OEE深度分析框架

### OEE的三层分解

OEE不仅是一个数字，更是一个诊断工具。世界级OEE的每个因子都有明确的分解结构：

```
OEE = 可用率 × 性能率 × 合格率

可用率（目标>90%）
├── 计划运行时间
│   ├── 日历时间
│   ├── 减去：计划停机（休息、会议、无订单）
│   └── 等于：计划运行时间
├── 非计划停机
│   ├── 设备故障（目标<2%）
│   ├── 换型调整（目标<3%）
│   ├── 等待物料/人员/指令（目标<1%）
│   └── 其他非计划停机（目标<1%）
└── 可用率 = (计划运行时间 - 所有停机) / 计划运行时间

性能率（目标>95%）
├── 理论产出 = 实际运行时间 / 理想节拍时间
├── 实际产出
├── 性能损失
│   ├── 小停机/空转（目标<2%）
│   ├── 速度降低（目标<2%）
│   └── 其他性能损失（目标<1%）
└── 性能率 = 实际产出 / 理论产出

合格率（目标>99.9%）
├── 总产出
├── 质量损失
│   ├── 报废品
│   ├── 返工品
│   └── 开机废品
└── 合格率 = (总产出 - 所有质量损失) / 总产出
```

### OEE改善的杠杆效应

**案例：冷镦机OEE从68%提升到85%**

```
改善前：可用率85% × 性能率88% × 合格率95% = 71.1%

改善措施：
1. 设备故障减少60% → 可用率从85%提升到92%
2. 换型时间缩短50% → 可用率从92%提升到95%
3. 小停机减少50% → 性能率从88%提升到93%
4. 过程缺陷减少40% → 合格率从95%提升到97.5%

改善后：可用率95% × 性能率93% × 合格率97.5% = 86.2%

产能提升：(86.2%-71.1%)/71.1% = 21.2%
即：在不增加设备的情况下，产能提升21.2%
```

## 自主维护七步法（详细版）

### 第一步：初期清扫——发现问题的入口

**目的：** 通过彻底清扫设备，发现隐藏在深处的缺陷（微缺陷、泄漏、松动、磨损、变形、污垢等）。

**微缺陷的放大效应：**

```
微缺陷积累模型：
1个微缺陷 → 1个
10个微缺陷 → 1个中缺陷
10个中缺陷 → 1个大缺陷
10个大缺陷 → 1次设备故障
10次设备故障 → 1次重大事故

即：1个重大事故背后可能有1000个微缺陷
```

**初期清扫检查清单（冷镦机）：**

| 检查部位 | 检查项目 | 判定标准 | 发现问题数 |
|----------|---------|---------|-----------|
| **润滑系统** | 油位、油质、泄漏、油压 | 油位在上下限之间，无泄漏 | |
| **传动系统** | 齿轮磨损、皮带张力、联轴器 | 齿面无剥落，皮带张力正常 | |
| **模具系统** | 冲头磨损、凹模裂纹、固定螺栓 | 工作面光滑，无松动 | |
| **送料系统** | 送料轮磨损、导轨间隙、送料精度 | 送料精度±0.1mm | |
| **冷却系统** | 冷却水流量、水管泄漏、水温 | 流量正常，无泄漏 | |
| **电气系统** | 接线端子、传感器、开关 | 接线牢固，无老化 | |
| **安全防护** | 防护罩、急停按钮、光栅 | 功能正常，无缺失 | |
| **气动系统** | 气缸泄漏、气管老化、压力 | 无泄漏，压力正常 | |

**清扫即点检的"五感"方法：**

| 感官 | 检查内容 | 异常发现 |
|------|---------|---------|
| **视觉** | 看外观、颜色、形状 | 裂纹、变色、变形、泄漏 |
| **听觉** | 听运转声音 | 异响、振动声、摩擦声 |
| **触觉** | 摸温度、振动 | 过热、异常振动 |
| **嗅觉** | 闻气味 | 烧焦味、油味、异味 |
| **味觉** | （一般不用于设备检查） | — |

## 预测性维护（PdM）技术

### 从预防性维护到预测性维护的演进

```
维护策略演进：

反应性维护 ──► 预防性维护 ──► 预测性维护 ──► 规范性维护
（坏了再修）   （定期检修）    （状态监测）    （AI决策）

损失：高         损失：中       损失：低       损失：最低
成本：低         成本：中       成本：中-高     成本：高
```

### 预测性维护核心技术

| 技术 | 监测对象 | 适用设备 | 检测故障类型 |
|------|---------|---------|-------------|
| **振动分析** | 振动频率/幅值 | 旋转设备（电机、轴承、齿轮） | 不平衡、不对中、轴承磨损 |
| **红外热成像** | 温度分布 | 电气接头、炉体、轴承 | 过热、接触不良、绝缘失效 |
| **油液分析** | 油液成分/颗粒 | 液压系统、齿轮箱 | 磨损、污染、油液劣化 |
| **超声波检测** | 超声波信号 | 压力容器、管道、阀门 | 泄漏、裂纹、放电 |
| **电机电流分析** | 电流波形 | 电机、泵、风机 | 转子断条、气隙偏心 |


### 冷镦机模具管理系统

**模具全生命周期管理：**

```
模具生命周期：
采购 → 验收 → 入库 → 领用 → 安装 → 使用 → 监控 → 维修 → 报废
 │      │      │      │      │      │      │      │      │
 ▼      ▼      ▼      ▼      ▼      ▼      ▼      ▼      ▼
供应商  IQ    台账   领用   安装   计数   预警   维修   报废
审核         管理   记录   记录   记录   更换   记录   审批
```

**模具寿命管理模型：**

```
模具寿命预测模型：

实际寿命 = 基础寿命 × 材料系数 × 工艺系数 × 维护系数

基础寿命：模具设计寿命（如50万件）
材料系数：
  - 低碳钢：1.0
  - 中碳钢：0.8
  - 合金钢：0.6

工艺系数：
  - 简单形状：1.0
  - 中等复杂度：0.85
  - 复杂形状：0.7

维护系数：
  - 良好维护：1.2
  - 正常维护：1.0
  - 维护不足：0.7

示例：
M10六角螺栓模具，中碳钢，中等复杂度，良好维护
实际寿命 = 50万 × 0.8 × 0.85 × 1.2 = 40.8万件
```
