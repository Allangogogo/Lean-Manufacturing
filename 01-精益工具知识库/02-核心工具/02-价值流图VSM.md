# 价值流图（Value Stream Mapping, VSM）

## 工具名称

| 语言 | 名称 |
|------|------|
| 中文 | 价值流图分析 |
| 英文 | Value Stream Mapping (VSM) |
| 日文 | 価値流図（Kachi-ryūzu） |

---

## 定义与目的

价值流图（VSM）是一种端到端流程的可视化分析工具，用于描绘产品从原材料到交付客户的完整流动过程，识别其中的增值活动和非增值活动（浪费）。VSM不仅展示物料流，还同时展示信息流，是精益转型的战略级工具。

在紧固件制造中，VSM覆盖从钢丝原材料采购、冷镦成型、搓丝攻丝、热处理、表面处理、质量检测、分选包装到物流发货的全过程。

### 核心目的

- **全局视角**：跳出单一工序的局限，从端到端视角审视整个价值流
- **识别浪费**：清晰区分增值活动与非增值活动（七大浪费）
- **发现瓶颈**：定位制约整体流动的关键工序和环节
- **建立共识**：为团队提供统一的流程认知和改进方向
- **制定路线图**：从当前状态出发，设计未来状态，制定分步实施计划

---

## 关键原则

### 原则一：从客户视角定义价值

价值的定义权在客户手中。只有客户愿意为之付费的活动才是增值活动。在紧固件行业，客户需要的是符合规格、按时交付、价格合理的产品，所有与之直接相关的工序活动才是真正的价值创造。

### 原则二：端到端绘制全流程

VSM必须覆盖完整的价值流，从原材料供应商到最终客户交付。仅分析单个工序或部门是不够的，因为很多浪费发生在工序之间的交接和等待环节。

### 原则三：同时绘制物料流和信息流

VSM的独特之处在于同时展示实物产品的流动和驱动生产的信息流动（订单、计划、看板等）。很多问题的根源在于信息流的不畅或扭曲。

### 原则四：亲自到现场收集数据（Gemba Walk）

VSM的数据必须来自现场实际观测，而非办公室里的估算或系统数据。走现场（Gemba）是绘制准确价值流图的基础。

### 原则五：区分增值与非增值

对每个流程步骤进行增值/非增值分析，重点关注非增值活动的消除和压缩。典型的非增值活动包括：等待、搬运、库存、返工、过度加工等。

### 原则六：改善是持续的过程

VSM不是一次性分析工具，而应定期更新和回顾。随着改善的推进，当前状态图会不断演变，新的未来状态图也会不断被制定和实施。

## 实施步骤

### 第一步：选择价值流范围

明确VSM分析的范围：
- **产品族**：选择具有相似加工路径的产品系列
- **起点和终点**：从原材料入厂到产品发货
- **时间范围**：通常覆盖最近1-3个月的生产情况

### 第二步：绘制当前状态图

#### 2.1 绘制客户和供应商

在VSM图的右侧标注客户信息：
- 客户名称/类型
- 月需求量
- 日均需求量
- 需求模式（稳定/波动）

在VSM图的左侧标注供应商信息：
- 钢丝供应商名称
- 交货频率
- 交货批量
- 前置时间

#### 2.2 绘制信息流

描绘客户需求如何传递到生产系统：
- 订单接收方式（ERP/MES/手工）
- 生产计划排产方式
- 各工序间的信息传递机制
- 电子/纸质信息流

#### 2.3 绘制物料流

逐步绘制每个工序的数据框：

| 数据项 | 说明 |
|--------|------|
| 工序名称 | 工序的名称和编号 |
| 节拍时间（C/T） | 每件产品的加工时间 |
| 换型时间（C/O） | 从一种产品切换到另一种的时间 |
| 可用时间 | 减去计划停机后的有效生产时间 |
| UPH | 每小时产量 |
| 合格率 | 一次合格率 |
| 班次 | 每天的班次数 |
| 操作员人数 | 该工序的操作员数量 |
| 备注 | 其他关键信息 |

#### 2.4 绘制库存三角

在工序间标注库存积压情况：
- 库存数量（件数或天数）
- 取库存时的现场测量日期

#### 2.5 绘制时间线

在VSM图底部绘制时间线：
- 上升段：增值时间（实际加工时间）
- 下降段：非增值时间（等待、库存对应的前置时间）

### 第三步：计算关键指标

- **总前置时间（Total Lead Time）**：所有库存等待时间 + 所有加工时间之和
- **总加工时间（Total Processing Time）**：所有工序实际加工时间之和
- **流程周期效率（PCE）**：总加工时间 / 总前置时间 × 100%

### 第四步：识别改善机会

对当前状态图进行分析，识别：
- 库存积压最严重的环节
- 前置时间最长的环节
- 合格率最低的工序
- 信息流中的延迟和扭曲
- 设备利用率的不均衡

### 第五步：设计未来状态图

基于精益原则设计未来状态：

1. **建立连续流**：在可行的工序间建立一个流
2. **设置拉动点**：在无法实现连续流的地方使用看板拉动
3. **均衡化排产**：在发运端实现均衡化生产
4. **确定节拍时间**：根据客户需求计算节拍时间
5. **减少换型时间**：应用SMED缩短换型时间
6. **改进质量**：提升各工序的一次合格率

### 第六步：制定实施计划

将未来状态分解为具体的改善项目：
- 按优先级排序
- 分配责任人和资源
- 设定完成时间节点
- 确定度量指标

## 增值/非增值活动识别

### 增值活动（VA）

- 冷镦成型：改变钢丝形状，形成螺母毛坯
- 搓丝：形成螺纹，赋予紧固功能
- 热处理：提升机械性能，达到客户要求的强度等级
- 表面处理：提供防腐蚀保护
- 质量检测：验证产品符合规格要求（适度检测为增值）
- 包装：保护产品，便于运输和使用

### 非增值活动（NVA）

| 浪费类型 | 在紧固件生产中的典型表现 |
|----------|--------------------------|
| 过量生产 | 超出订单需求的批量生产 |
| 等待 | 工序间排队等待、等待换模、等待检验结果 |
| 搬运 | 车间内部物料搬运、仓库到车间的转运 |
| 库存 | 原料积压、中间在制品堆积、成品库存过高 |
| 过度加工 | 超出客户要求的精度、不必要的工序步骤 |
| 返工 | 质量不合格品的修复或重新加工 |
| 动作 | 操作员不必要的走动、弯腰、寻找工具 |

## 关键指标/KPI

| 指标 | 定义 | 计算方法 | 目标参考 |
|------|------|----------|----------|
| **总前置时间** | 产品在系统中的总时间 | 各环节库存等待时间 + 加工时间之和 | 持续缩短 |
| **总加工时间** | 所有增值加工时间之和 | 各工序C/T之和 | 持续优化 |
| **流程周期效率（PCE）** | 增值时间占比 | 总加工时间 / 总前置时间 × 100% | 目标 > 25% |
| **增值比** | 增值活动时间占比 | 增值时间 / (增值 + 非增值时间) × 100% | 目标 > 50% |
| **库存周转天数** | 库存可用天数 | 平均库存量 / 日均需求量 | 目标 < 7天 |
| **一次合格率** | 首次加工合格比率 | 合格品数 / 总投入数 × 100% | > 98% |
| **节拍达成率** | 实际产出与节拍的匹配度 | 实际产出 / 目标产出 × 100% | > 95% |

## 紧固件行业具体应用案例

### 案例：汽车螺栓价值流改善

**背景**：某紧固件企业为汽车零部件供应商，生产ISO 898-1高强度螺栓。客户要求JIT交付，但实际交付准时率仅78%，且中间库存高企。

**当前状态分析结果**：
- 总前置时间：32天
- 总加工时间：47秒
- 流程周期效率：0.017%
- 瓶颈工序：热处理（网带炉产能不足）
- 最大浪费：等待（占总非增值时间的45%）

**未来状态改善措施**：
1. 热处理工序增加一台网带炉，消除产能瓶颈
2. 冷镦和搓丝合并为一个连续流单元
3. 建立客户看板拉动系统
4. 原料供应从每周一次改为每日配送

**实施效果**：

| 指标 | 改善前 | 改善后 | 变化 |
|------|--------|--------|------|
| 总前置时间 | 32天 | 8天 | -75% |
| 流程周期效率 | 0.017% | 0.089% | +423% |
| 准时交付率 | 78% | 97% | +19% |
| 中间库存 | 25天 | 5天 | -80% |

## 常见误区

### 误区一：VSM是一次性活动

VSM不是做完一次就束之高阁的分析报告。价值流会随市场需求、产品组合、设备状态的变化而变化。建议每6-12个月重新绘制VSM，或在重大变化时及时更新。

### 误区二：VSM只关注生产部门

价值流跨越多个部门和职能，包括销售、计划、采购、仓储、生产、质量、物流等。仅分析生产环节会遗漏大量的非增值活动和改善机会。

### 误区三：追求完美的当前状态图

初学者往往花大量时间追求当前状态图的完美细节。关键是捕捉足够准确的数据来识别改善方向，而非制作精美的图表。80%的准确性通常已足够支撑决策。

### 误区四：忽略信息流分析

很多团队只关注物料流的绘制，忽略了信息流的分析。实际上，信息流的延迟和失真往往是造成过量生产和等待浪费的根本原因。

### 误区五：未来状态过于理想化

未来状态图应是可实现的改善目标，而非遥不可及的理想状态。过于激进的未来状态会导致团队失去信心。建议设定分阶段的改善里程碑。

### 误区六：VSM数据依赖系统而非现场

仅凭ERP或MES系统中的数据绘制VSM，可能与现场实际情况存在偏差。系统数据反映的是计划值，而VSM需要反映实际值。必须到现场亲自测量和观察。
