### 01 看板 Kanban

| 维度 | 传统 | 升级路径 |
|------|------|---------|
| D | 纸质看板 | → 电子看板(电视屏) → 数字看板(MES集成) → AI动态看板(自动调批量) |
| G | 不关注能耗 | → 看板显示工序能耗 → 看板含碳足迹指标 → 碳约束看板(高碳时自动限产) |
| R | 固定批量 | → 动态批量(考虑供应波动) → 异常看板(红色预警+替代方案) → 韧性看板(多情景仿真) |
| H | 班组看板 | → 团队协作看板(改善建议嵌入) → 人机看板(AI推荐+人确认) → 自主管理看板(员工自组织) |

**关键转变**: 看板从"信息展示"升级为"决策支持+异常预警"系统。

## 工具间协同升级

传统工具间协同主要是"精益屋"结构（JIT+自働化为两大支柱）。Lean 2.0升级后，工具间协同新增：

```
传统协同：JIT + Jidoka → 零缺陷+零库存
                    ↓ I5.0升级
Lean 2.0协同：

D层：数字VSM → AI排产 → 数字看板 → 预测维护 → 数字双胞胎
G层：碳足迹VSM → 绿色JIT → 绿色Kaizen → 碳绩效看板 → CBAM合规
R层：韧性VSM → JIT+Buffer → 异常安灯 → 应急SOP → 韧性指数
H层：共创VSM → 人机协作排产 → AI辅助改善 → 人机共检 → 自主管理

跨层协同示例：
- 碳足迹VSM(G) × AI排产(D) = 碳约束智能排产
- 预测维护(D) × 人机协作(H) = AI建议+人确认的预测性TPM
- JIT+Buffer(R) × 绿色JIT(G) = 低碳韧性拉动系统
- AI视觉检测(D) × 人机共检(H) × 碳异常检测(G) = 三维Jidoka
```

## 使用方法

1. **评估当前状态**: 使用 `/lean20` 雷达图确定各维度成熟度
2. **选择升级工具**: 根据最大短板维度，选择对应升级路径
3. **制定升级计划**: 每个工具选1-2个升级步骤（不要跳级）
4. **验证升级效果**: 升级后重新评估，确认维度得分提升
5. **迭代**: 持续升级，工具间协同效应会逐步显现

**原则**: 升级不是替代，是扩展。传统精益工具的底层逻辑（消除浪费/创造价值）不变，I5.0维度是叠加增强。

## Lean2.0升级实施路线图

```
Phase 1 (0-3月): 基线评估+短板识别
├── 完成Lean2.0五维度评估(O/D/G/R/H)
├── 识别最薄弱维度（通常O先做，因基础最牢）
├── 为短板维度选择1-2个升级工具
├── 设定季度改善目标（每维度+0.5分）
└── 输出：升级优先级 + 工具选择 + 目标值

Phase 2 (3-9月): 单维度突破
├── 按升级路径实施选定工具
├── 每月检视进度+问题
├── 3个月后复评，确认维度提升
├── 6个月后启动第二维度升级
└── 输出：1-2个维度升级成功 + SOP固化

Phase 3 (9-18月): 跨维度协同
├── 第三/四维度升级启动
├── 重点做跨层协同（D×G碳约束排产/D×H人机TPM等）
├── 工具间数据打通（数字VSM数据流向看板→排产→TPM）
└── 输出：协同效应显现 + 综合得分>L3

Phase 4 (18-30月): 体系成熟
├── 五维度全面进入升级路径
├── 跨层协同常态化
├── Lean2.0成熟度>L4
├── 升级路径从"跟随"变为"创新"
└── 输出：行业领先的Lean2.0运营体系
```
