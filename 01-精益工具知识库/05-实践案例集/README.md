## 案例使用说明

### 🎯 如何选择适合的案例

1. **按工序选择**：找到与您所在工序相同的案例
2. **按问题类型选择**：根据面临的具体问题选择对应案例
3. **按工具方法选择**：学习特定工具的应用方法

### 📖 案例学习路径

**初学者建议：**
1. 先阅读[精益改善提案模板](02-精益改善提案模板.md)
2. 了解标准化的改善流程
3. 再学习具体的工序案例

**实践者建议：**
1. 直接参考与您问题相似的案例
2. 借鉴其中的分析方法和解决方案
3. 根据自身情况调整实施

### 🛠️ 案例应用方法

1. **分析借鉴**：理解案例中的问题分析思路
2. **方案调整**：根据自身条件调整改善方案
3. **数据收集**：建立自己的数据收集机制
4. **小步实施**：先试点再推广，控制风险
5. **持续改进**：建立长效机制，持续优化

## 案例贡献指南

### 📝 案例编写规范

鼓励各团队分享自己的改善案例，编写时请遵循以下规范：

1. **结构完整**：包含背景、问题、分析、方案、效果等部分
2. **数据详实**：提供具体的数据支持
3. **图文并茂**：适当添加图表和照片
4. **经验总结**：提炼可复制的经验和方法
