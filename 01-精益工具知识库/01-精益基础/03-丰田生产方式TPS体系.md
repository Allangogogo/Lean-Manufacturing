## 1. TPS 概述

### 1.1 什么是 TPS

TPS（Toyota Production System，丰田生产方式）是丰田汽车公司经过数十年实践总结而成的一套完整的生产管理体系。它的目标是**通过消除浪费来提高效率和质量，同时尊重每一位员工**。

TPS 的核心思想可以概括为：

> **用最少的资源（人、设备、时间、空间），在正确的时间，生产正确数量的正确产品。**

### 1.2 TPS 的起源背景

1950年代，丰田公司面临以下困境：

- 资金短缺，无法像美国企业那样维持大量库存
- 市场规模有限，无法实现大批量生产
- 劳动力成本虽然较低，但需要提高生产效率
- 质量问题是打开市场的关键

在大野耐一等人的推动下，丰田逐步发展出了一套与传统大批量生产截然不同的生产方式，后来被证明具有全球性的示范意义。

### 1.3 TPS 的核心理念

| 理念 | 说明 |
|------|------|
| 消除浪费 | 一切不创造价值的活动都是浪费，必须消除 |
| 尊重人性 | 员工是最重要的资源，要尊重和培养每个人 |
| 持续改善 | 追求永无止境的改进，每天进步一点点 |
| 现地现物 | 到现场去，看实物，了解实际情况 |

## 2. TPS 房屋模型

### 2.1 TPS 房屋的结构

TPS 通常以"房屋"模型来展示其体系结构。房屋模型将 TPS 的各个要素以建筑结构的形式呈现，形象地说明了各要素之间的关系。

```
┌─────────────────────────────────────────────────────┐
│                   客户满意                             │
│            (质量 · 成本 · 交期)                       │
├─────────────────────────────────────────────────────┤
│                                                       │
│    ┌──────────────┐         ┌──────────────┐         │
│    │              │         │              │         │
│    │   自働化      │         │   准时化      │         │
│    │  (Jidoka)    │         │   (JIT)      │         │
│    │              │         │              │         │
│    │  内建质量     │         │  消除浪费     │         │
│    │              │         │              │         │
│    └──────────────┘         └──────────────┘         │
│                                                       │
├─────────────────────────────────────────────────────┤
│          稳 定 的 作 业 （均 衡 化 · 标 准 作 业）       │
├─────────────────────────────────────────────────────┤
│                                                       │
│    ┌─────────────────────────────────────────┐       │
│    │       改善（Kaizen）· 尊重人性             │       │
│    └─────────────────────────────────────────┘       │
│                                                       │
└─────────────────────────────────────────────────────┘
```

### 2.2 各层含义解读

| 层级 | 内容 | 说明 |
|------|------|------|
| **屋顶** | 客户满意（质量、成本、交期） | TPS 的最终目标 |
| **左支柱** | 自働化（Jidoka） | 内建质量，防止不良品流出 |
| **右支柱** | 准时化（JIT） | 在正确的时间生产正确数量 |
| **地基** | 稳定的作业 | 均衡化和标准作业是两大支柱的基础 |
| **根基** | 改善与尊重 | 持续改善的文化和尊重人性的理念 |

### 2.3 TPS 房屋的启示

房屋模型传达了几个关键信息：

1. **各要素相互依存**：缺少任何一个要素，房屋就会不稳固
2. **基础必须牢固**：标准作业和均衡化是所有改善的前提
3. **两大支柱缺一不可**：只有 JIT 没有 Jidoka，质量问题会爆发；只有 Jidoka 没有 JIT，效率无法提升
4. **改善和尊重是根基**：没有持续改善的文化，TPS 无法持续运行

## 3. 支柱一：自働化（Jidoka）

### 3.1 自働化的含义

"自働化"中的"働"字是丰田创造的汉字，意为"有人的智慧的自动化"。它不是简单的机器自动化，而是指**设备在检测到异常时能够自动停止，防止不良品继续生产**。

### 3.2 自働化的核心原则

| 原则 | 说明 |
|------|------|
| 异常自动停机 | 设备检测到异常时自动停止 |
| 问题可视化 | 通过安灯（Andon）系统暴露问题 |
| 防止再发 | 分析根本原因，建立防错机制 |
| 人机分离 | 人不做机器的看守者 |

### 3.3 自働化的三大工具

#### 安灯系统（Andon）

安灯系统是一种视觉信号系统，用于即时报告生产线上的异常情况。

- **绿色**：正常运行
- **黄色**：需要关注，可能存在潜在问题
- **红色**：异常停线，需要立即处理

在生产线上，安灯可以安装在每个关键工序旁边，操作者发现问题时拉绳或按按钮即可发出信号。

#### 防错装置（Poka-Yoke）

防错装置是一种设计机制，用于防止人为失误导致的不良品。

制造业常用的防错方式：

| 防错类型 | 说明 | 应用场景 |
|---------|------|---------|
| 接触式 | 通过形状或尺寸检测 | 零件方向检测、缺件检测 |
| 固定值式 | 检查计数是否达到设定值 | 每箱数量确认 |
| 动作步骤式 | 确认动作顺序是否正确 | 装配工序的顺序确认 |
| 信息提示式 | 提供正确操作的指引 | 标准作业看板 |

#### 标准作业（Standardized Work）

标准作业是将最佳实践固化为标准操作程序，确保每次操作的一致性和高质量。

标准作业三要素：

1. **节拍时间（Takt Time）**：客户需求的节奏
2. **作业顺序**：操作的正确步骤
3. **标准在制品**：完成作业所需的最少在制品数量

### 3.4 自働化在制造业的应用

| 工序 | 自働化应用 |
|------|-----------|
| 机加工 | 监控冲压力，异常自动停机 |
| 精加工 | 尺寸在线检测，超差自动剔除 |
| 热处理 | 温度异常报警，自动调节 |
| 表面处理 | 镀层厚度在线监控 |
| 检验 | 自动检测设备替代人工检验 |
| 包装 | 自动计数和称重验证 |

## 4. 支柱二：准时化（JIT）

### 4.1 JIT 的含义

准时化（Just-In-Time）是指**在需要的时间，将需要的物品，以需要的数量，送到需要的地点**。

JIT 的目标是消除一切与时间相关的浪费：
- 等待时间
- 提前生产的时间
- 库存持有时间
- 搬运时间

### 4.2 JIT 的三大核心工具

#### 看板（Kanban）

看板是 JIT 系统中最重要的信息传递工具，用于控制物料的生产和搬运。

**看板的类型**：

| 类型 | 功能 | 说明 |
|------|------|------|
| 生产看板 | 指示生产 | 下游工序用看板向上游发出生产指令 |
| 搬运看板 | 指示搬运 | 标识物料从何处搬到何处 |
| 信号看板 | 批量生产信号 | 当库存降到补货点时触发批量生产 |
| 供应商看板 | 向供应商订货 | 控制外部采购物料的补货 |

**看板运行规则**：

1. 下游工序只在需要时向上游取件
2. 上游工序只生产下游取走的数量
3. 不良品不传递到下游
4. 看板附着在实物上移动
5. 逐步减少看板数量以暴露问题

#### 拉动系统（Pull System）

拉动系统是 JIT 的核心运行机制。与推动式生产不同，拉动式生产由下游需求驱动上游生产。

```
推动式（Push）：
  计划 → 原材料 → 机加工 → 精加工 → 热处理 → 表面处理 → 检验 → 包装 → 成品库
  （每个工序按计划独立生产，向前推送）

拉动式（Pull）：
  成品库 ← 包装 ← 检验 ← 表面处理 ← 热处理 ← 精加工 ← 机加工 ← 原材料
  （每个工序只在下游需要时才生产）
```

#### 均衡化（Heijunka）

均衡化是指将产品种类和数量在一段时间内平均分配，避免生产大幅波动。

**均衡化的两种类型**：

- **数量均衡**：每天的总产量保持稳定
- **品种均衡**：每天生产的产品品种混合搭配

**在制造业的应用**：

假设一个月需要生产 A 规格 60 万件、B 规格 30 万件、C 规格 10 万件：

| 方式 | 说明 | 优缺点 |
|------|------|--------|
| 批量生产 | 月头生产 A，月中生产 B，月末生产 C | 换模少但库存大、交期长 |
| 均衡生产 | 每天生产 A 2万 + B 1万 + C 3333 | 换模多但库存低、交期短 |

### 4.3 JIT 在制造业的挑战与应对

| 挑战 | 应对策略 |
|------|---------|
| 热处理是瓶颈工序 | 合理排程、热处理产能规划 |
| 换模时间长 | SMED 快速换模改善 |
| 供应商交期不稳定 | 供应商管理、安全库存策略 |
| 需求波动大 | 均衡化生产、柔性产能 |
| 多品种小批量 | 产品族分类、细胞化生产 |

## 5. TPS 核心要素详解

### 5.1 平准化生产（Heijunka）

平准化是 TPS 的基础要素，是实现 JIT 的前提条件。

**平准化的关键步骤**：

1. 统计各产品的月/周需求量
2. 计算每日平均需求
3. 确定生产节拍（Takt Time）
4. 安排每日混流生产计划
5. 在现场用平准化板（Heijunka Box）可视化

**节拍时间计算公式**：

```
节拍时间 = 每日可用工作时间 / 每日客户需求量
```

**示例**：
- 每日可用工作时间：450 分钟（8小时 × 60分钟 - 30分钟休息）
- 每日客户需求：某型号 工件 90,000 件
- 节拍时间 = 450 × 60 / 90,000 = 0.3 秒/件

### 5.2 标准作业（Standardized Work）

标准作业是将当前最佳操作方法固化为标准，确保每次操作都能达到一致的质量和效率。

**标准作业组合表**的内容：

| 项目 | 说明 |
|------|------|
| 作业顺序 | 操作的步骤序列 |
| 每步时间 | 每个步骤的标准时间 |
| 走动路线 | 操作者的移动路径 |
| 标准在制品 | 维持作业所需的最少在制品 |

**标准作业的三个文件**：

1. **作业要领书**：描述每个操作步骤的要点和注意事项
2. **标准作业组合表**：将人和设备的作业时间组合在一起
3. **工序能力表**：记录每台设备的加工能力

**标准作业的维护原则**：

- 标准是当前最佳实践，不是永久不变的
- 每次改善后都要更新标准作业
- 标准作业是改善的起点，不是终点
- 操作者参与制定和改进标准作业

### 5.3 快速换模（SMED）

SMED（Single-Minute Exchange of Die）由新乡重夫开发，目标是将换模时间缩短到个位数分钟（Single Digit）。

**SMED 的三个阶段**：

| 阶段 | 目标 | 方法 |
|------|------|------|
| 区分内部和外部 | 将换模作业分为内部作业（必须停机）和外部作业（不停机也可做） | 作业分析 |
| 将内部转为外部 | 尽量将内部作业转为外部作业 | 并行准备、标准化 |
| 缩短内部作业时间 | 优化剩余的内部作业 | 快速锁紧、位置对准 |

**SMED 在制造业的应用**：

机加工设备换模的典型改善：

| 改善前 | 改善后 |
|--------|--------|
| 换模时间 120 分钟 | 换模时间 15 分钟 |
| 换模时停机 | 外部准备不停机 |
| 模具现场找 | 模具定位存放 |
| 手动调整 | 快速锁紧装置 |
| 试模次数多 | 标准化参数设置 |

### 5.4 全面生产维护（TPM）

TPM（Total Productive Maintenance）是确保设备可靠性的系统性方法。

**TPM 的八大支柱**：

| 支柱 | 说明 |
|------|------|
| 自主维护 | 操作者负责日常保养 |
| 计划维护 | 基于时间或状态的维护计划 |
| 个别改善 | 针对设备损失的重点改善 |
| 教育训练 | 提升员工的维护技能 |
| 初期管理 | 新设备的高效导入 |
| 品质维护 | 确保设备不产生不良品 |
| 事务改善 | 办公和管理部门的效率提升 |
| 安全环境 | 消除安全隐患和环境问题 |

**TPM 的核心指标 —— OEE（设备综合效率）**：

```
OEE = 时间开动率 × 性能开动率 × 合格品率
```

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| 时间开动率 | 实际运行时间 / 计划运行时间 | ≥ 90% |
| 性能开动率 | 实际产出 / 理论产出 | ≥ 95% |
| 合格品率 | 合格品数量 / 总产出数量 | ≥ 99% |
| **OEE** | **三者相乘** | **≥ 85%** |

## 6. TPS 与精益制造的关系

### 6.1 TPS 是精益的源头

```
TPS（丰田生产方式）
  ↓ 1990年《改变世界的机器》
精益生产（Lean Production）
  ↓ 扩展到各行业
精益思想（Lean Thinking）
  ↓ 细分领域
精益创业 · 精益软件开发 · 精益医疗 · 精益建筑 ...
```

### 6.2 核心关系

| 关系维度 | TPS | 精益制造 |
|---------|-----|---------|
| 范围 | 丰田的内部实践 | 全球通用的方法论 |
| 核心 | 两大支柱（Jidoka + JIT） | 五大原则 |
| 工具 | 看板、安灯、SMED 等 | TPS 工具 + 更多扩展工具 |
| 文化 | 丰田特有的改善文化 | 通用的持续改善理念 |
| 目标 | 最高质量、最低成本、最短交期 | 消除浪费、创造价值 |

### 6.3 精益对 TPS 的扩展

精益在 TPS 的基础上增加了以下内容：

- **价值流管理**：更系统的价值流分析和改善方法
- **价值流图（VSM）**：可视化的现状分析工具
- **精益领导力**：领导者在精益转型中的角色定义
- **精益文化**：全员参与的改善文化建设方法
- **精益供应链**：将精益延伸到供应商和客户

## 7. TPS 在制造业的应用框架

### 7.1 产品生产的典型工艺流程

```
原材料（卷料/原材料）
    ↓
拉丝（Drawing）
    ↓
酸洗/磷化（Pickling/Phosphating）
    ↓
机加工（Machining）
    ↓
精加工（Precision Machining）
    ↓
热处理（Heat Treatment）
    ↓
表面处理（Surface Treatment）
    ↓
质量检验（Quality Inspection）
    ↓
包装入库（Packing & Warehousing）
    ↓
客户交付（Delivery）
```

### 7.2 各工序的 TPS 应用重点

| 工序 | TPS 应用重点 | 关键工具 |
|------|-------------|---------|
| 拉丝 | 原材料质量稳定、换线快速 | 标准作业、SMED |
| 机加工 | 模具寿命管理、设备稳定性 | TPM、防错、安灯 |
| 精加工 | 尺寸质量控制、快速换型 | 防错、SMED、标准作业 |
| 热处理 | 温度均匀性、批量管理 | SPC、标准作业、看板 |
| 表面处理 | 镀层质量、环保合规 | 防错、标准作业 |
| 检验 | 检验效率和准确性 | 自动检测、SPC |
| 包装 | 数量准确性、标签正确 | 防错、标准作业 |

### 7.3 制造业 TPS 实施路线

| 阶段 | 核心任务 | TPS 工具 | 时间 |
|------|---------|---------|------|
| 第一阶段 | 现状诊断 | 价值流图、时间观测 | 1-2 个月 |
| 第二阶段 | 基础建设 | 5S、标准作业、安灯 | 2-4 个月 |
| 第三阶段 | 质量内建 | 防错、自働化、TPM | 3-6 个月 |
| 第四阶段 | 流动生产 | 看板、拉动系统、SMED | 4-8 个月 |
| 第五阶段 | 均衡化 | Heijunka、节拍管理 | 6-12 个月 |
| 第六阶段 | 持续改善 | 全员改善、改善提案 | 持续进行 |

## 8. TPS 实施的关键成功因素

### 8.1 领导层的承诺与参与

- 高层管理者必须亲自参与和推动
- 设定清晰的精益愿景和目标
- 提供必要的资源（时间、资金、人员）
- 以身作则，到现场去（Gemba）
- 容忍短期的效率下降，关注长期收益

### 8.2 尊重员工，全员参与

- 一线员工是最了解问题的人
- 给予员工发现问题和解决问题的权力
- 建立提案制度，鼓励改善建议
- 表彰和奖励改善成果
- 培养员工的精益思维和问题解决能力

### 8.3 现地现物（Genchi Genbutsu）

- 到现场去，看实物，了解实际情况
- 不要仅依赖报告和数据做决策
- 观察实际操作，发现隐藏的浪费
- 与现场人员直接沟通

### 8.4 持续改善的文化

- 今天的最好表现是明天的最低要求
- 小改善积累成大变革
- 失败是学习的机会，不是惩罚的理由
- 建立 PDCA（计划-执行-检查-行动）循环

### 8.5 系统性思维

- TPS 是一个整体系统，不是工具的简单堆砌
- 各要素相互关联，需要同步推进
- 避免只做局部优化而忽视整体效果
- 关注端到端的价值流，而非单个工序

### 8.6 长期视角

- TPS 的建立需要 3-5 年甚至更长时间
- 不要期望立竿见影的效果
- 基础越牢固，上层建筑越稳固
- 持续投入，不要半途而废

## 9. TPS 实施案例

### 9.1 案例：某制造企业 TPS 转型

**背景**：

某制造企业，年产量约 2 万吨，主要产品为工件和法兰工件。面临的问题包括：库存周转率低（2.5 次/年）、准时交付率仅 85%、不良率 800 PPM。

**改善过程**：

| 阶段 | 时间 | 主要措施 | 成果 |
|------|------|---------|------|
| 现状诊断 | 第1-2月 | 绘制 VSM、时间观测、浪费识别 | 确定了主要瓶颈和浪费点 |
| 基础建设 | 第3-6月 | 5S、标准作业、安灯系统 | 现场管理基础建立 |
| 质量内建 | 第5-9月 | 机加工防错装置、精加工在线检测 | 不良率降至 350 PPM |
| 流动生产 | 第8-14月 | 看板系统、拉动式生产 | 库存周转率提升至 4.2 次/年 |
| 快速换模 | 第10-16月 | SMED 改善、模具标准化 | 换模时间从 90 分钟降至 20 分钟 |
| 持续改善 | 第12月起 | 改善提案、QC 圈 | 全员参与改善 |

**最终成果**（18个月后）：

| 指标 | 改善前 | 改善后 | 提升幅度 |
|------|--------|--------|---------|
| 库存周转率 | 2.5 次/年 | 5.1 次/年 | +104% |
| 准时交付率 | 85% | 96% | +11% |
| 不良率 | 800 PPM | 280 PPM | -65% |
| 换模时间 | 90 分钟 | 20 分钟 | -78% |
| OEE | 62% | 81% | +19% |
| 人均产出 | 基准 | +35% | +35% |

### 9.2 成功的关键因素分析

1. **高层亲自推动**：总经理每周参加精益推进会议
2. **选择正确的试点**：从一条产线开始，取得成果后推广
3. **重视基础建设**：花足够时间建立标准作业和 5S
4. **全员培训**：对所有管理者和班组长进行 TPS 系统培训
5. **持续跟踪**：建立月度精益指标看板，持续跟踪改善进度
