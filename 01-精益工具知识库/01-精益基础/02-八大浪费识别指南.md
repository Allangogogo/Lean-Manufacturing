## 1. 八大浪费概述

### 1.1 DOWNTIME 助记词

八大浪费可以用英文首字母缩写 **DOWNTIME** 来记忆：

| 序号 | 英文 | 中文 | 简要说明 |
|------|------|------|---------|
| D | Defects | 不良品 | 生产出不合格产品 |
| O | Overproduction | 过量生产 | 生产超过需求的数量 |
| W | Waiting | 等待 | 人或设备处于空闲等待状态 |
| N | Non-utilized Talent | 人才浪费 | 未充分发挥员工的技能和智慧 |
| T | Transportation | 搬运 | 物料在工序间的不必要移动 |
| I | Inventory | 库存 | 过多的原材料、半成品或成品 |
| M | Motion | 动作 | 人员不创造价值的身体动作 |
| E | Extra-processing | 过度加工 | 超出客户要求的加工或检验 |

### 1.2 浪费的层次

在实际分析中，浪费分为三个层次：

1. **Muda（浪费）**：不创造价值的活动
2. **Mura（波动）**：流程中的不均衡，导致浪费产生
3. **Muri（过劳）**：超出合理负荷的作业安排

精益改善需要同时关注这三个层次，仅消除 Muda 而忽视 Mura 和 Muri，改善效果将不可持续。

### 1.3 浪费识别的基本原则

- **从客户视角判断**：客户是否愿意为这项活动付费？
- **区分增值与非增值**：增值活动是客户认可并愿意付费的活动
- **不要只看明显浪费**：隐性浪费往往更难发现但影响更大
- **尊重一线员工**：现场操作者最了解实际浪费在哪里

## 2. D1 - Defects 不良品浪费

### 2.1 定义

生产出不符合规格要求的产品，导致返工、报废或客户投诉。

### 2.2 制造业的典型表现

#### 尺寸超差

- 外径、内径、关键尺寸超差
- 头部对边宽度、外形高度不在公差范围内
- 杆部长度超差
- 垫片面不平度超标

#### 尺寸不良

- 表面烂纹、滑牙
- 量规检测不通过
- 表面粗糙度超标
- 轮廓角度偏差

#### 热处理变形

- 淬火后弯曲变形
- 配合面变形导致无法装配
- 硬度不均匀（同一产品不同位置硬度差异大）
- 渗碳层深度不达标

#### 表面处理缺陷

- 电镀层厚度不均匀
- 镀锌后白锈、红锈
- 磷化膜附着力差
- 发黑层颜色不一致

### 2.3 识别方法

- **质量数据统计**：收集各工序的不良率数据（PPM、不良率%）
- **客户投诉分析**：按类型、频率、严重程度分类统计
- **返工/报废记录**：建立不良品台账，追踪根本原因
- **SPC 控制图**：监控关键尺寸的波动趋势
- **防错验证**：检查现有防错措施的有效性

### 2.4 改善方向

| 改善策略 | 具体措施 |
|---------|---------|
| 源头控制 | 来料检验强化、原材料质量追溯 |
| 过程防错 | 安装防错装置、传感器检测 |
| 标准作业 | 制定并执行标准操作规程 |
| 设备维护 | 定期校准、精度保持（TPM） |
| 培训赋能 | 操作者技能培训、质量意识教育 |
| 快速反馈 | 异常发生时即时停线、即时处理 |

### 2.5 典型案例

**案例：某工厂尺寸不良率改善**

- **问题**：某型号 工件量规检测不良率 2.3%
- **分析**：通过鱼骨图分析发现，主要原因是加工刀具磨损未及时更换
- **改善**：
  - 建立加工刀具寿命管理台账
  - 安装自动检测装置
  - 制定加工刀具更换标准
- **效果**：不良率从 2.3% 降至 0.15%

## 3. D2 - Overproduction 过量生产浪费

### 3.1 定义

生产超过客户需求的数量或提前生产，是八大浪费中最严重的浪费——因为它会引发其他所有浪费。

### 3.2 为什么过量生产被称为"万恶之源"

过量生产直接导致：
- **库存增加**：多余产品需要存储空间和管理
- **搬运增加**：多余产品需要搬运和转移
- **资金占用**：原材料和成品占用流动资金
- **过期风险**：库存时间过长可能导致生锈、氧化
- **掩盖问题**：充足的库存掩盖了生产和质量问题

### 3.3 制造业的典型表现

| 表现形式 | 具体场景 | 根本原因 |
|---------|---------|---------|
| 超订单生产 | 客户要 10 万件，生产 12 万件 | 担心不良品不够用 |
| 批量过大 | 一次生产 100 万件，库存积压数月 | 追求设备利用率 |
| 提前生产 | 客户下周要货，本周就生产完 | 不信任后工序能力 |
| 安全库存过高 | 各工序都设置大量安全库存 | 缺乏拉动机制 |
| 计划不准确 | 生产计划与实际订单脱节 | 预测式计划的偏差 |

### 3.4 识别方法

- **产出与订单对比**：比较实际产出与客户订单数量的差异
- **库存周转率分析**：周转率低说明存在过量生产
- **成品库龄分析**：库龄超过一定天数的产品占比
- **工序间 WIP 监控**：半成品积压情况

### 3.5 改善方向

- **建立拉动式生产**：基于客户订单组织生产
- **缩短换模时间**：使小批量生产经济可行
- **均衡化生产（Heijunka）**：平准化生产计划，避免集中大批量
- **提升质量水平**：减少因不良品补产的需要
- **合理设定安全库存**：基于实际需求和交付周期计算

## 4. D3 - Waiting 等待浪费

### 4.1 定义

人员或设备在等待物料、信息、工具、指示或上一道工序完成时产生的空闲时间。

### 4.2 制造业的典型表现

| 等待类型 | 具体场景 | 影响 |
|---------|---------|------|
| 等待物料 | 机加工工序等待原材料到货 | 产线停机、交期延误 |
| 等待模具 | 换模过程中产线停机 | 生产效率下降 |
| 等待质检 | 产品等待检验员检验 | 在制品积压、交期延长 |
| 等待设备 | 热处理炉排队等待装炉 | 生产节拍不均衡 |
| 等待信息 | 等待生产计划或工艺参数确认 | 停工待料 |
| 等待维修 | 设备故障等待维修人员 | 非计划停机 |
| 等待叉车 | 物料搬运等待叉车调度 | 工序衔接中断 |

### 4.3 识别方法

- **时间观测**：对各工序进行时间观测，记录空闲时间
- **OEE 分析**：通过设备综合效率中的可用率指标发现等待
- **工序平衡分析**：识别各工序节拍差异导致的等待
- **走动观察**：现场巡视，记录员工和设备的等待状态

### 4.4 改善方向

- **快速换模（SMED）**：减少换模停机时间
- **标准作业**：明确每道工序的作业时间和顺序
- **多能工培养**：减少因人员缺勤导致的等待
- **预防性维护（TPM）**：减少设备故障导致的等待
- **信息可视化**：看板、电子屏等实时显示生产信息
- **产线平衡**：消除瓶颈工序，均衡各工序节拍

### 4.5 典型案例

**案例：机加工工序等料问题改善**

- **问题**：机加工线平均每班等待原材料 45 分钟
- **分析**：原材料仓库到车间的配送不及时，缺乏标准化的物料配送流程
- **改善**：
  - 建立定时定量配送制度（水蜘蛛模式）
  - 设置线边标准料架
  - 与仓库建立看板拉动机制
- **效果**：等待时间从 45 分钟/班降至 8 分钟/班

## 5. D4 - Non-utilized Talent 人才浪费

### 5.1 定义

未能充分利用员工的技能、知识、经验和创造力，是八大浪费中最容易被忽视的浪费。

### 5.2 制造业的典型表现

| 表现形式 | 具体场景 | 后果 |
|---------|---------|------|
| 技能未发挥 | 高技能员工只做简单操作 | 人力资源浪费 |
| 缺乏参与 | 改善提案制度形同虚设 | 员工积极性低 |
| 单能工 | 员工只能操作一种设备 | 排班灵活性差 |
| 沟通不畅 | 一线员工的改进建议传不到管理层 | 最佳实践无法推广 |
| 人才流失 | 有经验的员工离职，知识未传承 | 经验断层 |
| 过度指挥 | 管理者事无巨细地控制操作细节 | 员工主动性丧失 |

### 5.3 识别方法

- **技能矩阵分析**：评估每位员工的技能水平和多能工程度
- **改善提案统计**：统计员工提案数量和采纳率
- **员工满意度调查**：了解员工对自身工作的看法
- **离职面谈分析**：了解人才流失的原因

### 5.4 改善方向

- **建立改善提案制度**：鼓励全员参与改善，给予物质和精神奖励
- **多能工培训**：制定技能矩阵，系统性地培训员工多技能
- **授权赋能**：赋予一线员工停线权和问题解决的自主权
- **质量圈（QC 圈）活动**：组织基层员工的小组改善活动
- **知识管理**：将老员工的经验文档化，建立企业知识库
- **职业发展通道**：为技术工人建立清晰的职业成长路径

## 6. D5 - Transportation 搬运浪费

### 6.1 定义

物料、产品或信息在不同地点之间的移动，且该移动不创造价值。

### 6.2 制造业的典型表现

| 搬运类型 | 具体场景 | 不良后果 |
|---------|---------|---------|
| 工序间搬运 | 从机加工车间到热处理车间 | 搬运时间、损坏风险 |
| 仓库到产线 | 原材料从仓库运到车间 | 等待时间增加 |
| 产线到仓库 | 成品从产线运到成品仓 | 搬运设备和人员投入 |
| 跨楼层搬运 | 不同楼层间的物料转移 | 效率极低、安全隐患 |
| 重复搬运 | 同一批物料多次搬进搬出 | 时间和人力浪费 |
| 返工搬运 | 不良品从产线运到返工区 | 额外搬运成本 |

### 6.3 识别方法

- **布局分析**：绘制工厂布局图，标注各工序位置和搬运路径
- **搬运距离测量**：测量各工序间的搬运距离
- **搬运频次统计**：记录各搬运路线的日搬运次数
- **搬运成本核算**：统计叉车、搬运工、容器等搬运成本
- **价值流图**：在 VSM 中标注搬运环节

### 6.4 改善方向

- **优化布局**：按产品族布置设备（U 型线、单元线）
- **消除搬运**：将相关工序紧凑布置，实现连续流
- **减少搬运距离**：重新规划车间布局
- **减少搬运频次**：提高单次搬运量（在合理范围内）
- **自动化搬运**：传送带、AGV、滑道等

### 6.5 改善原则

布局改善的优先级：

1. **消除**：能否通过工艺整合完全消除搬运？
2. **减少**：能否通过布局优化减少搬运距离和频次？
3. **简化**：能否简化搬运方式（如重力滑道代替叉车）？
4. **自动化**：能否用自动化设备替代人工搬运？

## 7. D6 - Inventory 库存浪费

### 7.1 定义

超出当前生产或客户需求的原材料、在制品（WIP）和成品的持有量。

### 7.2 库存浪费的六大成本

| 成本类别 | 说明 |
|---------|------|
| 资金成本 | 库存占用流动资金，产生利息成本 |
| 仓储成本 | 仓库租金、管理人员、设备维护 |
| 损耗成本 | 生锈、氧化、过期、损坏 |
| 管理成本 | 盘点、记账、系统维护 |
| 机会成本 | 资金被库存占用，无法用于其他投资 |
| 隐性成本 | 掩盖生产问题，阻碍改善 |

### 7.3 制造业的典型表现

| 库存类型 | 具体表现 | 风险 |
|---------|---------|------|
| 原材料库存 | 卷料、原材料大量囤积 | 占用资金、锈蚀 |
| 半成品库存 | 机加工后等待热处理的在制品 | 数量不清、管理困难 |
| 模具库存 | 各种规格模具大量储备 | 占用空间、维护成本 |
| 成品库存 | 各规格成品长期存放 | 氧化、生锈、客户变更 |
| 备件库存 | 设备备件大量储备 | 部分备件可能永远不用 |

### 7.4 识别方法

- **库存周转率计算**：年度销售成本 / 平均库存金额
- **库存天数分析**：各品类库存可满足的天数
- **ABC 分析**：按价值和使用频率对库存分类
- **呆滞物料分析**：超过一定期限未动的库存
- **库存地图**：标注仓库各区域的库存状况

### 7.5 改善方向

- **建立拉动系统**：用看板控制补货，避免过量补货
- **缩短换模时间**：使小批量生产经济可行，降低成品库存
- **VMI（供应商管理库存）**：与供应商合作管理原材料库存
- **均衡化生产**：避免集中大批量生产导致的库存积压
- **先进先出（FIFO）**：防止库存老化和变质
- **降低废品率**：减少因质量问题导致的安全库存需求

## 8. D7 - Motion 动作浪费

### 8.1 定义

人员在作业过程中不创造价值的身体动作，如弯腰、转身、行走、伸手取料等。

### 8.2 制造业的典型表现

| 动作类型 | 具体场景 | 影响 |
|---------|---------|------|
| 弯腰拾取 | 从地面拾取零件或工具 | 腰部疲劳、效率低下 |
| 转身操作 | 背对传送带取料再转身加工 | 不必要的动作时间 |
| 长距离取料 | 工具或物料放置在远处 | 增加走动时间 |
| 重复动作 | 同一动作反复多次才完成 | 体力消耗、效率低 |
| 等待动作 | 手持零件等待设备加工 | 人机不平衡 |
| 寻找动作 | 工具、量具找不到需要寻找 | 时间浪费 |

### 8.3 动作经济原则

基尔布瑞斯（Gilbreth）提出的动作经济原则：

1. **双手同时动作**：双手应同时开始并完成动作
2. **动作对称**：双手的动作应对称进行
3. **利用重力**：利用重力进行物料传送
4. **减少动作级别**：手指 > 手腕 > 前臂 > 上臂 > 全身
5. **利用惯性**：利用物体惯性减少施力
6. **节奏感**：建立自然、有节奏的作业模式
7. **工位布局合理**：工具和物料放在最佳位置

### 8.4 识别方法

- **动作分析**：对操作者进行动作分解和分析
- **摄像分析**：录制操作过程，反复观看分析动作
- **双手操作分析**：记录双手的动作和空闲时间
- **走动路径图**：绘制操作者的走动路线

### 8.5 改善方向

- **优化工位布局**：工具和物料放在最佳取用位置
- **减少走动**：缩短操作者与物料/工具的距离
- **利用治具**：设计简易治具减少手持操作
- **人机配合优化**：使人和设备的节拍匹配
- **目视化管理**：消除寻找动作

## 9. D8 - Extra-processing 过度加工浪费

### 9.1 定义

投入超出客户要求的加工精度、检验项目、包装标准等，虽然增加了成本但未增加客户认可的价值。

### 9.2 制造业的典型表现

| 过度类型 | 具体场景 | 分析 |
|---------|---------|------|
| 过度检验 | 100% 全检但历史不良率极低 | 可改为抽检或免检 |
| 过高精度 | 要求精度远超客户和标准要求 | 增加加工成本 |
| 多余工序 | 客户不需要的额外处理工序 | 增加了加工时间和成本 |
| 过度包装 | 过度的防锈和保护包装 | 增加材料和人工成本 |
| 重复检验 | 同一指标在多个工序重复检测 | 检验资源浪费 |
| 过度记录 | 过于繁琐的记录表格和流程 | 增加文员工作量 |

### 9.3 识别方法

- **客户要求对标**：比较内部标准与客户实际要求的差异
- **检验数据分析**：分析检验数据，确定哪些检验是必要的
- **工序价值分析**：对每个工序进行增值/非增值判断
- **加工精度分析**：分析实际加工精度与客户要求的差距

### 9.4 改善方向

- **理解客户要求**：深入了解客户的真实需求和可接受范围
- **优化检验方案**：基于统计分析设计合理的检验方案
- **工艺优化**：在满足要求的前提下简化工艺
- **合理设定公差**：与客户协商合理的公差范围
- **标准化包装**：根据运输和存储条件制定合理的包装标准

## 10. 浪费识别检查清单

### 10.1 现场巡查检查表

以下检查清单可用于日常现场巡查（Gemba Walk），帮助系统性地识别各类浪费。

#### 不良品浪费检查

- [ ] 各工序不良率是否在目标范围内？
- [ ] 是否存在反复出现的同一类不良？
- [ ] 防错装置是否正常运行？
- [ ] 不良品是否被及时隔离和处理？
- [ ] 根本原因分析是否落实到位？
- [ ] 操作者是否清楚当前的质量标准？

#### 过量生产浪费检查

- [ ] 实际产出是否与生产计划一致？
- [ ] 是否存在超订单生产的情况？
- [ ] 各工序的批量大小是否合理？
- [ ] 成品库存天数是否在合理范围？
- [ ] 是否有滞销的成品积压？

#### 等待浪费检查

- [ ] 是否有操作者在等待物料或工具？
- [ ] 设备是否经常处于空闲状态？
- [ ] 换模时间是否在目标范围内？
- [ ] 设备故障停机频率是否在可接受水平？
- [ ] 检验等待时间是否过长？

#### 人才浪费检查

- [ ] 员工的多能工程度如何？
- [ ] 改善提案制度是否有效运行？
- [ ] 一线员工是否有停线权？
- [ ] 员工培训是否系统化进行？
- [ ] 是否有经验传承机制？

#### 搬运浪费检查

- [ ] 工序间的搬运距离是否合理？
- [ ] 搬运频次是否可以减少？
- [ ] 布局是否便于连续流？
- [ ] 搬运设备是否充足且高效？

#### 库存浪费检查

- [ ] 原材料库存天数是否合理？
- [ ] 半成品是否在各工序间积压？
- [ ] 是否有呆滞物料需要处理？
- [ ] 库存数据是否准确？

#### 动作浪费检查

- [ ] 操作者是否有频繁弯腰、转身动作？
- [ ] 工具和物料的摆放是否合理？
- [ ] 操作者是否有不必要的走动？
- [ ] 人机配合是否均衡？

#### 过度加工浪费检查

- [ ] 检验项目是否都是客户要求的？
- [ ] 加工精度是否超出客户要求？
- [ ] 是否有多余的工序可以取消？
- [ ] 包装标准是否合理？

## 11. 浪费优先级矩阵

### 11.1 评估维度

识别出浪费后，需要按照以下维度评估优先级：

| 维度 | 说明 | 评分标准（1-5） |
|------|------|----------------|
| 影响程度 | 对成本、质量、交期的影响 | 1=轻微，5=严重 |
| 发生频率 | 浪费发生的频率 | 1=偶尔，5=每天 |
| 改善难度 | 实施改善的难度 | 1=容易，5=困难 |
| 改善成本 | 改善所需投入 | 1=低成本，5=高成本 |

### 11.2 优先级判定

- **高优先级（P1）**：影响大、频率高、难度低、成本低 —— 立即行动
- **中优先级（P2）**：影响中等或频率中等 —— 纳入季度改善计划
- **低优先级（P3）**：影响小、频率低 —— 纳入年度规划

### 11.3 制造企业常见浪费优先级参考

| 浪费类型 | 典型优先级 | 说明 |
|---------|-----------|------|
| 不良品 | P1 | 直接影响客户满意度和成本 |
| 等待 | P1-P2 | 通常通过布局和流程优化可快速改善 |
| 过量生产 | P1 | 需要建立拉动机制 |
| 搬运 | P2 | 布局优化是长期课题 |
| 库存 | P1-P2 | 需要系统性改善 |
| 动作 | P2 | 工位优化即可改善 |
| 过度加工 | P2-P3 | 需要深入了解客户要求 |
| 人才浪费 | P2 | 需要持续投入 |
