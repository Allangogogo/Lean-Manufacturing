# 精益成熟度模型（5级）

## 1. 模型概述

本模型基于 Shingo 模型和精益企业成熟度评估工具（LESAT），结合制造行业的工艺特点，建立了5级精益成熟度评估体系。从 L1 初始级到 L5 优化级，逐级递进，帮助企业准确定位当前精益实施水平，明确改进方向。

### 模型设计原则

- **渐进性**：各级别之间有清晰的递进关系，不可跨越
- **可衡量性**：每级都有明确的关键判据和典型表现
- **行业适配性**：紧密结合制造行业特点
- **可操作性**：提供具体的判定标准，便于评估人员操作

### 模型总览

| 等级 | 名称 | 综合得分区间 | 核心特征 |
|------|------|-------------|---------|
| L1 | 初始级/传统级 | 1.0 - 1.8 | 被动救火，无标准化 |
| L2 | 发展级/基础级 | 1.9 - 2.6 | 基础工具导入，部分标准化 |
| L3 | 定义级/系统级 | 2.7 - 3.4 | 精益融入日常，系统化推进 |
| L4 | 管理级/前瞻级 | 3.5 - 4.2 | 精益嵌入文化战略，持续优化 |
| L5 | 优化级/世界级 | 4.3 - 5.0 | 自驱精益文化，行业标杆 |

---

## 2. L1 初始级/传统级

### 2.1 特征描述

处于 L1 级别的企业，精益生产基本处于空白或萌芽状态。生产管理以传统方式为主，依赖个人经验和被动应对。缺乏系统的管理方法和工具应用，问题处理以救火式为主。

### 2.2 关键判据

- 无正式的精益推进组织或负责人
- 生产计划依赖人工经验安排，频繁变更
- 无标准作业文件或仅有过时的作业指导书
- 库存水平高，在制品积压严重
- 质量控制以终检为主，缺乏过程控制
- 设备维护以事后维修为主，无预防性维护计划
- 员工改善意识薄弱，依赖管理者决策

### 2.3 典型表现

| 领域 | 典型表现 |
|------|---------|
| 生产管理 | 排产靠经验，插单频繁，交期延误常见 |
| 质量管理 | 依赖终检挑不良，不良率波动大 |
| 设备管理 | 设备故障频繁，停机时间长 |
| 库存管理 | 在制品大量堆积，原材料库存过高 |
| 人员管理 | 岗位固化，技能单一，缺乏多能工 |
| 现场管理 | 5S基础薄弱，现场混乱，找料困难 |

### 2.4 制造业典型场景

- 机加工工序经常因模具意外损坏导致停机，缺乏模具寿命管理
- 精加工工序不良率居高不下，但缺乏系统的尺寸精度监控
- 热处理工序炉温波动大，碳势控制不稳定，硬度合格率波动
- 表面处理工序槽液管理粗放，镀层厚度不均匀
- 包装工序偶发混料事故，追溯困难
- 各工序之间信息不透明，前工序不良流入后工序
- 仓库积压大量成品库存，但客户订单交付率不高

### 2.5 等级跃迁关键行动

要从 L1 升级到 L2，企业需要：

1. **建立精益推进组织**：指定精益推进负责人，组建推进小组
2. **高层承诺**：总经理/厂长明确表态支持精益转型
3. **5S导入**：从整理、整顿开始，改善现场基础环境
4. **基础培训**：对管理层和班组长进行精益基础概念培训
5. **试点选择**：选择1-2条代表性生产线进行试点

## 3. L2 发展级/基础级

### 3.1 特征描述

处于 L2 级别的企业，已经启动精益推进工作，基础工具开始导入。部分标准作业已经建立，可视化管理初步实施。5S在现场有一定基础，但持续性不足。精益推进主要依靠推进部门驱动，尚未融入日常管理。

### 3.2 关键判据

- 已建立精益推进组织，但职责不清晰
- 5S已导入但维持困难，容易回退
- 部分工序建立了标准作业，但执行不一致
- 可视化看板初步建立，但信息更新不及时
- 价值流图（VSM）分析已启动，但未形成改进闭环
- 定期召开质量会议，但问题解决深度不足
- 设备管理开始推行预防性维护，但覆盖率低

### 3.3 典型表现

| 领域 | 典型表现 |
|------|---------|
| 生产管理 | 基础排产工具导入，但仍频繁变更 |
| 质量管理 | SPC初步导入，但数据分析能力不足 |
| 设备管理 | TPM活动启动，自主保全意识萌芽 |
| 库存管理 | 尝试设定安全库存，但经常调整 |
| 人员管理 | 多能工培训启动，但覆盖面有限 |
| 现场管理 | 5S定期检查，但维持效果波动 |

### 3.4 制造业典型场景

- 机加工工序建立基本的换模标准作业，但换模时间仍不稳定
- 精加工工序开始记录尺寸检测数据，但缺乏系统的统计分析
- 热处理工序制定了炉温管控标准，但碳势波动控制效果有限
- 表面处理工序建立了槽液点检制度，但点检频率和记录规范性不足
- 包装工序制定了防混料措施，但执行依赖人工确认
- 开始使用电子看板显示当日生产目标，但实际达成情况更新滞后
- VSM分析揭示了机加工到精加工之间的在制品积压问题，但尚未实施拉动系统

### 3.5 等级跃迁关键行动

要从 L2 升级到 L3，企业需要：

1. **标准化深化**：将标准作业扩展到所有关键工序，确保执行一致性
2. **拉动系统建立**：在关键工序之间建立看板拉动系统
3. **跨职能团队**：建立正式的跨职能改善团队
4. **KPI主动使用**：从数据收集转向数据分析和主动改善
5. **全员参与**：将精益从推进部门扩展到全员参与

---

## 4. L3 定义级/系统级

### 4.1 特征描述

处于 L3 级别的企业，精益已经融入日常管理体系。拉动系统建立并有效运行，跨职能团队协作改善成为常态。KPI体系完善并被主动使用来驱动改善。标准作业执行一致性高，5S维持良好。

### 4.2 关键判据

- 精益推进组织职责清晰，与业务深度融合
- 5S维持良好，已成为员工自觉行为
- 拉动系统（看板）在关键工序之间有效运行
- 跨职能团队定期开展改善活动
- KPI体系完善，数据驱动决策成为常态
- 问题解决使用系统化方法（A3、8D、鱼骨图等）
- 设备OEE达到行业平均水平以上
- 供应链基础协同初步建立

### 4.3 典型表现

| 领域 | 典型表现 |
|------|---------|
| 生产管理 | 拉动排产为主，交付准时率稳定 |
| 质量管理 | 过程控制为主，质量成本持续下降 |
| 设备管理 | TPM体系运行，自主保全水平较高 |
| 库存管理 | 在制品库存合理，周转率提升 |
| 人员管理 | 多能工比例高，全员参与改善 |
| 现场管理 | 5S水平稳定，可视化管理完善 |

### 4.4 制造业典型场景

- 机加工工序OEE达到75%以上，换模时间缩短至SMED目标水平
- 精加工工序尺寸合格率稳定在99%以上，SPC控制图实时监控
- 热处理工序碳势控制精度达到±0.03%，炉温均匀性±5°C以内
- 表面处理工序镀层厚度CPK≥1.33，槽液参数自动监控
- 包装工序实现扫码追溯，包装合格率99.5%以上
- 机加工与精加工之间建立看板拉动，在制品库存降低30%
- 月度经营分析会使用精益KPI仪表盘，数据驱动改善决策

### 4.5 等级跃迁关键行动

要从 L3 升级到 L4，企业需要：

1. **精益文化嵌入**：将精益从管理工具升级为企业文化和战略组成部分
2. **Kaizen日常化**：将改善活动从项目式转变为日常化、全员化
3. **高级工具成熟**：深化六西格玛、价值工程等高级工具的应用
4. **供应商整合**：将精益延伸到供应链上游
5. **管理层深度参与**：从支持者转变为精益的推动者和示范者

---

## 5. L4 管理级/前瞻级

### 5.1 特征描述

处于 L4 级别的企业，精益已经嵌入企业文化和战略层面。Kaizen成为全员日常行为，高级精益工具运用成熟。管理层深度参与并引领精益方向，改善活动与经营目标紧密对齐。供应链整合取得实质性进展。

### 5.2 关键判据

- 精益被纳入企业战略规划和年度经营计划
- Kaizen活动全员参与，改善提案制度成熟运行
- 高级精益工具（六西格玛、VSM、TOC等）成熟应用
- 管理层定期Gemba Walk，关注流程和系统问题
- 精益成果体现在财务指标上（成本、效率、质量）
- 供应商精益能力评估和辅导体系建立
- 员工技能发展与精益能力模型结合
- 创新性改善活动定期涌现

### 5.3 典型表现

| 领域 | 典型表现 |
|------|---------|
| 生产管理 | 流程优化持续，交付能力行业领先 |
| 质量管理 | 零缺陷为目标，质量成本极低 |
| 设备管理 | 预测性维护，设备可靠性极高 |
| 库存管理 | 供应链协同库存优化 |
| 人员管理 | 自主改善团队，创新提案活跃 |
| 现场管理 | 精益现场成为企业名片 |

### 5.4 制造业典型场景

- 机加工工序OEE达到85%以上，模具寿命预测性管理
- 精加工工序实现零缺陷目标，尺寸精度100%在线监控
- 热处理工序实现无人值守的自动化碳势控制
- 表面处理工序废水零排放，镀层质量达到汽车级标准
- 包装工序全自动化，AI视觉检测混料
- 棒料供应商纳入精益体系，实现JIT供应
- 年度改善提案人均5条以上，实施率超过70%
- 精益推进成果在公司年报中作为核心竞争力展示

### 5.5 等级跃迁关键行动

要从 L4 升级到 L5，企业需要：

1. **自驱文化**：精益改善完全成为自下而上的自发行为
2. **创新驱动**：在持续改善基础上融入技术创新和商业模式创新
3. **行业标杆**：成为行业精益实践的标杆，输出最佳实践
4. **全供应链整合**：将精益理念和方法延伸到整个供应链生态
5. **社会责任**：将精益与ESG、可持续发展目标结合

## 6. L5 优化级/世界级

### 6.1 特征描述

处于 L5 级别的企业，代表世界级的精益制造水平。精益文化完全自驱运行，创新驱动持续改善。企业成为行业标杆，全供应链实现精益整合。精益已不仅是制造方法，而是企业的核心竞争力和经营哲学。

### 6.2 关键判据

- 精益文化完全自驱，无需外部推动
- 创新驱动改善，持续产生突破性成果
- 行业公认的精益标杆企业
- 全供应链精益整合，上下游协同优化
- 精益与数字化、智能化深度融合
- 卓越的经营成果（成本、质量、交付、安全）
- 人才输出和经验分享，推动行业进步

### 6.3 典型表现

| 领域 | 典型表现 |
|------|---------|
| 生产管理 | 极致效率，行业最优交付表现 |
| 质量管理 | 六西格玛水平，客户零投诉 |
| 设备管理 | 智能预测维护，设备综合效率>90% |
| 库存管理 | 供应链端到端优化，现金周转极快 |
| 人员管理 | 全员创新，组织学习能力极强 |
| 现场管理 | 精益现场成为行业参观学习标杆 |

### 6.4 制造业典型场景

- 工厂成为行业精益示范工厂，每年接待数十家同行参观学习
- 机加工、精加工、热处理全工序实现数字化精益管理
- 棒料原材料实现VMI（供应商管理库存），库存成本极低
- 客户定制化需求通过柔性化生产快速响应
- 员工自主组成改善小组，每月产出创新性改善成果
- 精益方法论输出到行业标准和最佳实践指南
- 企业精益实践被写入行业教科书或权威出版物
- 精益理念延伸到产品设计、客户服务、社会责任等全价值链

## 7. 等级跃迁路径总结

### 7.1 跃迁方向

```
L1 → L2：从无序到基础    （6-12个月）
L2 → L3：从基础到系统    （12-18个月）
L3 → L4：从系统到文化    （18-36个月）
L4 → L5：从文化到卓越    （36个月以上）
```

### 7.2 各级跃迁核心驱动力

| 跃迁 | 核心驱动力 | 最大挑战 |
|------|-----------|---------|
| L1→L2 | 高层承诺+基础工具导入 | 打破惯性，建立信心 |
| L2→L3 | 系统化推进+全员参与 | 从工具到系统的思维转变 |
| L3→L4 | 文化建设+战略融合 | 从执行到引领的角色转变 |
| L4→L5 | 创新驱动+生态整合 | 突破自我，持续超越 |

### 7.3 注意事项

1. **不可跳跃**：每个等级的能力建设都是下一等级的基础，不可跳过
2. **夯实基础**：升级前确保当前等级的稳定性，避免表面达标
3. **因地制宜**：根据企业实际情况调整跃迁节奏，不盲目追求高等级
4. **持续评估**：至少每年进行一次成熟度评估，跟踪进展
5. **避免形式化**：评估应反映真实水平，而非表面文章

## 8. 评估应用指南

### 8.1 初始评估

首次评估建议使用以下步骤：

1. 阅读本模型全文，统一评估团队认知
2. 对照各等级判据，初步判断企业所在等级区间
3. 使用评估维度和权重进行详细评分
4. 综合评分确定最终等级
5. 与标杆企业对比，验证评估结果的合理性

### 8.2 后续评估

1. 每年至少进行一次全面评估
2. 对比历史评估结果，追踪进步
3. 识别薄弱环节，聚焦改进
4. 制定下一等级的跃迁计划

### 8.3 行业对标

建议关注以下行业标杆进行对标分析：

- 国际制造标杆企业（如日本、德国企业）
- 汽车零部件行业的精益标杆
- 国内制造业的领先企业
