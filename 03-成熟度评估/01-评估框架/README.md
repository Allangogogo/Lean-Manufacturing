# 评估框架

本目录包含精益成熟度评估的核心框架和标准体系，是整个评估模块的方法论基础。

## 内容说明

### 精益成熟度模型（5级）

基于 Shingo 模型和精益企业成熟度评估工具（LESAT），结合紧固件制造行业特点，建立了5级精益成熟度模型。从 L1 初始级到 L5 优化级，每级都有明确的特征描述、关键判据和典型表现，帮助企业准确定位自身水平。

### 评估维度与权重

评估体系包含6大维度：领导力与文化、战略与目标对齐、核心工具应用、流程与运营、人员能力与发展、绩效与成果。各维度权重根据紧固件行业特点进行设置，可根据企业实际情况适当调整。

### 评分标准与判定规则

采用1-5分制评分体系，每个分数等级都有具体的判定规则和评分指南。同时提供评分一致性保障方法，确保不同评估人员的评分结果具有可比性。

## 使用建议

1. 在进行任何评估之前，首先阅读本目录的三个文件，建立统一的评估认知
2. 根据企业实际情况调整评估维度权重
3. 将本框架作为评估培训的核心教材
