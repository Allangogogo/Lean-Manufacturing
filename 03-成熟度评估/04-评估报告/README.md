# 评估报告

本目录提供评估报告的标准化模板和分析工具，确保评估结果的规范化呈现和有效应用。

## 内容说明

### 评估报告模板

标准评估报告结构模板，包含评估概述、结果总览、各维度详细分析、改进建议、改进路线图和附录等章节。配套报告撰写指南，确保报告质量的一致性。

### 雷达图分析模板

使用雷达图（蜘蛛图）进行多维度对比分析的方法说明。支持当前状态与目标状态的可视化对比、改进前后对比、以及不同工厂/工序间的横向对比。

### 改进路线图模板

按优先级分类的改进计划模板，将改进项分为紧急改进（1-3个月）、重要改进（3-6个月）、长期提升（6-12个月）三个层次。每项改进包含目标、负责人、资源、时间和验收标准。

## 使用建议

1. 评估报告应在评估完成后5个工作日内完成
2. 报告应以数据和事实为依据，避免主观臆断
3. 改进路线图应获得管理层审批后正式实施
4. 定期回顾改进进度，至少每月更新一次路线图
5. 评估报告和改进路线图应向相关部门和人员进行沟通
