# 工厂整体评估

本目录提供工厂级精益成熟度的全面评估工具，覆盖领导力、文化、战略、供应链等宏观维度。

## 内容说明

### 工厂整体成熟度评估表

综合评估矩阵，包含6大维度及若干子项，每项均有明确的评估内容、评分标准、证据要求和数据来源。配套评估流程指导（自评 → 评审 → 报告 → 改进计划）。

### 领导力与文化评估

专项评估高层精益承诺、精益推进组织架构、文化建设、管理层现场走访、精益在绩效考核中的权重等。包含10-15个评估问题及评分标准。

### 战略与目标对齐评估

专项评估精益战略与企业战略对齐程度、目标设定的SMART原则、目标分解与传递、定期回顾机制、资源保障等。

### 供应链整合评估

专项评估供应商精益能力、交付准时率、原材料库存管理、质量协同、供应链可视化等。制造业原材料（棒料、卷料）供应的稳定性对生产影响重大。

## 使用建议

1. 工厂整体评估建议每年进行一次全面评估
2. 评估前需收集全厂级运营数据
3. 评估团队应包含高层管理者，以体现对精益推进的重视
4. 评估结果作为年度精益规划的重要输入
