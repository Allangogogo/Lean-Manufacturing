## 1. 模板说明

本模板为通用的单工序精益成熟度评估模板，可适用于紧固件制造工艺链中的任何工序或生产线。使用时根据具体工序的特点，参照已有的专项评估表（冷镦、搓丝、热处理、表面处理、包装）或自行填写。

## 3. 评估填写指南

### 3.1 评估前准备

1. **了解工序**：评估前充分了解该工序的工艺流程、设备、质量要求
2. **收集数据**：提前收集该工序的生产数据、质量数据、设备数据
3. **确认评估人员**：确保评估人员具备该工序的基本知识

### 3.2 评估操作要点

1. **现场走访**：评估必须包含现场走访（Gemba Walk），不可仅凭文件评估
2. **证据收集**：每个评分必须有对应的证据支撑，记录在关键证据列
3. **独立评分**：评估人员应独立评分，避免互相影响
4. **交叉验证**：多位评估者的评分差异超过1分时，需讨论达成一致
5. **工序特有项**：根据具体工序特点，填写工序特有的评估内容和标准

### 3.3 工序特有项填写建议

| 工序 | 特有评估项建议 |
|------|--------------|
| 冷镦 | 模具寿命管理、钢丝来料检验、冲压力监控 |
| 搓丝 | 通止规检测、螺纹精度控制、搓丝板磨损监控 |
| 热处理 | CQI-9合规、炉温曲线监控、气氛控制、脱碳控制 |
| 表面处理 | 镀层工艺参数、槽液管理、废水处理合规、氢脆防控 |
| 包装 | 防混料措施、追溯码管理、客户包装要求符合度 |
| 分选 | 检测设备精度、检测标准执行、不良品隔离管理 |

### 4.3 改进优先级判定

改进优先级基于以下因素综合判定：

1. **工序对最终质量的影响度**：质量影响大的工序优先改进
2. **当前评分与目标的差距**：差距大的优先改进
3. **改善的可行性和投入产出比**：易改善、高回报的优先
4. **客户投诉的相关性**：与客户投诉相关的优先改进
