# 局部评估

本目录提供制造各关键工序的精益成熟度专项评估表，以及通用的单工序评估模板。

## 内容说明

### 各工序评估表

针对制造工艺链的每道关键工序，提供专项评估表：

| 工序 | 评估表 | 核心关注点 |
|------|-------|-----------|
| 机加工 | 机加工工序成熟度评估表 | 模具寿命管理、设备OEE、冲压力监控 |
| 精加工 | 精加工工序成熟度评估表 | 尺寸精度控制、加工刀具寿命、量规检测 |
| 热处理 | 热处理工序成熟度评估表 | CQI-9合规、炉温曲线、碳势控制 |
| 表面处理 | 表面处理工序成熟度评估表 | 镀层质量、槽液管理、环保合规 |
| 包装 | 包装工序成熟度评估表 | 防混料、追溯码、客户要求符合度 |

每份评估表包含：设备管理、质量控制、效率指标、人员技能、5S/可视化等通用维度，以及工序特有的专项评估点。

### 单工序评估模板

通用评估模板，可适配任何工序或生产线的精益成熟度评估。提供评估表填写指南和评估结果汇总方法。

## 使用建议

1. 评估前根据工序特点选择对应的评估表
2. 每道工序的评估应由熟悉该工序的人员参与
3. 评估时重点关注工序特有的评估点
4. 各工序评估结果可汇总形成工厂整体评估的输入
5. 对于新增工序或工艺变更，使用单工序评估模板进行专项评估
