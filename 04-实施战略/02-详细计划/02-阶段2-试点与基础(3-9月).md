# 阶段2：试点与基础（第3-9月）

> 本阶段在选定的试点区域建立精益基础，通过5S、标准作业、Kaizen等工具的导入验证改善方法，培养内部能力。

---

## 目标

在试点区域建立精益管理基础，验证改善方法的有效性，培养内部精益推进能力，形成可复制的成功案例。

### 量化目标（试点区域）

| 指标 | 基线值 | 阶段目标 |
|------|--------|---------|
| OEE | 现状值 | 提升≥5个百分点 |
| 不良率 | 现状值 | 降低≥20% |
| 5S审核平均分 | 现状值 | ≥4.0分 |
| 标准作业覆盖率 | 0% | 100% |
| 换模时间 | 现状值 | 降低≥30% |

## 关键活动

### 第一月：基础导入（5S与可视化）

#### Week 1-2：5S启动

| 任务 | 说明 |
|------|------|
| 5S培训 | 对试点区域全员进行5S基础培训（4课时） |
| 红牌作战 | 发放红牌，识别不需要的物品 |
| 整理（Seiri） | 处理红牌物品：移走、报废、归位 |
| 整顿（Seiton） | 物品定位、定量、定容管理 |
| 清扫（Seiso） | 制定清扫标准和责任区 |

**红牌作战流程**：

```
准备阶段 → 现场贴红牌 → 红牌物品汇总 → 评审决策 → 处理执行 → 确认关闭
（1天）    （2天）       （0.5天）      （0.5天）   （1-2天）   （0.5天）
```

#### Week 3-4：可视化管理建立

| 任务 | 说明 |
|------|------|
| 区域划分 | 地面划线、区域标识、通道标识 |
| 设备标识 | 设备状态标识、操作规程标识 |
| 物料标识 | 物料区域标识、物料卡 |
| 管理板安装 | 生产管理板、质量管理板、安全管理板 |
| 目视化标准 | 制定区域5S标准照片 |

**管理板内容设计**：

| 管理板 | 包含内容 | 更新频率 |
|--------|---------|---------|

| 改善管理板 | 改善提案、进行中项目、完成案例 | 每周 |

### 第二至三月：标准作业建立

#### Week 5-6：现状观测与分析

| 任务 | 说明 |
|------|------|
| 作业要素分解 | 将每个岗位的作业分解为要素作业 |
| 时间观测 | 每个要素作业观测3-5次，取平均值 |
| 动作分析 | 识别不增值动作、等待、走动等浪费 |
| 节拍时间计算 | 根据客户需求计算节拍时间 |
| 岗位能力矩阵 | 评估操作工多技能水平 |

**节拍时间计算**：

```
节拍时间 = 可用工作时间 / 客户需求量

例：每天有效工作时间450分钟，客户需求500件
节拍时间 = 450 / 500 = 0.9分钟/件
```

#### Week 7-8：标准作业编制

| 任务 | 说明 |
|------|------|
| 编制标准作业票 | 每个岗位一份标准作业票 |
| 编制组合票 | 人机配合的岗位编制组合票 |
| 作业顺序优化 | 基于ECRS原则优化作业顺序 |
| 操作工培训 | 按标准作业培训所有操作工 |
| 标准作业审核 | 管理层审核标准作业的合理性和执行情况 |

**标准作业票三要素**：

| 要素 | 内容 |
|------|------|
| 节拍时间 | 客户需求决定的生产节奏 |
| 作业顺序 | 最优的作业步骤和顺序 |
| 标准在制品 | 完成作业所需的最少在制品数量 |

### 第四至五月：首次Kaizen事件

#### Week 9-10：Kaizen准备

| 任务 | 说明 |
|------|------|
| 选定主题 | 基于浪费识别和VSM分析选择改善主题 |
| 组建团队 | 5-8人跨职能团队（含外部顾问指导） |
| 现状调查 | 收集改善区域的详细数据 |
| 物料准备 | 准备所需的工具、标识、看板等物料 |
| 场地准备 | 确保改善区域有独立的工作空间 |

**Kaizen主题选择标准**：

| 标准 | 说明 |
|------|------|
| 与业务痛点相关 | 改善重点问题，如换模时间长、不良率高 |
| 可在5天内完成 | 范围适中，不选过大或过小的主题 |
| 可量化成果 | 改善前后可以用数据对比 |
| 有示范效应 | 成果可复制到其他区域 |

#### Week 11-13：5天Kaizen实施

| 天数 | 主题 | 关键活动 |
|------|------|---------|
| Day 1 | 现状认识 | 现场观察、数据收集、浪费识别、拍照记录 |
| Day 2 | 分析根因 | 鱼骨图、5Why分析、帕累托分析 |
| Day 3 | 方案制定 | 头脑风暴、方案评估、最佳方案选定 |
| Day 4 | 实施执行 | 现场改善实施、快速验证、调整优化 |
| Day 5 | 总结固化 | 成果确认、标准化、汇报展示 |

**Day 4实施要点**：
- 不追求完美，先快速实施验证效果
- 遇到问题当天解决，不要留到第二天
- 实施过程中持续拍照记录（改善前/中/后）
- 让所有团队成员参与动手实施

#### Week 14：Kaizen总结

| 任务 | 说明 |
|------|------|
| 成果量化 | 统计改善前后的各项指标数据 |
| 标准化固化 | 更新标准作业、5S基准等文件 |
| 汇报展示 | 向管理层汇报Kaizen成果 |
| 经验总结 | 总结成功经验和改进空间 |

## 阶段2经验提示

1. **5S不是打扫卫生**：5S是管理工具，重点是"素养"而非"清扫"
2. **标准作业要让操作工参与编制**：不是推进员写好让操作工执行，而是一起编制
3. **Kaizen不追求完美**：5天内的改善可能不完美，关键是建立改善的思维和方法
4. **固化比改善更重要**：改善后一定要标准化，否则会退化
5. **用数据说话**：改善前后要有数据对比，这是说服管理层继续投入的关键
