# 阶段3：扩展与部署（第9-18月）

> 本阶段将试点成功经验推广到全厂所有工序，建立拉动系统、平准化排产和TPM基础体系，实现精益的全面覆盖。

---

## 目标

将精益从试点区域扩展到全厂5个工序，建立拉动式生产系统和日常管理体系，实现精益工具的全面覆盖。

### 量化目标

| 指标 | 9月基线 | 18月目标 |
|------|---------|---------|
| 全厂OEE | 试点区域达标 | 全厂≥80% |
| 不良率 | 试点区域达标 | 全厂≤1.5% |
| 交付周期 | 现状值 | ≤10天 |
| 标准作业覆盖率 | 试点100% | 全厂≥80% |
| 看板准确率 | - | ≥95% |
| 设备故障率 | 现状值 | ≤3% |


### 第二阶段：拉动系统建设（第12-15月）

#### 看板系统设计

| 任务 | 说明 |
|------|------|
| 看板类型选择 | 确定使用生产看板、看板、信号看板等类型 |
| 看板数量计算 | 基于提前期和需求波动计算看板数量 |
| 超市库存设计 | 在关键工序间设计缓冲库存点 |
| 看板规则制定 | 明确看板的使用、回收、异常处理规则 |
| 看板制作 | 制作实体看板或电子看板 |

**看板数量计算公式**：

```
看板数量 = (日均需求 × 提前期 × (1 + 安全系数)) / 看板标准批量

例：日均需求1000件，提前期2天，安全系数20%，每箱500件
看板数量 = (1000 × 2 × 1.2) / 500 = 4.8 ≈ 5张看板
```

#### 看板试运行

| 步骤 | 说明 |
|------|------|
| 模拟运行 | 在会议室用模拟道具演练看板流程 |
| 现场试运行 | 在选定的工序间开始试运行 |
| 问题收集 | 每天收集运行中的问题和异常 |
| 规则调整 | 根据试运行情况调整看板参数 |
| 正式运行 | 问题解决后转为正式运行 |
| 持续优化 | 每月review看板运行效果，持续优化 |

### 第三阶段：平准化排产（第13-16月）

#### 平准化设计

| 任务 | 说明 |
|------|------|
| 需求分析 | 分析近12个月的订单模式和波动 |
| 产品分族 | 按工艺路线和加工时间将产品分族 |
| 节拍确定 | 根据需求确定日生产节拍 |
| 混合排产 | 设计同一品种批量最小化的排产模式 |
| 产线调整 | 根据平准化需求调整设备布局和人员配置 |

**平准化排产示例**：

| 传统排产 | 平准化排产 |
|---------|-----------|
| A产品1000件 → B产品500件 | A-B-A-B-A循环生产 |
| 批量大、换型少 | 批量小、换型多但换型快 |
| 库存高、响应慢 | 库存低、响应快 |

#### 换型时间优化配合

平准化排产要求快速换型，与SMED项目配合：
- 识别当前换型时间的构成
- 区分内部作业和外部作业
- 将内部作业转化为外部作业
- 优化剩余内部作业

### 第四阶段：TPM基础导入（第14-18月）

#### 自主保全3步法

| 步骤 | 内容 | 时间 |
|------|------|------|
| 第1步：初期清扫 | 设备清扫+劣化点检+困难点标注 | 2-3周 |
| 第2步：困难点对策 | 针对清扫困难点和劣化源制定对策 | 3-4周 |
| 第3步：自主基准 | 编制自主保全基准书，培训操作工 | 2-3周 |

#### 计划保全基础

| 任务 | 说明 |
|------|------|
| 设备台账建立 | 建立全部设备的基本信息台账 |
| 故障记录 | 建立设备故障记录和分析机制 |
| 保全计划 | 制定设备定期保全计划 |
| 备件管理 | 建立关键备件的安全库存管理 |

#### SMED快速换模项目

| 任务 | 说明 |
|------|------|
| 选择目标设备 | 选择换模时间最长的关键设备 |
| 现状观测 | 视频记录整个换模过程 |
| 作业分析 | 区分内部作业和外部作业 |
| 改善实施 | 将内部转外部、缩短内部作业时间 |
| 验证固化 | 验证改善效果，标准化新方法 |

## 阶段3经验提示

1. **扩展不是简单复制**：每个工序有自己的特点，需要因地制宜调整
2. **看板设计要简单起步**：先从简单的看板开始，逐步复杂化
3. **TPM要操作工参与**：自主保全不是设备部的事，操作工是主体
4. **SMED要视频记录**：用视频分析换模过程，比文字记录更直观有效
5. **日常管理是关键**：站立会和分层审核是维持改善成果的核心机制
