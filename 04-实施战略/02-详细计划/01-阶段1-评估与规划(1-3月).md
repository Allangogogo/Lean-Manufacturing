# 阶段1：评估与规划（第1-3月）

> 本阶段是精益转型的起点，核心任务是建立转型基础——组建团队、培养共识、评估现状、制定蓝图。

---

## 目标

建立精益转型的组织基础和战略方向，为后续实施提供清晰的路线图和可执行的方案。

### 量化目标

| 目标 | 达标标准 |
|------|---------|
| 团队组建 | 精益推进团队全部到位 |
| 高层共识 | 管理团队精益认知测试≥80分 |
| 现状评估 | 完成全厂VSM和成熟度评估 |
| 蓝图发布 | 转型蓝图获总经理批准 |

---

## 关键活动

### Week 1-2：组建精益推进团队

**目标**：搭建精益转型的组织架构

| 任务 | 负责人 | 输出 |
|------|--------|------|
| 发布精益推进组织架构 | 总经理 | 组织架构文件 |
| 任命精益总监/推进负责人 | 总经理 | 任命书 |
| 招聘或调配精益推进员 | 人力资源部 | 到岗确认 |
| 各部门指定精益联络员 | 各部门经理 | 联络员名单 |
| 召开精益推进团队启动会 | 精益总监 | 启动会议纪要 |

**关键决策**：
- 精益推进办公室设在何处（建议独立设置或挂在生产部）
- 精益推进员的来源（外部招聘 vs 内部选拔 vs 外部顾问兼任）
- 各部门联络员的选拔标准（建议选择有改善意愿的中层骨干）

### Week 3-4：领导力精益培训（2天）

**目标**：统一管理层对精益的认知和承诺

| 时间 | 内容 | 方式 |
|------|------|------|
| 第1天上午 | 精益起源与发展、丰田生产方式核心理念 | 讲授+视频 |
| 第1天下午 | 七大浪费识别、价值流概念 | 讲授+工厂参观 |
| 第2天上午 | 精益转型路径、成功案例分析 | 讲授+案例研讨 |
| 第2天下午 | 本企业精益愿景讨论、高层承诺宣誓 | 工作坊 |

**培训对象**：总经理、副总经理、各部门经理（10-15人）

**关键产出**：
- 高层管理团队精益认知统一
- 精益转型初步共识
- 高层公开承诺书

### Week 5-8：现状评估

**目标**：全面了解企业精益现状，识别改善机会

#### 价值流图（VSM）绘制

| 任务 | 时间 | 参与者 | 输出 |
|------|------|--------|------|
| 数据收集准备 | 第5周 | 推进团队 | 数据收集清单 |
| 现场数据采集 | 第5-6周 | 推进团队+各部门 | 各工序数据表 |
| 当前状态VSM绘制 | 第6-7周 | 推进团队 | 当前状态价值流图 |
| 浪费识别和分析 | 第7周 | 推进团队 | 浪费清单 |
| VSM评审和确认 | 第8周 | 管理团队 | 确认的VSM |

**VSM关键数据收集项**：

| 工序 | 收集数据 |
|------|---------|
| 冷镦 | 节拍时间、换模时间、OEE、不良率、在制品数量 |
| 搓丝 | 节拍时间、调整时间、OEE、不良率、在制品数量 |
| 热处理 | 处理周期、温度曲线、能耗、不良率 |
| 表面处理 | 处理时间、换线时间、不良率、废液量 |
| 包装 | 包装速度、差错率、装箱规格 |

#### 精益成熟度评估

| 评估维度 | 评估内容 |
|---------|---------|
| 领导力 | 管理层精益认知和参与度 |
| 战略 | 精益与业务战略的对齐程度 |
| 流程 | 核心流程的精益水平 |
| 人员 | 员工精益意识和能力 |
| 改善 | 持续改善机制的成熟度 |

**评估方式**：外部顾问主导 + 内部团队配合

#### 全厂浪费识别（Gemba Walk）

| 任务 | 说明 |
|------|------|
| 安排Gemba路线 | 覆盖全部5个工序和辅助区域 |
| 组建Gemba团队 | 管理层+推进团队+外部顾问 |
| 现场观察和记录 | 用浪费检查表逐项识别 |
| 浪费分类和优先级排序 | 按影响度和改善难度排序 |
| 编写浪费识别报告 | 包含照片、数据、改善建议 |

### Week 9-10：精益愿景工作坊

**目标**：形成精益转型的共同愿景和目标

| 时间 | 内容 | 参与者 |
|------|------|--------|
| 半天 | 回顾评估结果和浪费识别 | 管理团队 |
| 半天 | 讨论精益愿景："我们要成为什么样的企业？" | 管理团队+员工代表 |
| 半天 | 设定转型目标（OEE、不良率、交付周期、成熟度） | 管理团队 |
| 半天 | 讨论转型范围、路径和资源需求 | 管理团队 |
| 半天 | 共识确认和签署 | 全体参与者 |

**输出**：
- 精益转型愿景声明
- 36个月转型目标（量化）
- 转型范围和路径共识

### Week 11-12：制定转型蓝图和试点方案

**任务**：

| 任务 | 负责人 | 输出 |
|------|--------|------|
| 编写转型蓝图文档 | 精益推进办公室 | 转型蓝图（参见01-精益转型总体规划） |
| 确定试点区域 | 精益推进团队 | 试点区域选定报告 |
| 制定试点方案 | 精益推进团队 | 试点实施方案 |
| 制定培训计划 | 精益推进办公室+HR | 年度培训计划 |
| 制定预算方案 | 精益推进办公室+财务 | 精益转型预算 |
| 蓝图审批 | 总经理 | 审批签字 |

**试点区域选择标准**：

| 标准 | 权重 | 说明 |
|------|------|------|
| 问题典型性 | 30% | 问题有代表性，改善可复制 |
| 改善潜力 | 25% | 有明确的改善空间和机会 |
| 团队意愿 | 20% | 区域团队有改善意愿和配合度 |
| 影响范围 | 15% | 改善成果对全厂有示范效应 |
| 实施难度 | 10% | 难度适中，能较快见效 |

**推荐首选试点**：冷镦工序（紧固件生产的核心工序，设备密集，改善空间大）

**评审结果**：

- 不通过 → 延长阶段1，解决关键问题后重新评审

## 阶段1经验提示

1. **不要跳过评估**：充分的现状评估是后续一切工作的基础
2. **高层参与是关键**：如果高层不参加培训、不参与Gemba，后续推动力会不足
3. **VSM要到现场画**：不要在会议室里闭门造车，VSM必须基于现场实际数据
4. **试点宜小不宜大**：第一个试点区域选择要有把握成功的，用成功建立信心
5. **蓝图要务实**：目标要有挑战性但可实现，避免"大跃进"
