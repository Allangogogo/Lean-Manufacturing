## 评分标准

| 分数 | 等级 | 说明 |
|------|------|------|
| 5分 | 优秀 | 完全达标，已形成习惯并持续保持 |
| 4分 | 良好 | 基本达标，偶有不足但能快速纠正 |
| 3分 | 一般 | 部分达标，需要改善和巩固 |

| 1分 | 很差 | 大部分不达标，需要全面整改 |
| 0分 | 未执行 | 完全没有执行或不存在 |

## 审核流程

```
制定审核计划 → 现场审核（拍照记录） → 评分打分 → 编写审核报告
     ↑                                              │
     │                                              ▼
     └──── 跟踪整改 ← 制定改善计划 ← 与区域负责人确认 ←
```

---

## 使用说明

1. **审核频率**：建议每月审核一次，改善初期可每周审核
2. **审核人员**：建议交叉审核（不同区域班组长互审），避免自己审自己
3. **拍照记录**：审核时必须拍照记录，包括问题点和亮点
4. **当场确认**：评分结果当场与区域负责人确认
5. **跟踪闭环**：发现问题必须制定改善计划并跟踪至关闭
6. **持续提升**：每次审核应在上一次基础上有所提升
