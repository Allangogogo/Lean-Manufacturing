**团队组建原则**：
- 5-8人为宜
- 包含跨职能成员（生产、质量、设备等）
- 包含一线操作工（最了解现场的人）
- 尽量不包含该区域的直接上级（避免影响坦诚讨论）

|--------|--------|--------|---------|
| 指标1：_____ | | | |
| 指标2：_____ | | | |
| 指标3：_____ | | | |

**SMART检验**：
- [ ] Specific（具体的）：目标是否明确具体？
- [ ] Measurable（可衡量的）：是否有量化指标？
- [ ] Achievable（可实现的）：目标是否在5天内可达成？
- [ ] Relevant（相关的）：是否与业务痛点相关？
- [ ] Time-bound（有时限的）：是否明确完成时间？

## 使用说明

1. **活动前1周**：填写基本信息、团队组成、目标设定
2. **活动前3天**：确认日程安排和资源需求
3. **活动中**：每天更新数据和进展
4. **活动后1周**：填写预期成果并跟踪验证
5. **活动后1月**：验证成果持续性，更新标准化文件

**关键提醒**：
- Kaizen不是头脑风暴会，要到现场去（Genchi Genbutsu）
- Day 4的实施要动手做，不只是讨论
- 改善前后都要有数据和照片对比
- 标准化固化与改善本身同等重要
