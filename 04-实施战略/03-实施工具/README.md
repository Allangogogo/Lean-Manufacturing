# 03 - 实施工具

本目录提供 6 个标准化实施工具模板，覆盖精益转型中最常用的管理工具，确保执行过程的一致性和规范性。

## 工具清单

| 工具 | 用途 | 适用场景 |
|------|------|----------|
| Kaizen事件策划模板 | 规划和执行 Kaizen 改善活动 | 快速改善、现场问题解决 |
| A3报告模板 | 结构化问题分析和解决 | 日常问题解决、项目管理 |
| 价值流图模板 | 绘制当前/未来状态价值流 | 流程分析、系统优化 |
| 标准作业模板 | 建立和维护作业标准 | 稳定流程、减少变异 |
| 5S审核表模板 | 评估和改善现场管理水平 | 现场审核、持续改善 |
| 改善提案表模板 | 收集和管理员工改善建议 | 全员参与、持续改善 |

## 使用原则

- **标准化**：所有活动统一使用本目录模板，确保记录格式一致
- **可视化**：模板设计强调可视化管理，便于信息传递和决策
- **可追溯**：每次使用均应留档，形成改善记录和知识积累
- **持续更新**：根据实践经验持续优化模板内容

## 配套使用

每个模板均包含详细的填写指南和使用说明，首次使用前请仔细阅读。建议在正式使用前进行一次模拟填写，确保团队成员理解模板要求。
