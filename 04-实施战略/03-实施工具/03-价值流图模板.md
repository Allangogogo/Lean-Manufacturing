# 价值流图（VSM）模板

> 价值流图是分析和设计价值流的核心工具，帮助识别浪费、设计未来状态、制定改善路线图。

---

## VSM模板结构

### 当前状态图要素

```
客户 ──── 信息流 ────→ 计划部门 ──── 信息流 ────→ 供应商
                         │
                    生产指令
                         │
  ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐
  │ 机加工  │──→│ 精加工  │──→│ 热处理 │──→│ 表面  │──→│ 包装  │──→ 客户
  └──────┘   └──────┘   └──────┘   └──────┘   └──────┘
     △          △          △          △          △
   库存1      库存2      库存3      库存4      库存5
```

### 数据框内容（每个工序）

| 数据项 | 说明 |
|--------|------|
| C/T（Cycle Time） | 周期时间（秒/件） |
| C/O（Changeover Time） | 换型时间（分钟） |
| Uptime | 设备稼动率（%） |
| 人数 | 操作人数 |
| 班次 | 每天班次数 |
| 合格率 | 一次合格率（%） |
| 库存 | 工序间在制品数量 |

```
非增值时间：              ████                    ████
            ──────────────────────────────────────────→ 时间
```

## 未来状态图要素

| 要素 | 符号 | 说明 |
|------|------|------|
| 节拍时间 | TT | 根据客户需求计算的生产节奏 |
| 连续流 | → | 无中断的连续生产 |
| 拉动信号 | ▼ | 看板拉动信号 |
| 超市库存 | ▽ | 缓冲库存点 |
| FIFO通道 | ═ | 先进先出通道 |
| 安全库存 | ▽S | 安全库存缓冲 |

## 绘图步骤

### 当前状态绘制

1. **确定产品族**：选择代表性产品系列
2. **从客户开始**：标注客户需求（数量、频次、节拍时间）
3. **走向现场**：沿价值流从客户到供应商逐步走一遍
4. **收集数据**：在每个工序收集数据框所需信息
5. **画物料流**：画出工序和工序间的库存
6. **画信息流**：画出计划和信息传递方式
7. **画时间线**：标注增值时间和非增值时间
8. **计算总提前期**：汇总所有前置时间

### 未来状态设计

1. **确定节拍时间**：TT = 可用时间 / 客户需求量
2. **识别连续流机会**：哪些工序可以连接为连续流
3. **设计拉动系统**：在哪些位置设置看板拉动
4. **设计超市库存**：在哪些位置需要缓冲库存
5. **平衡工作负荷**：将工作量分配到节拍时间内
6. **识别改善机会**：标注需要改善的区域
7. **制定实施路线图**：按优先级排列改善项目

## 使用说明

1. **必须到现场画**：VSM数据必须来自现场实际测量，不可在办公室臆测
2. **团队协作**：绘制VSM应由跨职能团队共同完成
3. **定期更新**：每6-12个月更新一次VSM
4. **从简到繁**：首次可先画简版，逐步完善
5. **关注时间线**：时间线是非增值时间的可视化，是最有力的改善依据
6. **与改善联动**：VSM是改善的起点，不是终点——画完后要制定改善计划并执行
