# 附录

## 概述

本附录为精益转型知识库提供辅助参考资料，包括术语定义、推荐阅读和模板使用指南。

## 文件清单

| 文件 | 内容 | 说明 |
|------|------|------|
| `01-精益术语表.md` | 中英文精益术语对照表 | 60+术语，按类别分组，含定义 |
| `02-参考文献与推荐阅读.md` | 推荐书籍、网站、课程 | 入门到进阶的学习资源 |
| `03-模板使用说明.md` | 模板总览和使用规范 | 所有模板的分类和使用指南 |

## 使用建议

- 初学者建议先阅读术语表，建立精益基础知识框架
- 根据自身水平选择合适的推荐书籍和课程
- 使用模板前务必阅读模板使用说明
- 术语表可作为日常参考，遇到不确定的术语时查阅
