## 3. 使用规范

### 3.1 模板版本管理

| 规范项 | 要求 |
|--------|------|
| 版本号规则 | V1.0（初始版本），后续以0.1为单位递增 |
| 修改记录 | 每次修改必须在文档信息中更新版本号和日期 |
| 变更说明 | 大版本变更（如V1.0→V2.0）需说明变更原因 |
| 归档保存 | 历史版本应归档保存，便于追溯 |

### 3.2 填写要求

| 规范项 | 要求 |
|--------|------|
| 必填项 | 标注"_[填写]_"的字段必须填写，不得留空 |
| 日期格式 | 统一使用YYYY-MM-DD格式 |
| 金额单位 | 统一使用万元（人民币），保留两位小数 |
| 百分比 | 使用%符号，保留一位小数 |
| 人名 | 填写全名，必要时注明职位 |
| 备注 | 如有特殊说明，在备注栏填写 |

### 3.3 审批流程

| 模板类型 | 审批要求 |
|----------|----------|
| 项目章程 | 发起人签字 + 推进委员会主任签字 |
| 风险登记册 | 项目经理审核，红区风险需推进委员会审批 |
| 周报 | 项目经理编制，推进办公室审核 |
| 收尾报告 | 项目团队编制，管理层审批，财务审核 |
| ROI测算 | 项目经理编制，财务部门审核确认 |

### 3.4 存档要求

| 文件类别 | 保管期限 | 归档位置 | 访问权限 |
|----------|----------|----------|----------|
| 项目章程 | 永久 | 项目档案室 | 项目团队 |
| 收尾报告 | 永久 | 项目档案室 | 全公司 |
| 周报/月报 | 5年 | 项目档案室 | 项目团队 |

## 4. 模板定制指南

### 4.1 何时需要定制

- 企业有特殊的组织结构或审批流程
- 项目规模较小，标准模板过于复杂
- 项目有特殊的行业要求或合规要求
- 需要增加企业特有的字段或维度

### 4.2 定制原则

1. **保留核心结构**：模板的核心字段和结构不应删除
2. **可增不可减**：可以增加字段，但不应删除关键字段
3. **说明变更**：定制后的模板应标注"基于XX模板定制"
4. **版本独立**：定制模板使用独立版本号，如V1.0-C（C表示Customized）
5. **审批确认**：定制模板需经推进办公室确认

### 4.3 定制示例

```
原始字段：项目名称
定制后：项目名称 / 产线编号 / 改善区域

原始字段：责任人
定制后：责任人 / 协助人 / 审批人
```

## 5. 常见问题

### Q1：模板太多，不知道该用哪个？

**A：** 根据项目阶段选择：
- 启动阶段：项目章程 + 干系人登记册
- 规划阶段：沟通计划 + 甘特图 + 风险矩阵
- 执行阶段：周报 + 里程碑追踪表 + 风险登记册
- 监控阶段：KPI仪表板
- 收尾阶段：ROI测算 + 收尾报告

### Q2：小型项目需要使用所有模板吗？

**A：** 不需要。小型项目可以：
- 简化项目章程（合并为一页纸项目概述）
- 省略干系人登记册（如干系人较少）
- 合并周报和里程碑追踪
- 保留风险管理（但可简化）

### Q3：模板填写不完整怎么办？

**A：** 
- 标注"不适用"并说明原因
- 关键字段（标记为必填）必须填写
- 可在备注栏说明未填写的原因

### Q4：模板可以修改格式吗？

**A：** 可以调整格式（字体、表格样式等），但必须：
- 保留所有核心字段
- 不删除关键内容区域
- 不改变数据逻辑关系

### Q5：如何确保模板数据的准确性？

**A：** 
- 建立数据审核机制
- 关键数据需多方确认
- 定期与实际数据对比验证
- 使用自动化工具减少人工录入错误

### Q6：模板的电子版和纸质版如何管理？

**A：**
- 电子版为主，纸质版为辅
- 重要审批文件需保留纸质签字版
- 电子版按统一文件夹结构归档
- 纸质版扫描后与电子版一起存档
