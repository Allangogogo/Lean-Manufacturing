# 04-培训模板

## 子目录说明

本目录提供培训管理中常用的标准模板，包括签到管理、效果评估、讲师评价和学员反馈四个方面，确保培训过程的规范化和可追溯性。

## 文件列表

| 文件 | 说明 |
|------|------|
| [培训签到表](./01-培训签到表.md) | 培训签到记录表结构及使用说明 |
| [培训效果评估表](./02-培训效果评估表.md) | 基于柯氏四级评估模型的综合评估表 |
| [讲师评价表](./03-讲师评价表.md) | 学员对讲师授课质量的评价表 |
| [学员反馈表](./04-学员反馈表.md) | 学员对课程内容和教学方法的反馈表 |

## 使用说明

- 每次培训均应使用签到表记录参训人员
- 培训结束后立即收集学员反馈表和讲师评价表
- 培训效果评估应在培训后1-3个月进行行为层和结果层评估
- 所有模板可根据企业实际情况进行调整
