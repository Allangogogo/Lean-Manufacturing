# 06-效果反馈

## 子目录说明

本目录提供培训效果评估的框架、度量指标和持续改进工具，构建从评估到改进的完整闭环，确保培训投资的有效性。

## 文件列表

| 文件 | 说明 |
|------|------|
| [柯氏四级评估框架](./01-柯氏四级评估框架.md) | 基于柯氏模型的四层培训效果评估体系 |
| [培训效果度量指标](./02-培训效果度量指标.md) | 培训关键绩效指标的定义、计算方法和目标值 |
| [持续改进跟踪表](./03-持续改进跟踪表.md) | 培训改进建议的收集、分类和效果验证工具 |

## 使用说明

- 每次培训后执行Level 1（反应层）和Level 2（学习层）评估
- 每季度执行Level 3（行为层）评估
- 每半年或年度执行Level 4（结果层）评估
- 评估结果应纳入持续改进跟踪表，推动培训体系的不断优化
