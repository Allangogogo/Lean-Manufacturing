# 领导力培训大纲

## 1. 课程基本信息

| 项目 | 内容 |
|------|------|
| 课程名称 | 精益领导力培训 |
| 课程代码 | L3-001 |
| 总课时 | 24课时（每课时45分钟） |
| 培训方式 | 课堂讲授 + 案例分析 + 实操练习 + 角色扮演 |
| 适合对象 | 管理层（总经理、副总、部门经理、车间主任） |
| 前置条件 | 完成工具专项培训（L2-001）或具备同等水平精益知识 |
| 课程讲师 | 高级精益顾问 / 外部专家 |
| 教材 | 领导力培训手册、A3模板、VSM模板、案例集 |

## 2. 课程目标

完成本课程后，学员应能够：

1. **践行精益领导力**：运用精益领导理念指导团队，推动现场改善
2. **运用A3思维解决问题**：使用A3报告结构化地分析和解决问题
3. **绘制和分析价值流图**：独立完成当前状态和未来状态价值流图的绘制
4. **主持Kaizen改善活动**：组织和主持改善周活动，带领团队取得成果
5. **管理精益变革**：识别变革阻力，制定应对策略，推动组织变革
6. **进行精益评估**：使用精益评估框架审核现场，制定改进计划

### 模块1：精益领导力（4课时）

#### 教学目标

- 理解精益领导者的角色和行为准则
- 掌握现场现物（Genchi Genbutsu）的实践方法
- 建立精益日常管理体系

#### 教学内容

**1.1 精益领导者角色定位（60分钟）**

- 从"指挥官"到"教练"的角色转变
- 精益领导者的核心行为
  - 现场现物（Genchi Genbutsu）：到现场看实物
  - 现地现时（Genba）：在实际发生问题的地方
  - 问"为什么"而不是直接给答案
  - 示范标准作业
  - 培养下属的精益思维
- 精益领导力的五个维度
  1. 以身作则
  2. 现场导向
  3. 培育人才
  4. 持续改善
  5. 战略思维

**1.2 管理者标准化作业（60分钟）**

- 管理者日常标准化作业的内容
  - 每日现场巡视路线和检查点
  - 每日站会的组织和主持
  - 绩效看板的回顾和更新
  - 问题跟踪和闭环管理
- 管理者标准作业表的编制
- 实例：某制造企业车间主任的日常标准作业

**1.3 精益日常管理体系（60分钟）**

- 每日站会（Daily Stand-up Meeting）
  - 目的：信息共享、问题暴露、快速响应
  - 时长：15分钟以内
  - 内容：安全、质量、交付、成本、人员
- 可视化绩效管理
  - 生产绩效看板的设计和使用
  - 安灯系统和异常响应流程
  - 红绿灯管理法
- 层级会议体系
  - 班组级：每日站会
  - 车间级：每周精益回顾
  - 部门级：每月精益评审
  - 公司级：每季度精益战略回顾

**1.4 案例讨论（60分钟）**

- 成功案例：某制造企业精益转型中管理层的关键作用
- 失败案例：管理层不参与导致精益推行失败的教训
- 小组讨论：如何在自己的部门推动精益

### 模块2：A3问题解决（4课时）

#### 教学目标

- 理解A3思维的本质和价值
- 掌握A3报告的结构和编制方法
- 能够运用A3方法解决实际管理问题

#### 教学内容

**2.1 A3思维概述（30分钟）**

- A3名称的由来：A3纸张大小（297mm x 420mm）
- A3思维的本质：将复杂问题结构化、可视化
- A3报告的用途
  - 问题解决报告
  - 现状把握报告
  - 改善提案报告
  - 项目计划报告
- A3与PDCA的关系

**2.2 A3报告的结构（60分钟）**

A3报告的10个标准部分：

| 序号 | 部分 | 内容要点 | PDCA对应 |
|------|------|----------|----------|
| 1 | 主题 | 问题或改善主题的标题 | Plan |
| 2 | 背景 | 为什么这个问题重要 | Plan |
| 3 | 当前状态 | 问题的现状和数据 | Plan |
| 4 | 目标 | 期望达到的目标状态 | Plan |
| 5 | 根本原因 | 导致问题的根本原因分析 | Plan |
| 6 | 对策 | 针对根本原因的对策方案 | Do |
| 7 | 实施计划 | 对策的实施步骤和时间表 | Do |
| 8 | 效果确认 | 对策实施后的效果验证 | Check |
| 9 | 标准化 | 成功做法的标准化和固化 | Act |
| 10 | 后续工作 | 遗留问题和下一步计划 | Act |

**2.3 A3编制实操（90分钟）**

- 每位学员选择一个实际的管理问题
- 按照A3结构逐步编制报告
- 讲师巡回指导，提供反馈
- 小组内分享和互评

### 模块3：价值流图（6课时）

#### 教学目标

- 掌握价值流图的符号和绘制方法
- 能够独立绘制当前状态价值流图
- 能够设计未来状态价值流图
- 制定从当前到未来的改善计划

#### 教学内容

**3.1 价值流图基础（60分钟）**

- 价值流的定义：从原材料到成品交付客户的全部活动
- 价值流图的目的
  - 识别增值和非增值活动
  - 发现改善机会
  - 建立未来愿景
  - 制定改善计划
- 价值流图的基本符号
  - 流程框、数据框、库存三角
  - 推动箭头、拉动箭头
  - 信息流箭头、物料流箭头
  - 时间线（增值时间和非增值时间）

**3.2 当前状态图绘制（90分钟）**

- 绘制步骤
  1. 选择产品族
  2. 绘制物料流（从右到左）
  3. 绘制信息流
  4. 收集数据（各工序的周期时间、换模时间、可用时间、不良率等）
  5. 绘制时间线
  6. 计算增值比
- 产品族选择方法
- 产品生产典型工序的数据收集要点

**3.3 当前状态图绘制练习（90分钟）**

- 以某产品为例
- 现场收集数据（或使用提供的模拟数据）
- 绘制完整的当前状态价值流图
- 计算增值比和生产周期

**3.4 未来状态图设计（60分钟）**

- 未来状态设计的七个关键问题
  1. 节拍时间是多少？
  2. 哪里可以建立连续流？
  3. 哪里需要使用拉动系统？
  4. 生产指令在何处下达？
  5. 如何均衡生产？
  6. 哪些工序需要改善？
  7. 需要什么流程改善来实现未来状态？
- 制造企业未来状态图示例

**3.5 改善计划制定（30分钟）**

- 从当前状态到未来状态的差距分析
- 改善项目的优先级排序
- 改善路线图的制定
- 改善项目的负责人和时间安排

### 模块4：Kaizen主持技巧（4课时）

#### 教学目标

- 掌握Kaizen改善周的组织和准备方法
- 能够有效主持改善团队的工作
- 学会管理改善过程中的常见问题

#### 教学内容

**4.1 Kaizen改善周的准备（40分钟）**

- 改善主题的选择标准
- 改善团队的组建（6-8人，跨职能）
- 改善前的数据收集和准备
- 改善期间的后勤安排（场地、物料、工具）
- 改善目标的设定

**4.2 改善周的组织和主持（80分钟）**

- 改善周的典型日程安排

| 日期 | 上午 | 下午 |
|------|------|------|
| 第1天 | 现状了解和数据收集 | 问题分析和原因识别 |
| 第2天 | 对策头脑风暴 | 方案评估和选择 |
| 第3天 | 对策实施 | 对策实施和调试 |
| 第4天 | 效果验证 | 标准化和固化 |
| 第5天 | 成果总结 | 汇报发表 |

- 主持人的关键职责
  - 管理时间和议程
  - 引导团队讨论
  - 保持团队动力
  - 处理冲突和分歧
  - 确保成果产出

**4.3 改善发表会（40分钟）**

- 改善发表会的组织和准备
- 发表报告的结构和内容
- 发表技巧：STAR法则（情境-任务-行动-结果）
- 评委提问和点评的技巧

**4.4 模拟主持练习（60分钟）**

- 分组模拟主持一次Kaizen改善活动
- 每组轮流担任主持人
- 其他学员扮演团队成员
- 讲师观察并提供反馈

### 模块5：变革管理（4课时）

#### 教学目标

- 理解组织变革的基本理论
- 能够识别精益推行中的常见阻力
- 制定有效的变革沟通和推进策略

#### 教学内容

**5.1 变革管理理论（40分钟）**

- Kotter八步变革法
  1. 建立紧迫感
  2. 组建领导团队
  3. 制定愿景和战略
  4. 沟通变革愿景
  5. 授权广泛行动
  6. 创造短期成效
  7. 巩固成果并推进
  8. 将变革融入文化
- 变革曲线：否认→愤怒→协商→接受→承诺
- 组织变革的常见失败原因

**5.2 精益变革中的阻力分析（40分钟）**

| 阻力来源 | 表现形式 | 应对策略 |
|----------|----------|----------|
| 习惯惯性 | "我们一直这样做" | 展示改善效果，小步推进 |
| 能力不足 | "我不知道怎么做" | 加强培训和辅导 |
| 利益受损 | 担心岗位或权力变化 | 沟通利益，提供发展机会 |
| 信任缺失 | 对管理层动机怀疑 | 以身作则，兑现承诺 |
| 资源不足 | "没有时间和预算" | 合理分配资源，展示ROI |
| 短期压力 | 生产任务重，没时间改善 | 从快速改善入手，展示收益 |

**5.3 利益相关者管理（40分钟）**

- 利益相关者识别和分析
- 利益相关者矩阵：影响力 x 支持度
- 不同利益相关者的管理策略
  - 高支持高影响力：充分授权
  - 高支持低影响力：保持沟通
  - 低支持高影响力：重点管理
  - 低支持低影响力：适度关注

**5.4 沟通计划制定（40分钟）**

- 精益变革沟通的五个关键信息
  1. 为什么要变革（Why）
  2. 变革的愿景是什么（What）
  3. 对每个人意味着什么（What's in it for me）
  4. 如何参与变革（How）
  5. 支持和资源在哪里（Support）
- 沟通渠道和频率
- 角色扮演：模拟处理精益推行中的典型阻力场景

### 模块6：精益评估与审计（2课时）

#### 教学目标

- 了解精益成熟度评估框架
- 能够使用审核检查表进行现场审核
- 能够撰写审核报告并制定改进计划

#### 教学内容

**6.1 精益成熟度评估框架（30分钟）**

- 精益成熟度的五个级别
  1. 初始级：随机、被动的改善活动
  2. 基础级：建立基本的精益工具应用
  3. 系统级：系统化的精益管理体系
  4. 优化级：持续改善的组织文化
  5. 卓越级：行业标杆的精益实践
- 评估维度
  - 领导力和战略
  - 现场管理
  - 流程管理
  - 人才发展
  - 质量管理
  - 设备管理
  - 安全管理

**6.2 现场审核技巧（40分钟）**

- 审核前的准备：检查表、计划、分组
- 审核中的技巧
  - 观察：看现场、看数据、看行为
  - 提问：开放式问题为主
  - 记录：客观记录发现
  - 沟通：尊重被审核方
- 审核后的报告撰写
- 审核发现的分类：符合、不符合、观察项

**6.3 审核实操（50分钟）**

- 对模拟车间（或实际车间区域）进行审核
- 使用精益审核检查表
- 记录审核发现
- 撰写审核报告
- 制定改进计划

## 5. 考核方式

### 5.1 A3报告提交（30%）

- 提交一份完整的A3问题解决报告
- 评审标准：
  - 问题定义清晰度（15%）
  - 数据和分析的准确性（25%）
  - 根本原因分析的深度（25%）
  - 对策的有效性和可行性（20%）
  - 报告格式和逻辑性（15%）

### 5.2 价值流图绘制（25%）

- 完成一份当前状态和未来状态价值流图
- 评审标准：
  - 数据准确性和完整性（30%）
  - 符号使用的规范性（20%）
  - 问题识别的全面性（25%）
  - 未来状态设计的合理性（25%）

### 5.3 Kaizen活动模拟（25%）

- 模拟主持一次Kaizen改善活动
- 评估标准：
  - 活动组织和时间管理（25%）
  - 团队引导和讨论效果（30%）
  - 问题分析和对策质量（25%）
  - 发表和汇报效果（20%）

### 5.4 课堂参与（20%）

- 出勤率：100%
- 案例讨论参与度
- 角色扮演投入度
