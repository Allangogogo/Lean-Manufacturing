# 工具专项培训大纲

## 1. 课程基本信息

| 项目 | 内容 |
|------|------|
| 课程名称 | 精益工具专项培训 |
| 课程代码 | L2-001 |
| 总课时 | 16课时（每课时45分钟） |
| 培训方式 | 课堂讲授 + 模拟演练 + 现场实操 + 小组练习 |
| 适合对象 | 班组长、工程师（工艺、质量、设备）、生产计划员 |
| 前置条件 | 完成精益意识培训（L1-001）并取得合格证书 |
| 课程讲师 | 内部高级讲师 / 外部精益顾问 |
| 教材 | 工具专项培训手册、练习册、案例集 |

## 2. 课程目标

完成本课程后，学员应能够：

1. **掌握看板系统的设计和运行方法**：能够为生产线设计和计算看板数量
2. **编制标准作业文件**：能够制作标准作业组合票和标准作业票
3. **实施自主保全**：理解TPM自主保全的七个步骤并能制定保全基准
4. **设计防错装置**：运用防错原理设计防错方案
5. **实施SMED快速换模**：运用SMED方法缩短换模时间
6. **主持Kaizen改善活动**：运用问题分析工具制定改善方案

### 模块1：看板系统（2课时）

#### 教学目标

- 理解看板的种类和作用
- 掌握看板数量的计算方法
- 能够设计适合生产线的看板系统

#### 教学内容

**1.1 看板基础概念（20分钟）**

- 看板的起源和定义
- 看板的两大功能：生产指示和物料搬运
- 看板运行的基本规则
  - 规则1：后工序向前工序取货
  - 规则2：前工序按看板数量生产
  - 规则3：没有看板不生产、不搬运
  - 规则4：看板必须附在实物上
  - 规则5：不良品不流入后工序

**1.2 看板种类详解（25分钟）**

| 看板类型 | 用途 | 制造工序应用 |
|----------|------|----------------|
| 生产看板 | 指示前工序生产 | 机加工工序的生产指令 |
| 运输看板 | 指示物料搬运 | 工序间半成品的搬运指令 |
| 信号看板 | 批量生产时的生产信号 | 热处理批量生产触发 |
| 临时看板 | 应对临时需求 | 紧急订单的特殊看板 |
| 供应商看板 | 向供应商订货 | 原材料（原材料、卷料）的订货看板 |

**1.3 看板数量计算（25分钟）**

- 看板数量计算公式：
  ```
  看板数量 = (日需求量 x 前置时间 x (1 + 安全系数)) / 每箱数量
  ```
- 计算实例：以某种工件为例
  - 日需求量：10,000件
  - 前置时间：0.5天
  - 安全系数：0.1
  - 每箱数量：500件
  - 看板数量 = (10,000 x 0.5 x 1.1) / 500 = 11张
- 练习：计算另外两种产品的看板数量

**1.4 看板系统设计练习（30分钟）**

- 小组任务：为一条生产线设计看板系统
- 步骤：
  1. 分析生产流程和工序关系
  2. 确定看板种类和数量
  3. 设计看板样式和内容
  4. 制定看板运行规则
  5. 绘制看板运行流程图

### 模块2：标准作业（2课时）

#### 教学目标

- 理解标准作业三要素
- 掌握标准作业组合票和标准作业票的编制方法
- 能够编制产品工序的标准作业文件

#### 教学内容

**2.1 标准作业基础（20分钟）**

- 标准作业的定义和目的
- 标准作业三要素
  - **节拍时间**（Takt Time）：客户需求的节奏
    - 计算公式：节拍时间 = 可用工作时间 / 客户需求量
  - **作业顺序**：最高效的作业步骤
  - **标准在制品**：维持流程所需的最少在制品
- 标准作业与作业标准的区别

**2.2 标准作业组合票（30分钟）**

- 标准作业组合票的结构和内容
- 时间观测方法
- 手动时间、自动时间、走动时间的区分
- 编制步骤和注意事项
- 实例：工件冲压工序标准作业组合票

**2.3 标准作业票（20分钟）**

- 标准作业票的内容：作业步骤、时间、在制品位置
- 标准作业票的制作方法
- 现场张贴和维护要求
- 标准作业票与作业指导书的关系

**2.4 编制练习（30分钟）**

- 选择一个产品工序（如机加工或精加工）
- 观测实际作业时间
- 编制标准作业组合票
- 制作标准作业票

### 模块3：TPM基础（3课时）

#### 教学目标

- 理解TPM的八大支柱和核心理念
- 掌握自主保全的七个步骤
- 能够制定设备日常保全基准

#### 教学内容

**3.1 TPM概述（30分钟）**

- TPM的定义：全员生产维护
- TPM的八大支柱
  1. 自主保全
  2. 计划保全
  3. 个别改善
  4. 教育训练
  5. 初期管理
  6. 品质保全
  7. 事务改善
  8. 安全环境
- 设备的六大损失
  - 故障损失
  - 换模调整损失
  - 空转短停损失
  - 速度降低损失
  - 不良品损失
  - 启动损失
- OEE（设备综合效率）的概念和计算

**3.2 自主保全七步骤（60分钟）**

| 步骤 | 名称 | 主要内容 | 产品设备要点 |
|------|------|----------|----------------|
| 1 | 初期清扫 | 清扫设备，发现异常 | 机加工设备、精加工设备清扫标准 |
| 2 | 发生源对策 | 消除污染发生源 | 润滑油泄漏治理 |
| 3 | 清扫基准 | 制定清扫和点检标准 | 设备点检基准书编制 |
| 4 | 总点检 | 全面检查设备 | 设备精度检查要点 |
| 5 | 自主点检 | 员工自主进行日常点检 | 操作工日常点检项目 |
| 6 | 整理整顿 | 工作场所标准化 | 设备周边工具和物料管理 |
| 7 | 自主管理 | 持续改善，自主管理 | 自主保全活动推进 |

**3.3 设备日常保全实操（60分钟）**

- 现场观摩：一台产品设备的日常保全流程
- 实操练习：在指导下进行设备点检
- 保全基准书编制练习：为一台设备制定保全基准

**3.4 产品设备保全要点（30分钟）**

| 设备类型 | 关键保全项目 | 点检频率 |
|----------|--------------|----------|
| 机加工设备 | 模具状态、润滑系统、冲压力 | 每班次 |
| 精加工设备 | 加工刀具状态、冷却系统、进料机构 | 每班次 |
| 热处理炉 | 温度控制、气氛控制、传送速度 | 每班次 |
| 表面处理线 | 溶液浓度、温度、电流密度 | 每班次 |
| 包装机 | 称重精度、封口质量、计数器 | 每班次 |

### 模块4：防错技术（2课时）

#### 教学目标

- 理解防错（Poka-Yoke）的概念和分类
- 掌握防错装置的设计原则
- 能够针对具体问题设计防错方案

#### 教学内容

**4.1 防错基础（20分钟）**

- 防错的定义：通过设计使错误不可能发生或立即被发现
- 防错的三个层次
  1. **预防型防错**：使错误不可能发生
  2. **检测型防错**：使错误立即被发现
  3. **缓解型防错**：使错误的影响最小化
- 防错与质量零缺陷的关系

**4.2 防错方法分类（25分钟）**

| 防错方法 | 原理 | 制造工序应用 |
|----------|------|----------------|
| 固定销防错 | 通过固定销使错误位置无法安装 | 模具安装方向防错 |
| 光电感应 | 通过传感器检测物体存在 | 产品计数和缺件检测 |
| 接触式检测 | 通过接触判断产品尺寸 | 量规自动检测 |
| 限位装置 | 通过限位使操作只能在正确位置进行 | 工装夹具定位防错 |
| 顺序控制 | 通过控制确保操作按正确顺序进行 | 工序顺序防错 |
| 计数器 | 通过计数确保操作次数正确 | 工件数量计数包装 |
| 标识防错 | 通过颜色等标识区分 | 产品规格颜色区分 |

**4.3 产品防错案例分析（25分钟）**

- **案例1：加工方向防错**
  - 问题：部分工件正反面混装
  - 防错方案：设计导向槽，使反面产品无法通过
  - 效果：混装率从2%降至0%

- **案例2：产品规格混装防错**
  - 问题：不同规格的工件混装
  - 防错方案：不同规格使用不同颜色料盒，料盒口尺寸与产品匹配
  - 效果：混装率从1.5%降至0%

- **案例3：热处理温度监控防错**
  - 问题：热处理温度偏差导致力学性能不合格
  - 防错方案：安装温度自动监控和报警系统，超温自动停炉
  - 效果：温度偏差导致的不合格率从1%降至0.1%

**4.4 防错设计练习（30分钟）**

- 小组任务：针对一个给定的质量问题设计防错方案
- 步骤：
  1. 分析问题的根本原因
  2. 确定防错类型（预防/检测/缓解）
  3. 设计防错装置或方法
  4. 评估方案的有效性和可行性
  5. 制定实施计划

### 模块5：SMED快速换模（3课时）

#### 教学目标

- 理解SMED的核心理念和方法
- 掌握区分内部作业和外部作业的技巧
- 能够运用SMED方法缩短换模时间
- 了解产品模具更换的特殊性

#### 教学内容

**5.1 SMED基础概念（20分钟）**

- SMED的定义：Single Minute Exchange of Die（单位数换模）
- 换模时间的定义：从最后一个合格品到第一个合格品之间的时间
- 换模时间的四大构成
  1. 准备时间
  2. 拆卸时间
  3. 安装时间
  4. 调试时间
- SMED的三个阶段
  1. 区分内部作业和外部作业
  2. 将内部作业转化为外部作业
  3. 缩短内部作业时间

**5.2 内外部作业区分（25分钟）**

- **内部作业**：必须停机才能进行的作业
- **外部作业**：可以在设备运行时进行的作业
- 区分方法：逐一分析每个换模步骤
- 常见的外部化机会
  - 预热模具（在设备运行时预热）
  - 准备工具和物料（提前准备好）
  - 首件检验标准确认（提前确认）

**5.3 SMED改善方法（30分钟）**

- 缩短内部作业时间的方法
  - 并行作业：两人同时操作
  - 标准化：统一操作方法和工具
  - 快速锁定装置：用快速夹具替代工件
  - 功能集成：减少调整步骤
- 产品换模的SMED改善实例
  - 机加工设备换模：从45分钟缩短至15分钟
  - 精加工设备换板：从30分钟缩短至10分钟

**5.4 模拟工位换模演练（55分钟）**

- 在模拟工位进行换模演练
- 步骤：
  1. 第一轮：记录当前换模流程和时间（基准数据）
  2. 分析：区分内部和外部作业
  3. 改善：实施外部化和时间缩短措施
  4. 第二轮：记录改善后的换模时间
  5. 对比：计算改善效果
- 记录和分析改善过程

### 模块6：Kaizen方法（2课时）

#### 教学目标

- 掌握Kaizen改善的基本步骤和工具
- 能够运用问题分析工具找到根本原因
- 能够制定和实施改善方案

#### 教学内容

**6.1 Kaizen改善流程（20分钟）**

- Kaizen改善的八个步骤
  1. 选择改善主题
  2. 现状调查和数据收集
  3. 目标设定
  4. 原因分析
  5. 对策制定
  6. 对策实施
  7. 效果确认
  8. 标准化和固化

**6.2 问题分析工具（40分钟）**

**鱼骨图（因果图）**

- 鱼骨图的结构：人、机、料、法、环、测
- 绘制步骤和技巧
- 产品质量鱼骨图实例

**5Why分析法**

- 连续追问"为什么"直到找到根本原因
- 5Why分析实例：工件表面裂纹问题
  - Why 1：为什么工件头部有裂纹？→ 因为机加工时材料流动不均匀
  - Why 2：为什么材料流动不均匀？→ 因为原材料硬度不均匀
  - Why 3：为什么原材料硬度不均匀？→ 因为来料检验未检测硬度
  - Why 4：为什么未检测硬度？→ 因为供应商质量管控不足
  - Why 5：为什么供应商管控不足？→ 因为供应商审核机制不完善

**帕累托图**

- 80/20法则的应用
- 帕累托图的绘制方法
- 用于确定改善优先级

**6.3 改善方案制定与实施（30分钟）**

- 对策制定的原则：消除>替代>简化>检测
- 对策的可行性评估
- 改善实施计划的编制
- 改善效果的验证方法

### 模块7：综合演练（2课时）

#### 教学目标

- 综合运用所学工具解决模拟生产问题
- 培养团队协作和问题解决能力
- 体验完整的改善过程

#### 教学内容

**7.1 模拟场景介绍（15分钟）**

- 模拟场景：某生产线面临以下问题
  - 换模时间长，影响产能
  - 在制品库存高，占用资金
  - 质量不良率偏高
  - 设备故障频繁

**7.2 小组改善活动（75分钟）**

- 各小组（4-6人）分工协作
- 运用所学工具进行系统改善
  - 运用看板管理控制在制品
  - 运用标准作业规范操作
  - 运用SMED缩短换模时间
  - 运用防错技术降低不良率
  - 运用TPM减少设备故障

**7.3 改善成果汇报（30分钟）**

- 各小组汇报改善成果
- 汇报内容：问题分析、改善措施、预期效果
- 讲师点评和建议
- 评选最佳改善团队

## 5. 考核方式

### 5.1 笔试测试（40%）

- 考试时间：90分钟
- 题型：选择题、简答题、计算题、案例分析题
- 合格标准：75分以上

### 5.2 工具应用实操（40%）

| 考核项目 | 权重 | 考核方式 |
|----------|------|----------|
| 看板设计 | 10% | 设计一套看板系统 |
| 标准作业编制 | 10% | 编制一份标准作业组合票 |
| 模拟换模 | 10% | 完成一次SMED改善演练 |
| 防错设计 | 10% | 设计一个防错方案 |

### 5.3 改善项目报告（20%）

- 提交一份完整的改善项目报告
- 报告内容：问题描述、现状分析、原因分析、改善对策、效果验证
- 由讲师和精益推进委员会评审
