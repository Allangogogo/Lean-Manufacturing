# 02-培训材料

## 子目录说明

本目录包含四类精益培训课程的详细大纲，按照培训层级从基础到高级排列，每份大纲包含课程目标、模块内容、教学方法和考核方式。

## 文件列表

| 文件 | 课时 | 适合对象 |
|------|------|----------|
| [精益意识培训大纲](./01-精益意识培训大纲.md) | 8课时 | 全体员工 |
| [工具专项培训大纲](./02-工具专项培训大纲.md) | 16课时 | 班组长、工程师 |
| [领导力培训大纲](./03-领导力培训大纲.md) | 24课时 | 管理层 |
| [高级精益培训大纲](./04-高级精益培训大纲.md) | 40课时 | 精益推进者 |

## 使用说明

- 各大纲可根据企业实际情况调整模块顺序和课时分配
- 案例和练习均以离散制造为背景设计
- 建议配合 [培训模板](../04-培训模板/) 中的签到表、评估表使用
