# 05-记录追踪

## 子目录说明

本目录提供培训记录管理和能力追踪的工具，帮助企业建立完整的培训档案体系，实现培训效果的可视化追踪。

## 文件列表

| 文件 | 说明 |
|------|------|
| [培训记录汇总表](./01-培训记录汇总表.md) | 培训记录的结构化汇总及年度统计方法 |
| [技能矩阵追踪表](./02-技能矩阵追踪表.md) | 员工技能掌握程度的矩阵化追踪工具 |
| [认证进度追踪表](./03-认证进度追踪表.md) | 精益认证级别的进度追踪及可视化方法 |

## 使用说明

- 培训记录应在每次培训结束后24小时内完成录入
- 技能矩阵建议每季度更新一次
- 认证进度追踪应与个人发展计划相结合
- 所有记录应保存至少3年，作为员工能力发展档案
