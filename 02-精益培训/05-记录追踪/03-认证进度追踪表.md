# 认证进度追踪表

## 1. 模板说明

本模板用于追踪员工在精益认证体系中的进度，包括各级别的培训完成情况、项目实践和考核成绩。认证进度追踪有助于激励员工持续学习，并为人才发展提供客观依据。

## 2. 认证级别定义

### 2.1 三级认证体系

| 级别 | 名称 | 课时要求 | 实践要求 | 考核要求 | 有效期 |
|------|------|----------|----------|----------|--------|
| 一级 | 精益入门 | 8课时 | 无 | 笔试70分以上 | 永久（每2年复训） |
| 二级 | 精益实践者 | 24课时（含一级） | 参与1个改善项目 | 笔试75分以上 + 项目评审 | 3年 |
| 三级 | 精益专家 | 64课时（含一、二级） | 主导2个改善项目 | 综合评审通过 | 3年 |

### 2.2 各级别详细要求

#### 一级：精益入门

- [ ] 完成精益意识培训（8课时）
- [ ] 笔试成绩70分以上
- [ ] 现场浪费识别合格
- [ ] 颁发"精益入门"证书

#### 二级：精益实践者

- [ ] 持有一级证书
- [ ] 完成工具专项培训（16课时）
- [ ] 完成领导力培训基础模块（8课时，选修）
- [ ] 笔试成绩75分以上
- [ ] 工具应用实操合格
- [ ] 参与1个Kaizen改善项目（有记录）
- [ ] 提交并通过改善项目报告评审
- [ ] 颁发"精益实践者"证书

#### 三级：精益专家

- [ ] 持有二级证书
- [ ] 完成高级精益培训（40课时）
- [ ] 主导2个精益改善项目（有完整记录）
- [ ] DMAIC项目报告通过评审
- [ ] 精益评估报告通过评审
- [ ] 教练技术评估合格
- [ ] 综合评审委员会评审通过
- [ ] 颁发"精益专家"证书

## 5. 使用说明

### 5.1 追踪流程

1. **培训完成时**：培训管理员在培训记录中注明对应的认证要求
2. **考核完成后**：将考核成绩录入认证追踪表
3. **项目实践完成时**：项目负责人确认实践要求的完成情况
4. **每季度审核**：培训管理部门审核各员工的认证进度
5. **证书颁发**：满足全部要求后，经评审委员会确认颁发证书

### 5.2 进度汇报

- 每月更新认证进度数据
- 每季度向管理层汇报认证推进情况
- 对进度滞后的员工进行跟进和辅导
- 年度认证工作总结和下年度目标设定

### 5.3 证书管理

- 证书编号规则：LR-级别-年份-序号（如：LR-1-2026-001）
- 证书有效期到期前3个月提醒员工复训
- 复训要求：参加对应级别的复训课程并通过考核
- 证书遗失可申请补发，补发证书编号加注"补"字
