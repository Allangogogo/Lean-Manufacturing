# 年度培训计划模板

## 1. 模板说明

本模板用于制定年度精益培训计划，以月份为时间单位安排全年的培训活动。模板采用表格形式，清晰展示每个月的培训主题、对象、讲师、课时、人数和预算，便于培训管理者进行系统化的年度规划。

## 2. 年度培训计划表格结构

### 2.1 表头字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 月份 | 培训安排的月份 | 1月、2月...12月 |
| 培训主题 | 该月的主要培训内容 | 精益意识全员轮训 |
| 培训对象 | 参训人员类别和人数 | 全体员工（200人） |
| 培训层级 | 对应的培训层级 | 第一层/第二层/第三层/第四层 |
| 讲师 | 培训讲师安排 | 内部讲师张工 / 外部顾问李老师 |
| 课时 | 培训总课时数 | 8课时 |
| 培训方式 | 教学方式 | 课堂+现场 |
| 人数 | 参训人数 | 50人/批 |
| 场次 | 培训场次 | 4场（每场50人） |
| 预算（元） | 该月培训预算 | 15,000元 |
| 备注 | 补充说明 | 需提前预订外部讲师 |

## 5. 使用说明

### 5.1 编制流程

1. **需求调研**（每年11月）：收集各部门培训需求
2. **计划编制**（每年12月）：制定下一年度培训计划
3. **审批发布**（每年1月）：经管理层审批后发布
4. **月度回顾**：每月末回顾当月计划执行情况
5. **季度调整**：每季度根据实际情况调整后续计划

### 5.2 注意事项

- 旺季（Q2-Q3）以OJT和短期培训为主，避免影响生产
- 外部讲师需提前1-2个月预约
- 培训预算应预留10%的应急费用
- 每次培训后及时更新计划执行记录
- 年度计划应与公司精益转型路线图保持一致

### 5.3 跟踪记录

| 跟踪项目 | 记录方式 | 频率 |
|----------|----------|------|
| 计划完成率 | 实际完成项/计划项 | 月度 |
| 预算执行率 | 实际支出/预算金额 | 月度 |
| 培训覆盖率 | 参训人数/应训人数 | 季度 |
| 考核通过率 | 合格人数/参训人数 | 每次培训后 |
