# 03-培训计划

## 子目录说明

本目录提供培训计划的模板文件，覆盖年度、季度和单次培训三个时间维度，帮助企业系统化地规划和安排精益培训活动。

## 文件列表

| 文件 | 说明 |
|------|------|
| [年度培训计划模板](./01-年度培训计划模板.md) | 全年培训安排的框架模板，含12个月培训主题示例 |
| [季度培训计划模板](./02-季度培训计划模板.md) | 季度细化计划模板，按周次分解培训任务 |
| [培训日程安排模板](./03-培训日程安排模板.md) | 单次培训的日程安排模板，精确到时间段 |

## 使用说明

- 三个模板为层级关系：年度计划 → 季度计划 → 单次日程
- 年度计划确定培训方向和预算，季度计划落实具体安排，日程安排指导每次培训执行
- 建议在每季度末进行计划回顾和下季度计划编制
