# 02-精益培训

## 模块概述

本模块为金属紧固件制造企业构建系统化的精益培训体系，涵盖培训策略规划、培训材料开发、培训计划制定、培训模板标准化、记录追踪管理和效果反馈评估六大板块，旨在培养全员精益思维，推动持续改善文化的落地。

## 目录结构

| 序号 | 子目录 | 说明 |
|------|--------|------|
| 01 | [培训策略](./01-培训策略/) | 精益培训体系规划、四层培训架构设计、预算与资源规划 |
| 02 | [培训材料](./02-培训材料/) | 精益意识、工具专项、领导力、高级精益四类培训大纲 |
| 03 | [培训计划](./03-培训计划/) | 年度培训计划、季度培训计划、单次培训日程模板 |

| 06 | [效果反馈](./06-效果反馈/) | 柯氏四级评估框架、度量指标、持续改进跟踪 |

## 培训体系特色

- **行业聚焦**：所有案例和练习均围绕金属紧固件制造场景设计
- **分层培养**：从全员精益意识到高级精益推进者的四层递进架构
- **实战导向**：OJT在岗训练与模拟工位实操相结合
- **闭环管理**：计划-执行-评估-改进的完整培训管理循环

## 适用对象

- 企业管理层（总经理、副总、部门经理）
- 工程技术人员（工艺工程师、质量工程师、设备工程师）
- 基层管理者（班组长、线长、拉长）
- 一线操作工（冲压、搓丝、热处理、表面处理、包装等岗位）
