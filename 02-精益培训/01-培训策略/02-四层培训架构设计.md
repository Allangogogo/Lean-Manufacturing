# 四层培训架构设计

## 1. 架构概述

### 1.1 设计理念

四层培训架构采用金字塔式递进设计，从全员基础培训到高级专业培训逐层深入。每一层都有明确的培训对象、内容体系、课时要求和考核标准，确保不同层级人员获得与其岗位匹配的精益能力。

### 1.2 架构总览

```
                    ┌─────────────────┐
                    │   第四层         │
                    │  高级精益培训    │  精益推进者（5-8人）
                    │  40课时          │
                    └────────┬────────┘
                   ┌─────────┴─────────┐
                   │     第三层         │
                   │   领导力培训       │  管理层（15-20人）
                   │   24课时           │
                   └─────────┬─────────┘
              ┌──────────────┴──────────────┐
              │          第二层              │
              │      工具专项培训            │  班组长+工程师（30-50人）
              │      16课时                  │
              └──────────────┬──────────────┘
         ┌───────────────────┴───────────────────┐
         │              第一层                    │
         │        精益意识培训                    │  全体员工（200-500人）
         │        8课时                           │
         └───────────────────────────────────────┘
```

## 2. 第一层：精益意识培训（全员）

### 2.1 培训目标

使全体员工理解精益生产的基本概念，认识工作中的浪费现象，树立持续改善的意识，为后续的精益推行奠定思想基础。

### 2.2 培训对象

- 全体员工，包括管理层、工程师、班组长和操作工
- 新员工入职一个月内必须完成

### 2.3 课时安排：8课时

| 模块 | 内容 | 课时 | 教学方式 |
|------|------|------|----------|
| 模块1 | 精益起源与哲学 | 2课时 | 课堂讲授 + 视频 |
| 模块2 | 八大浪费识别 | 2课时 | 课堂讲授 + 现场观察 |
| 模块3 | 5S与可视化管理 | 2课时 | 课堂讲授 + 现场实践 |
| 模块4 | 持续改善文化 | 2课时 | 案例分析 + 小组讨论 |

### 2.4 详细大纲

#### 模块1：精益起源与哲学（2课时）

**教学要点：**

- 丰田生产方式的起源和发展历程
- 精益生产的核心思想：消除浪费、持续改善、尊重人性
- 精益五原则：定义价值、识别价值流、建立流动、实现拉动、追求完美
- 制造业的精益转型趋势和案例

**教学方法：**

- 丰田历史纪录片片段（15分钟）
- 丰田与传统制造对比案例分析
- 小组讨论：精益思维对我们日常工作意味着什么

#### 模块2：八大浪费识别（2课时）

**教学要点：**

- 八大浪费的定义和表现形式
  - 过量生产浪费
  - 等待浪费
  - 搬运浪费
  - 过度加工浪费
  - 库存浪费
  - 动作浪费
  - 不良品浪费
  - 人才浪费
- 产品生产各工序中的典型浪费案例

**教学方法：**

- 每种浪费配合2-3个制造业实例
- 现场浪费识别练习（在车间实地观察，记录发现的浪费）
- 浪费识别竞赛：各小组比赛发现浪费数量和质量

#### 模块3：5S与可视化管理（2课时）

**教学要点：**

- 5S的定义、目的和实施要点
  - 整理（Seiri）：区分必要与不必要物品
  - 整顿（Seiton）：定置管理，取用方便
  - 清扫（Seiso）：清扫即点检
  - 清洁（Seiketsu）：标准化维持
  - 素养（Shitsuke）：养成良好习惯
- 目视化管理工具：颜色标识、看板、标线、警示灯
- 产品车间5S实施案例

**教学方法：**

- 5S实施前后对比图片展示
- 车间5S标准样板区参观
- 分组5S改善实践（选择一个区域进行15分钟快速5S）

#### 模块4：持续改善文化（2课时）

**教学要点：**

- Kaizen的理念：小步快跑、全员参与
- 合理化建议制度介绍
- PDCA循环的应用
- 改善发表会的组织和参与
- 制造企业持续改善成功案例分享

**教学方法：**

- 优秀改善案例展示和分析
- 小组改善提案练习：针对一个模拟问题提出改善方案
- 改善发表会模拟：各小组发表改善成果

### 2.5 考核标准

| 考核项目 | 权重 | 合格标准 |
|----------|------|----------|
| 笔试测试 | 60% | 70分以上（满分100分） |
| 现场浪费识别 | 30% | 至少正确识别5种以上浪费 |
| 课堂参与度 | 10% | 出勤率100%，积极参与讨论 |

### 2.6 认证要求

- 完成全部8课时培训
- 笔试成绩70分以上
- 现场浪费识别合格
- 颁发"精益意识培训合格证书"

## 3. 第二层：工具专项培训（班组长+工程师）

### 3.1 培训目标

使班组长和工程师掌握精益核心工具的原理和应用方法，能够在日常工作中运用这些工具解决实际问题，推动现场改善。

### 3.2 培训对象

- 各生产线班组长、线长
- 工艺工程师、质量工程师、设备工程师
- 生产计划员、物料管理人员

### 3.3 前置条件

完成第一层精益意识培训并取得合格证书。

### 3.4 课时安排：16课时

| 模块 | 内容 | 课时 | 教学方式 |
|------|------|------|----------|
| 模块1 | 看板系统 | 2课时 | 课堂 + 模拟 |
| 模块2 | 标准作业 | 2课时 | 课堂 + 现场 |
| 模块3 | TPM基础 | 3课时 | 课堂 + 实操 |
| 模块4 | 防错技术 | 2课时 | 课堂 + 设计 |
| 模块5 | SMED快速换模 | 3课时 | 课堂 + 模拟工位 |
| 模块6 | Kaizen方法 | 2课时 | 课堂 + 改善实践 |
| 模块7 | 综合演练 | 2课时 | 模拟工位实操 |

### 3.5 各模块要点

#### 模块1：看板系统（2课时）

**核心要点：**

- 看板的种类：生产看板、运输看板、信号看板
- 看板数量计算方法
- 看板运行规则和异常处理
- 生产线看板设计实例

**练习：** 为一条生产线设计看板系统，计算看板数量

#### 模块2：标准作业（2课时）

**核心要点：**

- 标准作业三要素：节拍时间、作业顺序、标准在制品
- 标准作业组合票的编制方法
- 标准作业票的制作和现场应用
- 产品冲压、精加工工序标准作业实例

**练习：** 选择一个产品工序，编制标准作业组合票

#### 模块3：TPM基础（3课时）

**核心要点：**

- TPM的八大支柱概述
- 自主保全的七个步骤
- 日常点检的标准和方法
- 产品生产设备（机加工设备、精加工设备、热处理炉）的保全要点

**练习：** 为一台机加工设备制定自主保全基准书

#### 模块4：防错技术（2课时）

**核心要点：**

- 防错（Poka-Yoke）的概念和分类
- 防错装置的设计原则
- 产品生产中的防错应用案例
  - 加工方向防错
  - 产品规格混装防错
  - 热处理温度监控防错

**练习：** 针对一个质量问题设计防错方案

#### 模块5：SMED快速换模（3课时）

**核心要点：**

- 换模时间的定义和构成
- 区分内部作业和外部作业
- 内部作业外部化的方法
- 换模作业标准化
- 产品模具更换的SMED改善实例

**练习：** 在模拟工位进行换模演练，记录改善前后的换模时间

#### 模块6：Kaizen方法（2课时）

**核心要点：**

- Kaizen改善的基本步骤
- 问题分析工具：鱼骨图、5Why、帕累托图
- 改善方案的制定和实施
- 改善成果的标准化和固化

**练习：** 针对一个模拟的生产问题，运用PDCA和问题分析工具制定改善方案

#### 模块7：综合演练（2课时）

**核心要点：**

- 综合运用所学工具解决模拟生产问题
- 团队协作和分工
- 改善成果汇报

**练习：** 在模拟工位上，各小组综合运用看板、标准作业、防错、SMED等工具进行改善

### 3.6 考核标准

| 考核项目 | 权重 | 合格标准 |
|----------|------|----------|
| 笔试测试 | 40% | 75分以上 |
| 工具应用实操 | 40% | 完成规定的工具应用任务 |
| 改善项目报告 | 20% | 提交一份完整的改善报告 |

### 3.7 认证要求

- 完成全部16课时培训
- 笔试成绩75分以上
- 工具应用实操合格
- 提交并通过改善项目报告评审
- 颁发"精益实践者（初级）认证证书"

## 4. 第三层：领导力培训（管理层）

### 4.1 培训目标

使管理层掌握精益领导力的核心理念和方法，具备主导A3问题解决、价值流分析和Kaizen改善活动的能力，能够在部门层面推动精益转型。

### 4.2 培训对象

- 总经理、副总
- 各部门经理
- 车间主任

### 4.3 前置条件

完成第二层工具专项培训或具备同等水平的精益知识。

### 4.4 课时安排：24课时

| 模块 | 内容 | 课时 | 教学方式 |
|------|------|------|----------|
| 模块1 | 精益领导力 | 4课时 | 课堂 + 案例 |
| 模块2 | A3问题解决 | 4课时 | 课堂 + 实操 |
| 模块3 | 价值流图 | 6课时 | 课堂 + 现场绘制 |
| 模块4 | Kaizen主持技巧 | 4课时 | 课堂 + 模拟 |
| 模块5 | 变革管理 | 4课时 | 课堂 + 角色扮演 |
| 模块6 | 精益评估与审计 | 2课时 | 课堂 + 现场审核 |

### 4.5 各模块要点

#### 模块1：精益领导力（4课时）

**核心要点：**

- 精益领导者的角色和职责
- 现场现物（Genchi Genbutsu）原则
- 管理者标准化作业
- 精益日常管理：每日站会、可视化绩效管理
- 培养下属的精益思维

**案例：** 制造企业精益转型中管理层角色转变的成功与失败案例

#### 模块2：A3问题解决（4课时）

**核心要点：**

- A3思维的本质：将复杂问题结构化
- A3报告的10个部分及其逻辑关系
- 问题定义和现状分析
- 根本原因分析
- 对策制定和效果验证
- A3报告的沟通和汇报技巧

**实操：** 每位学员选择一个实际问题，完成一份A3报告

#### 模块3：价值流图（6课时）

**核心要点：**

- 价值流图的符号和绘制方法
- 当前状态图的绘制和分析
- 未来状态图的设计原则
- 改善计划的制定
- 产品价值流图绘制实例

**现场实操：** 选择一款产品，现场绘制当前状态价值流图

#### 模块4：Kaizen主持技巧（4课时）

**核心要点：**

- Kaizen改善周的组织和准备
- 改善团队的组建和分工
- 现场观察和数据收集
- 改善方案的头脑风暴和决策
- 改善成果的汇报和标准化

**模拟：** 模拟主持一次为期半天的Kaizen改善活动

#### 模块5：变革管理（4课时）

**核心要点：**

- 变革管理的基本理论（Kotter八步法等）
- 精益转型中的常见阻力和应对策略
- 利益相关者分析和管理
- 沟通计划的制定和执行
- 可持续变革的关键成功因素

**角色扮演：** 模拟处理精益推行中的典型阻力场景

#### 模块6：精益评估与审计（2课时）

**核心要点：**

- 精益成熟度评估框架
- 现场审核检查表的使用
- 审核发现的分类和报告
- 改进计划的跟踪和闭环

### 4.6 考核标准

| 考核项目 | 权重 | 合格标准 |
|----------|------|----------|
| A3报告提交 | 30% | 提交一份完整的A3报告并通过评审 |
| 价值流图绘制 | 25% | 完成一份当前状态和未来状态价值流图 |
| Kaizen活动模拟 | 25% | 模拟主持Kaizen活动表现评估 |
| 课堂参与 | 20% | 出勤率100%，积极参与讨论和练习 |

### 4.7 认证要求

- 完成全部24课时培训
- A3报告通过评审
- 价值流图绘制合格
- Kaizen主持模拟评估合格
- 颁发"精益管理者认证证书"

## 5. 第四层：高级精益培训（精益推进者）

### 5.1 培训目标

培养企业内部的精益专家和推进者，使其具备DMAIC方法论应用、战略部署、教练技术等高级能力，能够独立领导大型精益改善项目并指导他人开展精益活动。

### 5.2 培训对象

- 精益推进部门负责人
- 高级精益工程师
- 储备精益推进者（经推荐和选拔）

### 5.3 前置条件

- 完成第三层领导力培训
- 具有2年以上精益实践经验
- 经管理层推荐和选拔

### 5.4 课时安排：40课时

| 模块 | 内容 | 课时 | 教学方式 |
|------|------|------|----------|
| 模块1 | DMAIC方法论 | 8课时 | 课堂 + 项目实操 |
| 模块2 | 战略部署Hoshin Kanri | 6课时 | 课堂 + 案例 |
| 模块3 | 教练技术 | 6课时 | 课堂 + 角色扮演 |
| 模块4 | 精益评估框架 | 4课时 | 课堂 + 审核实操 |
| 模块5 | 供应链精益 | 4课时 | 课堂 + 案例 |
| 模块6 | Office TPM | 4课时 | 课堂 + 实操 |
| 模块7 | 综合项目 | 8课时 | 项目实操 |

### 5.5 各模块要点

#### 模块1：DMAIC方法论（8课时）

**核心要点：**

- DMAIC五阶段详解：定义、测量、分析、改进、控制
- 界定问题和项目范围
- 数据收集和统计分析基础
- 过程能力分析（Cp、Cpk）
- 根本原因验证方法
- 改进方案的优化和验证
- 控制计划和标准化
- 产品质量改善DMAIC项目实例

**项目实操：** 每位学员完成一个DMAIC项目的完整报告

#### 模块2：战略部署Hoshin Kanri（6课时）

**核心要点：**

- Hoshin Kanri的概念和原理
- 突破性目标的设定
- 方策展开（Catchball过程）
- 关键行动计划的制定
- 定期回顾和调整机制
- 制造企业战略部署实例

#### 模块3：教练技术（6课时）

**核心要点：**

- 精益教练的角色定位
- 提问技巧：开放式问题、反思性问题
- 倾听和观察能力
- 反馈技巧：建设性反馈和正面强化
- GROW模型在精益辅导中的应用
- 培养他人精益思维的方法

**角色扮演：** 模拟教练场景，练习教练技术

#### 模块4：精益评估框架（4课时）

**核心要点：**

- 精益成熟度评估模型
- 评估维度和评分标准
- 现场审核技巧
- 评估报告的撰写
- 改进路线图的制定

**实操：** 对模拟车间进行精益评估并撰写报告

#### 模块5：供应链精益（4课时）

**核心要点：**

- 供应链精益管理的理念
- 供应商精益发展和辅导
- 物流和库存优化
- 制造业供应链特点和优化方向

#### 模块6：Office TPM（4课时）

**核心要点：**

- 办公流程中的浪费识别
- 办公流程标准化
- 文档和信息管理优化
- 跨部门协作效率提升

#### 模块7：综合项目（8课时）

**核心要点：**

- 选择一个真实的精益改善项目
综合运用所学方法论和工具
- 项目计划制定、实施和总结
- 项目成果汇报和评审

### 5.6 考核标准

| 考核项目 | 权重 | 合格标准 |
|----------|------|----------|
| DMAIC项目报告 | 25% | 完成并通过评审 |
| 精益评估报告 | 20% | 完成现场评估并提交报告 |
| 综合项目 | 30% | 完成真实改善项目并汇报 |
| 教练技术评估 | 15% | 模拟教练场景评估合格 |
| 课堂参与 | 10% | 出勤率100% |

### 5.7 认证要求

- 完成全部40课时培训
- 所有考核项目合格
- 提交至少1个完整的精益改善项目报告
- 经精益推进委员会评审通过
- 颁发"精益专家认证证书"
