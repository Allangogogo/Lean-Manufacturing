# 01-培训策略

## 子目录说明

本目录包含精益培训体系的顶层策略设计文件，涵盖体系规划、架构设计和资源配置三大核心内容。

## 文件列表

| 文件 | 说明 |
|------|------|
| [精益培训体系规划](./01-精益培训体系规划.md) | 培训体系总览、目标、对象分类、方式及效果评估机制 |
| [四层培训架构设计](./02-四层培训架构设计.md) | 从精益意识到高级推进者的四层递进培训架构 |
| [培训预算与资源规划](./03-培训预算与资源规划.md) | 预算科目、资源需求、年度预算模板及投资回报分析 |

## 关键原则

- 培训策略必须与企业精益转型路线图对齐
- 每个培训层级都需要明确的考核标准和认证要求
- 预算规划应基于实际需求，优先保障高频次的基础培训
