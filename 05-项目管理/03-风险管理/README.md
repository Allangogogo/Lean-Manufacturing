# 03-风险管理

## 概述

风险管理模板用于系统化地识别、评估和应对精益转型过程中的各类风险，降低项目失败的可能性。

## 包含模板

| 模板 | 用途 | 使用阶段 |
|------|------|----------|
| `01-风险登记册模板.md` | 记录和追踪所有已识别的风险 | 全生命周期 |
| `02-风险矩阵模板.md` | 评估风险等级，确定优先级 | 风险评估 |
| `03-风险应对计划模板.md` | 制定具体的风险应对措施 | 风险应对 |

## 使用建议

- 风险识别应全员参与，鼓励一线员工反馈潜在风险
- 风险评估至少每月更新一次，重大变更时即时更新
- 高风险项必须制定应对计划并指定责任人
- 已关闭的风险应保留记录，用于后续项目参考
