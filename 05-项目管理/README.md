# 05-项目管理

## 模块概述

项目管理模块为精益转型提供系统化的项目管控框架，确保转型项目按时、按质、按预算交付。模块涵盖项目全生命周期的管理需求，从项目启动、规划、执行、监控到收尾。

## 子目录结构

| 目录 | 内容 | 说明 |
|------|------|------|
| `01-项目治理/` | 项目章程、干系人管理、沟通计划 | 建立项目治理框架和决策机制 |
| `02-进度管理/` | 甘特图、里程碑追踪、周报 | 项目进度计划与监控 |
| `03-风险管理/` | 风险登记册、风险矩阵、应对计划 | 风险识别、评估与应对 |
| `04-绩效管理/` | KPI仪表板、ROI测算、收尾报告 | 项目绩效度量与评估 |

## 核心理念

精益项目管理遵循以下原则：

1. **可视化管理** — 所有项目状态透明可见
2. **PDCA循环** — 计划-执行-检查-行动的持续改进
3. **快速决策** — 减少审批层级，加速响应
4. **数据驱动** — 基于事实和数据进行项目决策
5. **全员参与** — 项目团队与业务团队紧密协作

## 适用场景

- 精益转型整体项目的规划与管控
- 单一改善项目的立项与执行
- Kaizen活动的组织与追踪
- TPM推进的项目化管理
- 跨部门协作项目的协调

## 使用建议

1. 根据项目规模选择适当的模板，小型项目可简化使用
2. 项目章程在启动阶段完成，后续根据需要更新
3. 建议每周更新进度信息，每月进行项目评审
4. 风险管理应贯穿项目全生命周期
5. 项目收尾时务必完成知识转移和文档归档
