# 04-绩效管理

## 概述

绩效管理模板用于度量精益转型项目的成效，量化改善成果，为决策提供数据支撑。

## 包含模板

| 模板 | 用途 | 使用阶段 |
|------|------|----------|
| `01-KPI仪表板模板.md` | 设计和维护项目核心指标看板 | 项目执行与监控 |
| `02-ROI测算表.md` | 测算精益转型的投资回报率 | 项目评估 |
| `03-项目收尾报告模板.md` | 编制项目总结与经验沉淀 | 项目收尾 |

## 使用建议

- KPI指标应与企业战略目标对齐，避免指标过多
- ROI测算应在项目启动前完成预估，过程中跟踪实际值
- 项目收尾报告是组织学习的重要输入，应认真编写
- 建议将改善前后的数据对比可视化呈现
