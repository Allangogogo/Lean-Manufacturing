## 4. 财务指标计算

### 4.1 净现值（NPV）

```
NPV = Σ(Ct / (1+r)^t) - C0

其中：
Ct = 第t年的净现金流
r = 折现率
C0 = 初始投资
```

| 年份 | 投资（万元） | 收益（万元） | 净现金流（万元） | 折现系数 | 现值（万元） |
|------|------------|------------|----------------|----------|------------|
| 第0年 | _[投资额]_ | 0 | -_[投资额]_ | 1.000 | -_[现值]_ |
| 第1年 | _[投资额]_ | _[收益]_ | _[净现金流]_ | _[系数]_ | _[现值]_ |
| 第2年 | _[投资额]_ | _[收益]_ | _[净现金流]_ | _[系数]_ | _[现值]_ |
| 第3年 | 0 | _[收益]_ | _[净现金流]_ | _[系数]_ | _[现值]_ |
| | | | | **NPV** | **_[总额]_** |

## 5. 紧固件企业ROI测算示例

### 5.1 示例假设

| 项目 | 假设值 |
|------|--------|
| 企业规模 | 年产值5000万元 |
| 员工人数 | 200人 |
| 产品类型 | 标准紧固件（螺栓、螺母、螺钉） |
| 项目周期 | 3年 |
| 折现率 | 8% |

### 5.2 示例投资（总投资约180万元）

| 投资科目 | 金额（万元） | 占比 |
|----------|------------|------|
| 外部咨询 | 45 | 25% |
| 培训费用 | 25 | 14% |
| 设备改造 | 65 | 36% |
| 人力投入 | 30 | 17% |
| 其他+应急 | 15 | 8% |
| **合计** | **180** | **100%** |

### 5.3 示例年收益（年收益约95万元）

| 收益科目 | 年收益（万元） | 占比 |
|----------|--------------|------|
| OEE提升（85%→90%） | 30 | 32% |
| 不良降低（800PPM→400PPM） | 25 | 26% |
| 换型时间减少（30分→15分） | 15 | 16% |
| 库存减少（5天→3天） | 15 | 16% |
| 交付改善+其他 | 10 | 10% |
| **合计** | **95** | **100%** |

### 5.4 示例财务指标

| 指标 | 计算结果 | 判定 |
|------|----------|------|
| NPV（3年，8%折现） | 约60万元 | 正值，可行 |
| IRR | 约28% | 高于8%，可行 |
| 静态回收期 | 约1.9年 | <3年，可行 |
| 动态回收期 | 约2.1年 | <4年，可行 |

> **结论：** 投资回报率约53%（95÷180），项目具有良好的经济可行性。

## 6. 使用说明

1. **保守估算**：收益估算应保守，避免过度乐观影响决策
2. **数据支撑**：所有假设和数据应有依据，必要时进行敏感性分析
3. **分阶段测算**：建议按年度分别测算，便于分阶段验证
4. **定性收益**：除量化收益外，还应记录难以量化的定性收益（如员工能力提升、企业文化改善）
5. **持续跟踪**：项目实施过程中定期对比实际收益与预估，及时调整
6. **多方审核**：财务数据应由财务部门审核确认
7. **案例积累**：完成的ROI测算应归档作为后续项目的参考基准
