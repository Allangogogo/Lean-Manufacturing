## 2. 各KPI详细说明

### 2.1 OEE（设备综合效率）

**计算公式：**
```
OEE = 可用率(A) × 性能率(P) × 合格率(Q)

可用率(A) = (计划运行时间 - 停机时间) / 计划运行时间 × 100%
性能率(P) = (实际产出 × 理论周期时间) / 实际运行时间 × 100%
合格率(Q) = 合格品数量 / 总产出数量 × 100%
```

| 子指标 | 当前值 | 目标值 | 行业基准 |
|--------|--------|--------|----------|
| 可用率 | _[值]_% | ≥90% | 85-90% |
| 性能率 | _[值]_% | ≥95% | 90-95% |
| 合格率 | _[值]_% | ≥99% | 98-99% |
| **OEE** | **_[值]_%** | **≥85%** | **75-85%** |

**数据来源**：MES系统自动采集或现场停机记录表

### 2.2 不良率（PPM）

**计算公式：**
```
不良率(PPM) = 不良品数量 / 总检验数量 × 1,000,000
不良率(%) = 不良品数量 / 总检验数量 × 100%
```

| 分类 | PPM目标 | 说明 |
|------|---------|------|
| 尺寸不良 | ≤150PPM | 关键尺寸、外形尺寸等 |
| 外观不良 | ≤200PPM | 表面缺陷、划痕等 |
| 性能不良 | ≤100PPM | 硬度、扭矩等 |
| **综合** | **≤500PPM** | |

**数据来源**：质量检验系统、SPC数据

### 2.3 换型时间（SMED）

**计算公式：**
```
换型时间 = 末件合格时间 - 首件合格时间
```

| 阶段 | 目标时间 | 说明 |
|------|----------|------|
| 内部作业（停机时） | ≤10分钟 | 必须停机进行的换型操作 |
| 外部作业（运行中） | 提前完成 | 可在运行中准备的操作 |
| **总换型时间** | **≤15分钟** | 从停机到首件合格 |

**数据来源**：换型记录表、视频分析

### 2.4 WIP库存（在制品库存天数）

**计算公式：**
```
WIP库存天数 = 在制品数量 / 日均产出数量
```

### 2.5 交付周期（Lead Time）

**计算公式：**
```
交付周期 = 订单确认到发货的自然天数
交付周期 = 处理时间 + 等待时间 + 加工时间 + 检验时间 + 运输时间
```

## 3. 状态判定标准

| 状态 | 条件 | 说明 |
|------|------|------|
| 🟢 达标 | 实际值 ≥ 目标值（正向指标） | 维持现有水平 |
| 🟡 预警 | 实际值在目标值的90%-100%之间 | 需要关注和改善 |
| 🔴 未达标 | 实际值 < 目标值的90% | 需要立即采取行动 |

> **注意：** 对于反向指标（如不良率、WIP库存），达标条件取"≤目标值"。

## 4. 仪表板展示建议

### 线下看板（推荐张贴位置：生产现场/项目办公室）
- 使用A0或A1尺寸打印
- 每月更新一次数据
- 用红/黄/绿标记可视化状态
- 包含趋势折线图展示指标变化

### 线上仪表板（推荐工具：飞书多维表格/Power BI/钉钉宜搭）
- 实时或每日自动更新
- 支持按产线、时段等维度筛选
- 设置异常预警自动通知
- 历史数据可追溯查询

---

## 使用说明

1. **指标选择**：根据项目阶段选择重点指标，不必全部使用
2. **目标设定**：目标值应具有挑战性但可实现，参考行业基准
3. **数据质量**：确保数据来源可靠，采集方法标准化
4. **趋势分析**：不仅看当前值，更要关注趋势变化
5. **根因分析**：指标异常时要深入分析原因，制定改善措施
6. **持续改进**：定期审视KPI体系，根据项目进展调整指标
7. **全员可见**：仪表板信息应向全体项目团队成员公开透明
