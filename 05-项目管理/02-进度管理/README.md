# 02-进度管理

## 概述

进度管理模板用于制定、追踪和报告精益转型项目的进度计划，确保项目按时完成各阶段目标。

## 包含模板

| 模板 | 用途 | 使用阶段 |
|------|------|----------|
| `01-项目甘特图模板.md` | 制定项目时间线和任务计划 | 项目规划 |
| `02-里程碑追踪表.md` | 追踪关键里程碑的完成情况 | 项目执行与监控 |
| `03-周报模板.md` | 定期汇报项目进展 | 项目执行与监控 |

## 使用建议

- 甘特图建议使用项目管理工具（如MS Project、飞书项目等）维护
- 里程碑延误应立即评估影响并制定补救措施
- 周报应简明扼要，重点突出风险和需要的支持
