# 01-项目治理

## 概述

项目治理模板用于建立精益转型项目的管理框架，明确项目组织架构、干系人关系和沟通机制。

## 包含模板

| 模板 | 用途 | 使用阶段 |
|------|------|----------|
| `01-精益项目章程模板.md` | 定义项目范围、目标和治理结构 | 项目启动 |
| `02-干系人登记册模板.md` | 识别和管理项目干系人 | 项目启动 |
| `03-项目沟通计划模板.md` | 规划项目沟通策略和机制 | 项目规划 |

## 使用建议

- 项目章程是项目的核心文件，需获得发起人签字批准
- 干系人登记册应在项目过程中定期更新
- 沟通计划应根据项目阶段和干系人需求调整
